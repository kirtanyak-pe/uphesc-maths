Question 35 of 120Abstract Algebra

Question 36 of 120Abstract Algebra

Question 39 of 120Abstract Algebra

Question 43 of 120Linear Algebra

Consider the following statements for real \(n\times n\) matrices. I. If \(A\) has \(n\) distinct real eigenvalues, then \(A\) is diagonalisable over \(\mathbb{R}\). II. If \(A\) is invertible and diagonalisable, then its eigenvalues are distinct. III. If \(\chi_A\) has a repeated root, then \(A\) is not diagonalisable. IV. If \(A^2=A\), then \(A\) is diagonalisable. Question 54 of 120Real and Functional Analysis

Question 55 of 120Real and Functional Analysis

Which function on \([0,1]\) is Riemann integrable?

The discontinuity set of \(\chi_C\) is \(C\), which has measure \(0\), so it is Riemann integrable. The discontinuity set of \(\chi_K\) is \(K\) (positive measure), and \(\chi_{\mathbb{Q}}\), \(\chi_{\mathbb{Q}^c}\) are discontinuous everywhere.

Question 56 of 120Real and Functional Analysis

Which subset is compact (in the stated space with the usual metric)?

In \(\mathbb{R}^n\) compact means closed and bounded (Heine-Borel). The unit ball of \(\ell^2\) is closed and bounded but not compact (\(e_n\) has no convergent subsequence); \(\mathbb{Q}\cap[0,1]\) is not complete; \(\mathbb{Z}\) is unbounded.

Question 57 of 120Real and Functional Analysis

Which of the following series converges uniformly on \(\mathbb{R}\)?

\(\lvert\cos nx/n^2\rvert\le 1/n^2\), so the M-test gives uniform convergence on \(\mathbb{R}\). \(\sum x^n\) and \(\sum x^n/n\) are not uniform on \((-1,1)\) (the sums blow up as \(x\to1^-\)). \(\sum\sin nx/n\) has a jump at \(0\) in its sum, so it is not uniform on \([0,2\pi]\).

Question 59 of 120Complex Analysis

Which statement is true?

Morera: a continuous function with zero integral on every closed curve (in particular every triangle) is analytic everywhere, hence entire. The other three fail: \(f(z)=z\) is bounded and analytic on the disc but not constant; \(\sin z\) is unbounded; and if \(\operatorname{Re}f\le0\) then \(e^{f}\) is bounded entire, so \(f\) is constant.

Question 70 of 120Topology and Differential Geometry

Which continuous functions \(f:(\mathbb R,\text{cofinite})\to(\mathbb R,\text{usual})\) exist?

If \(f(x)\ne f(y)\), disjoint open intervals around the two values pull back to disjoint nonempty open sets of the cofinite topology, which is impossible. So \(f\) is constant.

Question 71 of 120Topology and Differential Geometry

A geodesic triangle on a sphere of radius \(2\) has angles \(80^\circ\), \(70^\circ\) and \(60^\circ\). Its area is

Question 72 of 120Topology and Differential Geometry

Which of the following is NOT part of the definition of a topological manifold?

A topological manifold is Hausdorff, second countable and locally Euclidean. Compactness is not required: \(\mathbb R^n\) is a manifold and is not compact.

Question 73 of 120Topology and Differential Geometry

Question 74 of 120Topology and Differential Geometry

Which of the following is NOT true for every metric space?

Every metric space is \(T_4\) and first countable. Second countable holds only for separable metric spaces; an uncountable discrete metric space (or \(\ell^\infty\)) is not second countable.

Question 75 of 120Topology and Differential Geometry

Let \(\mathbb R/\mathbb Q\) be the set of cosets \(x+\mathbb Q\) with the quotient topology. This topology is

A nonempty open set of \(\mathbb R/\mathbb Q\) pulls back to a nonempty saturated open subset of \(\mathbb R\). Such a set contains a whole coset \(x+\mathbb Q\), which is dense, and being a union of cosets and open it must meet every coset, hence it is everything. So only \(\emptyset\) and the whole space are open.

Question 83 of 120Differential Equations
