Lebesgue measure and integral

  1. Question 1Easy
    The Lebesgue measure of the set of all algebraic numbers in \(\mathbb{R}\) is

    Why

    The algebraic numbers are countable (countably many polynomials with integer coefficients, each with finitely many roots). Every countable set has measure \(0\).
  2. Question 2Easy
    Which statement about the Cantor set \(C\) is correct?

    Why

    \(C\) is the set of numbers in \([0,1]\) with a ternary expansion using only digits \(0\) and \(2\), so it is uncountable. \(m(C)=\lim(2/3)^n=0\).
  3. Question 3Easy
    Let \(f(x)=5\) for rational \(x\) and \(f(x)=2\) for irrational \(x\) in \([0,1]\). The Lebesgue integral \(\int_{[0,1]}f\,dm\) is

    Why

    \(f=2\) almost everywhere because \(m(\mathbb{Q}\cap[0,1])=0\). So \(\int f=2\cdot1+5\cdot0=2\). The value \(3.5\) is the (wrong) average of the two values; \(f\) is not Riemann integrable at all.
  4. Question 4Easy
    A bounded function \(f\) on \([a,b]\) is Riemann integrable. Which conclusion is correct?

    Why

    Riemann integrable implies Lebesgue integrable with the same value. By Lebesgue’s criterion \(f\) is continuous almost everywhere, which does not mean continuous or having finitely many discontinuities (Thomae’s function has infinitely many).
  5. Question 5Medium
    On \([0,1]\), for which sequence does \(\lim\int f_n=\int\lim f_n\) hold?

    Why

    \(x^n\to0\) a.e. and \(\int_0^1x^n=\frac1{n+1}\to0\); also \(0\le x^n\le1\) (DCT). The other three tend to \(0\) pointwise but have integrals \(1\), \(n\), and \(1\) respectively.
  6. Question 6Medium
    Let \(f_n=n\chi_{(0,1/n)}\) on \([0,1]\). The pair \(\big(\int\liminf f_n,\ \liminf\int f_n\big)\) is

    Why

    \(f_n(x)=0\) once \(n>1/x\), so \(\liminf f_n=0\) and \(\int\liminf f_n=0\). But \(\int f_n=1\) for every \(n\). Fatou says \(0\le1\); the reverse inequality is wrong.
  7. Question 7Medium
    Consider: (I) every null set is Lebesgue measurable; (II) every uncountable subset of \(\mathbb{R}\) has positive measure; (III) every subset of a null set is null. Which are true?

    Why

    (I) holds because Lebesgue measure is complete; (III) is monotonicity. (II) is false: the Cantor set is uncountable with measure \(0\).
  8. Question 8Medium
    Which function on \([0,1]\) is Riemann integrable?

    Why

    The discontinuity set of \(\chi_C\) is \(C\), which has measure \(0\), so it is Riemann integrable. The discontinuity set of \(\chi_K\) is \(K\) (positive measure), and \(\chi_{\mathbb{Q}}\), \(\chi_{\mathbb{Q}^c}\) are discontinuous everywhere.
  9. Question 9Medium
    The set of \(x\in[0,1]\) whose decimal expansion contains no digit \(7\) has Lebesgue measure

    Why

    After \(n\) digit places the surviving set is a union of intervals of total length \((9/10)^n\). The set is contained in all of them, so its measure is at most \((9/10)^n\to0\). (Numbers with two expansions are countably many.)
  10. Question 10Medium
    Let \(C\) be the Cantor set. On each interval removed at stage \(n\) (there are \(2^{n-1}\) of them, each of length \(3^{-n}\)) put \(f=2^{-n}\), and put \(f=0\) on \(C\). Then \(\int_{[0,1]}f\,dm\) equals

    Why

    \(\int f=\sum_{n\ge1}2^{-n}\cdot2^{n-1}\cdot3^{-n}=\frac12\sum_{n\ge1}3^{-n}=\frac12\cdot\frac12=\frac14\). The value \(1/5\) comes from forgetting the factor \(2^{n-1}\).
  11. Question 11Medium
    Assertion A: The Dirichlet function \(\chi_{\mathbb{Q}}\) is Lebesgue integrable on \([0,1]\). Reason R: Every Lebesgue integrable function on \([0,1]\) is Riemann integrable.

    Why

    A is true: \(\chi_{\mathbb{Q}}\) is measurable with integral \(m(\mathbb{Q}\cap[0,1])=0\). R is false, and \(\chi_{\mathbb{Q}}\) is the counterexample: it is not Riemann integrable. The true implication goes the other way.
  12. Question 12Hard
    \(\displaystyle\lim_{n\to\infty}\int_0^n\Big(1-\frac xn\Big)^ne^{x/2}\,dx\) equals

    Why

    Since \((1-x/n)^n\le e^{-x}\) on \([0,n]\), the integrands are dominated by \(e^{-x/2}\in L^1(0,\infty)\) and converge to \(e^{-x/2}\). By DCT the limit is \(\int_0^\infty e^{-x/2}dx=2\). The answer \(1\) forgets the factor \(e^{x/2}\); \(2/3\) uses \(e^{-3x/2}\).
  13. Question 13Hard

    Enumerate \(\mathbb{Q}\cap[0,1]=\{q_n\}\) and take \(G=\bigcup(q_n-\varepsilon/2^{n+2},q_n+\varepsilon/2^{n+2})\): open, dense, \(m(G)\le\varepsilon/2\).   14. Question 14Hard
    Which statement is true?

    Why

    \((f\circ g)^{-1}(U)=g^{-1}(f^{-1}(U))\) with \(f^{-1}(U)\) open, so it is measurable. For \(g\circ f\) the preimage of a measurable set under a continuous map can be non-measurable. Products of measurable functions are always measurable, so the third statement is false. The supremum statement fails: the supremum of \(\chi_{\{x\}}\) over \(x\in V\) is \(\chi_V\) with \(V\) a Vitali set.
