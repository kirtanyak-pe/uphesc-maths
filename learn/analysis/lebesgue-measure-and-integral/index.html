Why it matters for the exam

Measure theory is the one analysis topic that appeared three times in the recovered 2019 paper (measure of \(\mathbb{Q}\), measure of the irrationals, the Dirichlet function). The 2025 and 2026 papers had no direct measure question, but the same ideas return inside integral-equation and \(L^2\) questions. Expect one-line fact questions: the measure of a standard set, Riemann versus Lebesgue integrability, and which convergence theorem needs which hypothesis.

Core ideas

Lebesgue outer measure

For any \(A\subseteq\mathbb{R}\),

\[m^*(A)=\inf\Big\{\sum_{k=1}^{\infty}\ell(I_k)\;:\; A\subseteq\bigcup_{k}I_k,\ I_k\text{ open intervals}\Big\}.\]

Properties of \(m^*\):

  • Defined for every set, with \(m^*(\varnothing)=0\).
  • Monotone: \(A\subseteq B\Rightarrow m^*(A)\le m^*(B)\).
  • Countably subadditive: \(m^*(\bigcup A_n)\le\sum m^*(A_n)\).
  • \(m^*(I)=\ell(I)\) for every interval.
  • Translation invariant: \(m^*(A+t)=m^*(A)\). Dilation: \(m^*(cA)=\lvert c\rvert\,m^*(A)\).

\(m^*\) is not additive on all sets. That is why we restrict to measurable sets.

Measurable sets (Carathéodory)

\(E\) is Lebesgue measurable if for every set \(A\),

\[m^*(A)=m^*(A\cap E)+m^*(A\cap E^c).\]

Then \(m(E)=m^*(E)\). Facts:

  • The measurable sets form a \(\sigma\)-algebra \(\mathcal{M}\): closed under complements, countable unions and countable intersections.
  • Every open set, closed set, interval, \(G_\delta\) and \(F_\sigma\) is measurable (all Borel sets).
  • Every set of outer measure \(0\) is measurable (Lebesgue measure is complete).
  • \(E\) is measurable iff for every \(\varepsilon>0\) there is an open \(G\supseteq E\) with \(m^*(G\setminus E)<\varepsilon\); iff there is a closed \(F\subseteq E\) with \(m^*(E\setminus F)<\varepsilon\).
  • Equivalent: \(E=H\cup N\) with \(H\) an \(F_\sigma\) set and \(m(N)=0\).

Properties of the measure \(m\)

  • Countable additivity: disjoint measurable \(E_k\) give \(m(\bigcup E_k)=\sum m(E_k)\).
  • Continuity from below: \(E_1\subseteq E_2\subseteq\cdots\) gives \(m(\bigcup E_n)=\lim m(E_n)\).
  • Continuity from above: \(E_1\supseteq E_2\supseteq\cdots\) and \(m(E_1)<\infty\) give \(m(\bigcap E_n)=\lim m(E_n)\). The hypothesis \(m(E_1)<\infty\) is needed: \(E_n=[n,\infty)\) has \(m(E_n)=\infty\) for all \(n\) but \(\bigcap E_n=\varnothing\).
  • \(m(E\cup F)+m(E\cap F)=m(E)+m(F)\) for measurable \(E,F\).
  • Translation invariant; \(m(cE)=\lvert c\rvert m(E)\).

Null sets

A set \(N\) is null if \(m(N)=0\).

  • Every countable set is null. Proof: enumerate \(x_1,x_2,\dots\) and cover \(x_k\) by an interval of length \(\varepsilon/2^k\); the total length is \(\varepsilon\). So \(\mathbb{Q}\), the algebraic numbers, and \(\mathbb{N},\mathbb{Z}\) all have measure \(0\).
  • A countable union of null sets is null. Any subset of a null set is null (and measurable).
  • Null does not mean countable. The Cantor set is uncountable and null.
  • Digit-restricted sets are null. Let \(A\subseteq[0,1]\) be the set of numbers having no digit \(7\) in their decimal expansion. At stage \(n\) the numbers whose first \(n\) digits avoid \(7\) form a union of \(9^n\) intervals of length \(10^{-n}\), so \(m(A)\le\left(\frac9{10}\right)^n\to0\). The same argument works for any proper subset of digits: a set defined by restricting digits to fewer than \(10\) allowed values (decimal) or fewer than \(3\) (ternary) has measure \(0\). The Cantor set is the ternary case with allowed digits \(\{0,2\}\). Each such set is uncountable (digits \(\{0,1\}\) in decimal already give \(2^{\aleph_0}\) numbers). Conversely, almost every \(x\in[0,1]\) contains every digit infinitely often (Borel’s normal number theorem), so “has at least one digit \(7\)” has measure \(1\).
  • Null \(+\) null need not be null. \(C+C=[0,2]\) and \(C-C=[-1,1]\) although \(m(C)=0\). (Contrast: \(m(A)>0\Rightarrow A-A\) contains an interval around \(0\), Steinhaus.)

The Cantor set

\(C=\bigcap_{n}C_n\), where \(C_0=[0,1]\) and \(C_{n}\) is obtained from \(C_{n-1}\) by removing the open middle third of each interval. \(C_n\) is a union of \(2^n\) closed intervals of length \(3^{-n}\), so

\[m(C)=\lim_{n\to\infty}\Big(\tfrac23\Big)^n=0.\]

Equivalently, the removed intervals have total length \(\sum_{n\ge1}2^{n-1}/3^{n}=1\).

Properties to know:

Property Cantor set \(C\)
Measure \(0\)
Cardinality uncountable (\(=\mathfrak{c}\)): \(C\) is the set of \(x\in[0,1]\) with a ternary expansion using only digits \(0\) and \(2\)
Topology closed, compact, perfect (no isolated points), nowhere dense, totally disconnected
Cantor function continuous, increasing, constant on each removed interval, so \(f'=0\) a.e. but \(f(1)-f(0)=1\) (not absolutely continuous)

A fat Cantor set is closed, nowhere dense, uncountable and has positive measure. Example (Smith-Volterra-Cantor): at stage \(n\) remove from each of the \(2^{n-1}\) remaining intervals a middle open interval so that the pieces removed at stage \(n\) have total length \(2^{n-1}/4^{n}\). The total removed is \(\sum_{n\ge1}2^{n-1}/4^n=\tfrac12\), so the remaining set has measure \(\tfrac12\). So “nowhere dense” does not imply “null”.

Non-measurable sets

The Vitali set (one representative from each coset of \(\mathbb{Q}\) in \([0,1]\)) is not Lebesgue measurable. Its construction needs the axiom of choice. Every set of positive outer measure contains a non-measurable subset. There are \(2^{\mathfrak{c}}\) Lebesgue measurable sets (every subset of \(C\) is measurable) but only \(\mathfrak{c}\) Borel sets, so some Lebesgue measurable sets are not Borel.

A dense set need not have full measure: \(\mathbb{Q}\) is dense with measure \(0\), and an open dense subset of \([0,1]\) can have measure \(<\tfrac12\).

Measurable functions

\(f:E\to[-\infty,\infty]\) is measurable if \(\{x\in E: f(x)>a\}\) is measurable for every real \(a\). Equivalent: use \(\ge a\), \(<a\) or \(\le a\). Equivalent: \(f^{-1}(U)\) is measurable for every open \(U\).

  • Continuous functions, monotone functions, step functions and \(\chi_E\) (\(E\) measurable) are measurable. \(\chi_E\) is measurable iff \(E\) is.
  • If \(f,g\) are measurable then \(f+g\), \(fg\), \(\lvert f\rvert\), \(\max(f,g)\), \(\min(f,g)\) are measurable.
  • \(\sup f_n\), \(\inf f_n\), \(\limsup f_n\), \(\liminf f_n\) and the pointwise limit of measurable functions are measurable.
  • If \(f\) is measurable and \(g=f\) almost everywhere (a.e.), then \(g\) is measurable (completeness).
  • Composition: \(f\) continuous and \(g\) measurable gives \(f\circ g\) measurable. But \(g\circ f\) (\(g\) measurable, \(f\) continuous) need not be measurable. It is if \(g\) is Borel.

Three theorems on how measurable functions behave (statements only):

  • Egorov. \(m(E)<\infty\) and \(f_n\to f\) a.e. on \(E\): for every \(\varepsilon>0\) there is a closed \(F\subseteq E\) with \(m(E\setminus F)<\varepsilon\) and \(f_n\to f\) uniformly on \(F\). Finite measure is essential.
  • Lusin. A measurable \(f\) (finite a.e.) on \([a,b]\) is continuous on a closed set \(F\) with \(m([a,b]\setminus F)<\varepsilon\).
  • Convergence in measure. \(f_n\to f\) in measure if \(m\{\lvert f_n-f\rvert>\varepsilon\}\to0\) for every \(\varepsilon\). a.e. convergence on a finite-measure set implies convergence in measure. Convergence in measure implies a subsequence converges a.e. The converse implications fail in general (the “typewriter” sequence of moving indicators converges in measure but at no point).

Simple functions and the integral

A simple function is \(\varphi=\sum_{i=1}^{n}a_i\chi_{E_i}\) with \(E_i\) measurable and disjoint, \(a_i\) real. Its integral is

\[\int\varphi\,dm=\sum_{i=1}^{n}a_i\,m(E_i)\qquad(0\cdot\infty=0).\]

Approximation theorem. Every measurable \(f\ge0\) is the limit of an increasing sequence of simple functions, for instance \(\varphi_n=\min\big(n,\,2^{-n}\lfloor 2^nf\rfloor\big)\).

Integral of \(f\ge0\): \(\int f=\sup\{\int\varphi:\ 0\le\varphi\le f,\ \varphi\text{ simple}\}\in[0,\infty]\).

General \(f\): \(f=f^+-f^-\) with \(f^{\pm}\ge0\). If at least one of \(\int f^{\pm}\) is finite, \(\int f=\int f^+-\int f^-\). \(f\) is integrable (\(f\in L^1\)) iff \(\int\lvert f\rvert<\infty\).

Basic properties:

  • Linear on \(L^1\); monotone (\(f\le g\Rightarrow\int f\le\int g\)); \(\big\lvert\int f\big\rvert\le\int\lvert f\rvert\).
  • \(\int_E f=0\) if \(m(E)=0\). Changing \(f\) on a null set changes nothing.
  • \(f\ge0\) and \(\int f=0\) iff \(f=0\) a.e.
  • \(f\in L^1\) implies \(f\) finite a.e.
  • Absolute continuity of the integral: for \(f\in L^1\) and \(\varepsilon>0\) there is \(\delta>0\) with \(\int_E\lvert f\rvert<\varepsilon\) whenever \(m(E)<\delta\).

The three convergence theorems

Monotone Convergence Theorem (MCT). If \(f_n\) are measurable, \(0\le f_1\le f_2\le\cdots\) and \(f_n\to f\) a.e., then \(\int f_n\uparrow\int f\) (the value \(\infty\) is allowed). Hypotheses: non-negative and increasing. Consequence: for \(g_k\ge0\), \(\int\sum_kg_k=\sum_k\int g_k\) with no further condition.

Fatou’s Lemma. If \(f_n\ge0\) are measurable then

\[\int\liminf_{n\to\infty}f_n\ \le\ \liminf_{n\to\infty}\int f_n.\]

The inequality can be strict: \(f_n=n\chi_{(0,1/n)}\) has \(\int f_n=1\) for all \(n\) but \(\liminf f_n=0\); also \(f_n=\chi_{[n,n+1]}\).

Dominated Convergence Theorem (DCT). If \(f_n\) are measurable, \(f_n\to f\) a.e., and there is an integrable \(g\) with \(\lvert f_n\rvert\le g\) a.e. for all \(n\), then \(f\in L^1\), \(\int\lvert f_n-f\rvert\to0\), and in particular \(\int f_n\to\int f\).

Corollaries: the bounded convergence theorem (finite measure space, \(\lvert f_n\rvert\le K\)); term-by-term integration \(\int\sum f_k=\sum\int f_k\) whenever \(\sum\int\lvert f_k\rvert<\infty\).

Typical evaluations.

  • \(\lim\int_0^1nxe^{-nx}dx=0\): the integrand tends to \(0\) for each \(x>0\), and \(\sup_n nxe^{-nx}=\frac1e\) (at \(n=\frac1x\)) is a constant bound on \([0,1]\); bounded convergence applies.
  • \(\lim\int_0^\infty n\sin\frac xn\,e^{-x}dx=\int_0^\infty xe^{-x}dx=1\): \(\lvert n\sin\frac xn\rvert\le x\), and \(xe^{-x}\) is integrable, so DCT applies.
  • \(\lim\int_0^\infty\frac{\sin(x/n)}{x(1+x^2)}dx=0\): the integrand is bounded by \(\frac{1}{n(1+x^2)}\).
  • MCT for series of non-negative terms: \(\int_0^1\frac{-\ln x}{1-x}dx=\sum_{k\ge0}\int_0^1x^k(-\ln x)\,dx=\sum_{k\ge1}\frac1{k^2}=\frac{\pi^2}6\).
  • DCT cannot be applied to \(f_n=n\chi_{(0,1/n)}\) (\(\sup_nf_n\approx\frac1x\) on \((0,1)\) is not integrable) and indeed \(\int f_n=1\not\to0\).

What goes wrong without the hypotheses:

Example What it shows
\(f_n=n\chi_{(0,1/n)}\): \(f_n\to0\) pointwise, \(\int f_n=1\) no dominating \(g\) in \(L^1\): the limit and the integral do not commute
\(f_n=\chi_{[n,n+1]}\): \(f_n\to0\), \(\int f_n=1\) same, on an infinite-measure space
\(f_n=\chi_{[n,\infty)}\downarrow0\), \(\int f_n=\infty\) MCT is for increasing sequences; the decreasing version needs \(\int f_1<\infty\)

Riemann versus Lebesgue

Lebesgue’s criterion. A bounded \(f:[a,b]\to\mathbb{R}\) is Riemann integrable iff the set of its discontinuities has measure zero.

Consequences:

  • Riemann integrable on \([a,b]\) \(\Rightarrow\) Lebesgue integrable, with the same value. So Lebesgue integration is an extension.
  • The converse is false.
  • The Lebesgue criterion needs boundedness; Riemann integrability is defined for bounded functions on compact intervals.

The Dirichlet function \(\chi_{\mathbb{Q}}\) on \([0,1]\) (\(1\) on rationals, \(0\) on irrationals):

  • Every subinterval contains rationals and irrationals, so every upper Darboux sum is \(1\) and every lower sum is \(0\). Not Riemann integrable. (Equivalently, it is discontinuous at every point, and \([0,1]\) has measure \(1\ne0\).)
  • It is measurable (\(\mathbb{Q}\) is countable, hence Borel), and \(\int_{[0,1]}\chi_{\mathbb{Q}}\,dm=1\cdot m(\mathbb{Q}\cap[0,1])=0\). So it is Lebesgue integrable, with integral \(0\).
  • It equals \(0\) a.e. It is not continuous, and it is measurable (not “non-measurable”).

Improper integrals. For \(f\ge0\) locally Riemann integrable on \([a,\infty)\), the improper Riemann integral equals the Lebesgue integral (both may be \(\infty\)). For \(f\) that changes sign, Lebesgue integrability needs \(\int\lvert f\rvert<\infty\). So

\[\int_0^\infty\frac{\sin x}{x}\,dx=\frac{\pi}{2}\ \text{(improper Riemann, converges)},\qquad \frac{\sin x}{x}\notin L^1(0,\infty)\]

because \(\int_0^\infty\lvert\sin x/x\rvert\,dx\ge\sum_k\frac{2}{(k+1)\pi}=\infty\). Conditionally convergent improper integrals are Riemann-improper but not Lebesgue.

Hoelder, Minkowski and the \(L^p\) inclusions

For \(1\le p\le\infty\) with \(\frac1p+\frac1q=1\):

  • Hoelder. \(\int\lvert fg\rvert\le\lVert f\rVert_p\lVert g\rVert_q\) (Cauchy-Schwarz is \(p=q=2\)).
  • Minkowski. \(\lVert f+g\rVert_p\le\lVert f\rVert_p+\lVert g\rVert_p\) for \(p\ge1\); for \(0<p<1\) it fails, so \(\lVert\cdot\rVert_p\) is not a norm.
  • Finite measure space: \(\lVert f\rVert_p\le m(E)^{\frac1p-\frac1q}\lVert f\rVert_q\) for \(p<q\), so \(L^q\subseteq L^p\). Sequence spaces go the other way: \(\ell^p\subseteq\ell^q\) for \(p<q\). On \(\mathbb{R}\) neither inclusion holds.
  • Power functions. \(x^{-a}\in L^p(0,1)\) iff \(ap<1\); \(x^{-a}\in L^p(1,\infty)\) iff \(ap>1\). So \(x^{-1/3}\in L^1(0,1)\) (integral \(\frac32\)), but \(x^{-1/3}\notin L^3(0,1)\) since \(\int x^{-1}=\infty\); \(x^{-1/2}\in L^1(0,1)\setminus L^2(0,1)\).
  • On \(\mathbb{R}\): \(\frac1{1+\lvert x\rvert}\in L^2\setminus L^1\), while \(x^{-1/2}\chi_{(0,1)}\in L^1\setminus L^2\), which shows that no inclusion holds.
  • \(\lVert f\rVert_p\to\lVert f\rVert_\infty\) as \(p\to\infty\) on a finite measure space, and \(L^p\) convergence implies a subsequence converging a.e.

Other results worth knowing

  • Fubini–Tonelli. For \(f\ge0\) measurable on a product, iterated integrals exist (as elements of \([0,\infty]\)) and are equal (Tonelli). For \(f\in L^1\) of the product, Fubini gives the same equality with a.e. defined inner integrals.
  • Lebesgue differentiation / FTC. A monotone function is differentiable a.e. \(f\) is absolutely continuous on \([a,b]\) iff \(f(x)=f(a)+\int_a^xf'\) with \(f'\in L^1\). The Cantor function is continuous and increasing but not absolutely continuous.
  • \(L^p\) spaces. \(L^p(E)\) is the set of (classes of a.e. equal) measurable \(f\) with \(\int\lvert f\rvert^p<\infty\), with norm \(\lVert f\rVert_p\). Riesz–Fischer: \(L^p\) is complete for \(1\le p\le\infty\). On a finite measure space \(L^q\subseteq L^p\) for \(p<q\); on \(\mathbb{R}\) no inclusion holds.
  • Borel-Cantelli. If \(\sum m(E_n)<\infty\) then almost every \(x\) lies in only finitely many \(E_n\), that is \(m(\limsup E_n)=0\).
  • Lebesgue measure in \(\mathbb{R}^n\) is the product measure: a box has measure \(\prod(b_i-a_i)\), a hyperplane (or any proper affine subspace) has measure \(0\), and \(m(TE)=\lvert\det T\rvert\,m(E)\) for a linear map \(T\).

Formulas and results

  • \(m^*(A)=\inf\sum\ell(I_k)\) over countable interval covers.
  • \(E\) measurable iff \(m^*(A)=m^*(A\cap E)+m^*(A\cap E^c)\) for all \(A\).
  • Countable sets have measure \(0\): cover \(x_k\) by length \(\varepsilon/2^{k}\).
  • \(m(C_n)=(2/3)^n\to0\), so \(m(\text{Cantor set})=0\), yet \(C\) is uncountable.
  • \(m(E+t)=m(E)\) and \(m(cE)=\lvert c\rvert m(E)\).
  • Continuity from below always; from above only when some \(m(E_n)<\infty\).
  • \(\int\sum_i a_i\chi_{E_i}=\sum a_i m(E_i)\).
  • MCT (\(0\le f_n\uparrow f\)): \(\lim\int f_n=\int f\).
  • Fatou (\(f_n\ge0\)): \(\int\liminf f_n\le\liminf\int f_n\).
  • DCT (\(f_n\to f\) a.e., \(\lvert f_n\rvert\le g\in L^1\)): \(\int f_n\to\int f\) and \(\int\lvert f_n-f\rvert\to0\).
  • Bounded \(f\) on \([a,b]\): Riemann integrable iff discontinuities form a null set; then Riemann \(=\) Lebesgue.
  • \(\int_a^bf\) (Lebesgue) \(=0\) whenever \(f=0\) a.e.
  • \(\sum_{n\ge1}n\,r^n=\dfrac{r}{(1-r)^2}\) for \(\lvert r\rvert<1\) (useful for Cantor-type integrals).

Worked examples

Example 1: an integral over a Cantor-type partition

Let \(C\) be the Cantor set. On \([0,1]\setminus C\) define \(f=n\) on each of the intervals removed at stage \(n\) (there are \(2^{n-1}\) of them, each of length \(3^{-n}\)), and \(f=0\) on \(C\). Find \(\int_{[0,1]}f\).

Since \(m(C)=0\), only the removed intervals count. By countable additivity (or MCT),

\[\int f=\sum_{n\ge1}n\cdot2^{n-1}\cdot3^{-n}=\frac12\sum_{n\ge1}n\Big(\frac23\Big)^n=\frac12\cdot\frac{2/3}{(1/3)^2}=\frac12\cdot6=3.\]

Example 2: modifying a function on \(\mathbb{Q}\)

Let \(f(x)=x\) if \(x\) is irrational and \(f(x)=7\) if \(x\) is rational, on \([0,1]\). Then \(f=x\) a.e., so \(f\) is measurable and \(\int_{[0,1]}f=\int_0^1x\,dx=\tfrac12\). The function is not Riemann integrable: it is discontinuous at every point except \(x=7\), which is not in \([0,1]\), so it is discontinuous everywhere and \([0,1]\) has measure \(1\).

Example 3: a limit by DCT

Compute \(\displaystyle\lim_{n\to\infty}\int_0^n\Big(1-\frac xn\Big)^ne^{x/2}\,dx\).

Write the integral as \(\int_0^\infty f_n\) with \(f_n(x)=(1-x/n)^ne^{x/2}\chi_{[0,n]}(x)\).

  • Pointwise: \((1-x/n)^n\to e^{-x}\), so \(f_n(x)\to e^{-x}e^{x/2}=e^{-x/2}\).
  • Domination: \(1-t\le e^{-t}\) gives \(0\le(1-x/n)^n\le e^{-x}\) on \([0,n]\), so \(0\le f_n\le e^{-x/2}\), which is integrable.

By DCT the limit is \(\int_0^\infty e^{-x/2}dx=2\).

Example 4: Fatou can be strict

Let \(f_n=n\chi_{(0,1/n)}\) on \([0,1]\). For every \(x\), \(f_n(x)=0\) once \(n>1/x\), so \(\liminf f_n=0\) and \(\int\liminf f_n=0\). But \(\int f_n=n\cdot\frac1n=1\). So \(0<1\) and Fatou’s inequality is strict. DCT does not apply: on \((1/(k+1),1/k)\) we have \(\sup_nf_n=k\), so \(\int\sup_nf_n=\sum_k k\big(\tfrac1k-\tfrac1{k+1}\big)=\sum_k\tfrac1{k+1}=\infty\), and no integrable dominating function exists.

Example 5: is it Riemann integrable? Is it Lebesgue integrable?

Decide for \(\chi_C\) (\(C\) the Cantor set) on \([0,1]\).

\(\chi_C\) is discontinuous exactly at the points of \(C\) (at a point outside the closed set \(C\) it is locally \(0\); at a point of \(C\), which has no interior, nearby points outside \(C\) exist). \(m(C)=0\), so by Lebesgue’s criterion it is Riemann integrable. Its integral is \(m(C)=0\). For a fat Cantor set \(K\) with \(m(K)>0\), \(\chi_K\) is discontinuous on the set \(K\) of positive measure, so it is Lebesgue integrable but not Riemann integrable.

Common traps

  • “Measure zero means countable.” False: the Cantor set is uncountable with measure \(0\).
  • “Nowhere dense means measure zero.” False: fat Cantor sets are nowhere dense with positive measure.
  • “Dense means large.” \(\mathbb{Q}\) is dense with measure \(0\). An open set containing \(\mathbb{Q}\) can have measure less than \(\varepsilon\).
  • “The Dirichlet function is not integrable.” It is Riemann non-integrable but Lebesgue integrable with integral \(0\). It is measurable.
  • Riemann integrable implies Lebesgue integrable (same value). The reverse fails, and only for bounded functions on \([a,b]\) does the discontinuity criterion apply.
  • DCT needs one integrable dominating function \(g\) for all \(n\). A bound like \(\lvert f_n\rvert\le n\) is not enough.
  • MCT is for increasing sequences of non-negative functions. For decreasing sequences you need \(\int f_1<\infty\).
  • Fatou gives only an inequality, and the direction is \(\int\liminf\le\liminf\int\).
  • Improper conditionally convergent integrals (\(\sin x/x\)) exist in the Riemann sense but not as Lebesgue integrals.
  • Continuity from above needs a finite-measure set in the chain.
  • Outer measure is defined for all sets but is not additive on all sets. Non-measurable sets exist (Vitali), and their construction uses choice.
  • \(\int f=0\) with \(f\ge0\) means \(f=0\) a.e., not \(f\equiv0\).
  • Composition: \(g\circ f\) with \(g\) Lebesgue measurable and \(f\) continuous need not be measurable.

Previous-year questions

These 2019 items come from a partial reconstruction of the 2019 paper (35 of 70 maths questions, re-typed in a solution video), not from the official booklet. The answers are the ones ticked in that video, and each agrees with the mathematics.

2019, unnumbered 26. The Lebesgue measure of \(\mathbb{Q}\) is: \(\infty\), \(1\), \(0\), \(2\).

Answer: \(0\). \(\mathbb{Q}\) is countable. Cover the \(k\)-th rational by an interval of length \(\varepsilon/2^k\); the total length is \(\varepsilon\) for every \(\varepsilon\), so \(m^*(\mathbb{Q})=0\).

2019, unnumbered 27. The Lebesgue measure of the set of irrationals in \([0,1]\) is: \(1\), and three other values.

Answer: \(1\). \([0,1]=(\mathbb{Q}\cap[0,1])\cup(\text{irrationals})\) is a disjoint union with \(m([0,1])=1\) and \(m(\mathbb{Q}\cap[0,1])=0\), so the irrationals have measure \(1-0=1\).

2019, unnumbered 28. For the indicator function of the rationals on \([0,1]\), which statement is true: it is continuous; it is Riemann integrable; it is Lebesgue integrable; it is non-measurable?

Answer: Lebesgue integrable. It is discontinuous everywhere, so it is not continuous and, by Lebesgue’s criterion, not Riemann integrable (upper sum \(1\), lower sum \(0\)). It is measurable because \(\mathbb{Q}\) is countable. Its Lebesgue integral is \(0\cdot m(\text{irrationals})+1\cdot m(\mathbb{Q}\cap[0,1])=0\).

Quick revision

  • Outer measure: infimum of total lengths of countable interval covers; subadditive and monotone but not additive on all sets.
  • Measurable sets form a \(\sigma\)-algebra containing all Borel sets and all null sets.
  • Countable sets are null, so \(m(\mathbb{Q})=0\), \(m(\text{algebraic numbers})=0\), irrationals in \([0,1]\) have measure \(1\).
  • Cantor set: uncountable, closed, nowhere dense, measure \(0\) since \(m(C_n)=(2/3)^n\).
  • Fat Cantor set: nowhere dense, positive measure.
  • Simple function integral: \(\sum a_im(E_i)\); \(\int f\) for \(f\ge0\) is the sup over simple \(\varphi\le f\).
  • MCT: \(0\le f_n\uparrow f\) gives \(\int f_n\uparrow\int f\).
  • Fatou: \(\int\liminf f_n\le\liminf\int f_n\), with \(n\chi_{(0,1/n)}\) as the standard strict example.
  • DCT: needs a single integrable dominating \(g\); the example \(n\chi_{(0,1/n)}\) shows what fails without it.
  • Bounded \(f\) on \([a,b]\) is Riemann integrable iff its discontinuity set is null; then Riemann \(=\) Lebesgue.
  • Dirichlet function: not Riemann integrable, Lebesgue integral \(0\), measurable.
  • \(\int_0^\infty\sin x/x\,dx\) exists as an improper integral but \(\sin x/x\notin L^1\).
