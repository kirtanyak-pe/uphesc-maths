Why it matters for the exam

The syllabus names Gauss elimination and Gauss-Seidel directly, and the 2026 paper asked Gauss-Seidel versus Jacobi (Q59). Typical questions: which method needs pivoting, what the convergence condition is (diagonal dominance, spectral radius), which of Jacobi and Gauss-Seidel is faster, and the form of an LU factorisation. Operation counts and condition number appear as statement-type options.

Core ideas

The problem

Solve \(A\mathbf x=\mathbf b\) with \(A\) an \(n\times n\) nonsingular matrix.

  • Direct methods give the exact answer in a finite number of steps if there were no rounding: Gauss elimination, Gauss-Jordan, LU, Cholesky.
  • Iterative methods produce a sequence \(\mathbf x^{(0)},\mathbf x^{(1)},\dots\to\mathbf x\): Jacobi, Gauss-Seidel, SOR. They are preferred for large sparse systems.

Gauss elimination

Two phases on the augmented matrix \([A\mid\mathbf b]\).

  1. Forward elimination. For \(k=1,\dots,n-1\) use row \(k\) (pivot \(a_{kk}\)) to make zeros below it. Multiplier \(m_{ik}=a_{ik}/a_{kk}\); row\(_i\leftarrow\) row\(_i-m_{ik}\,\)row\(_k\). This ends with an upper-triangular system \(U\mathbf x=\mathbf c\).
  2. Back substitution. \(x_n=\frac{c_n}{u_{nn}},\qquad x_i=\frac1{u_{ii}}\Big(c_i-\sum_{j=i+1}^{n}u_{ij}x_j\Big).\)

Facts used in questions:

  • \(\det A=\pm\) product of the pivots (sign \((-1)^s\) for \(s\) row interchanges).
  • It fails (without row exchange) if a pivot is \(0\), even when \(A\) is nonsingular.
  • Inconsistency shows as a row \(0=c\neq0\); infinitely many solutions as an all-zero row.

Pivoting

A small pivot gives a huge multiplier and amplifies rounding error. Fix: exchange rows before eliminating.

  • Partial pivoting: in column \(k\), pick the row \(i\ge k\) with largest \(\lvert a_{ik}\rvert\) and swap it to row \(k\).
  • Complete pivoting: pick the largest \(\lvert a_{ij}\rvert\) over the whole remaining block (swaps rows and columns, so variables are re-ordered). More stable but more costly.
  • Scaled partial pivoting: compare \(\lvert a_{ik}\rvert/s_i\) where \(s_i=\max_j\lvert a_{ij}\rvert\).

Pivoting is for stability, not for speed. It does not change the exact solution.

Gauss-Jordan method

Eliminate above and below each pivot, and scale pivots to \(1\), so \([A\mid\mathbf b]\to[I\mid\mathbf x]\). No back substitution. Applying the same row operations to \([A\mid I]\) gives \([I\mid A^{-1}]\), the standard way to compute an inverse by hand. It needs about \(n^3/2\) multiplications versus \(n^3/3\) for Gauss elimination, so it is slower for solving a single system.

LU factorisation

If \(A=LU\) with \(L\) lower and \(U\) upper triangular, solve \(A\mathbf x=\mathbf b\) in two triangular solves:

\(L\mathbf y=\mathbf b\ \text{(forward)},\qquad U\mathbf x=\mathbf y\ \text{(backward)}.\)

Existence. If all leading principal minors of \(A\) are nonzero, \(A=LU\) exists and is unique once the diagonal of \(L\) (or \(U\)) is fixed. Otherwise row pivoting is needed: \(PA=LU\).

Variant Normalisation Notes
Doolittle \(l_{ii}=1\) \(U\) is the result of Gauss elimination, \(L\) stores the multipliers \(m_{ik}\)
Crout \(u_{ii}=1\) \(L'=LD,\ U'=D^{-1}U\) where \(D=\operatorname{diag}(u_{ii})\)
Cholesky \(A=LL^{T}\) only for symmetric positive definite \(A\); about half the work

Doolittle formulas (\(u_{1j}=a_{1j}\)):

\(u_{ij}=a_{ij}-\sum_{k=1}^{i-1}l_{ik}u_{kj}\ (j\ge i),\qquad l_{ij}=\frac1{u_{jj}}\Big(a_{ij}-\sum_{k=1}^{j-1}l_{ik}u_{kj}\Big)\ (i>j).\)

\(\det A=\prod u_{ii}\) (Doolittle). The big advantage: factorise once (\(\approx n^3/3\)), then each new right-hand side costs only \(n^2\).

Operation counts (multiplications and divisions)

Task Count
Gauss elimination (solve) \(\dfrac{n^3}{3}+n^2-\dfrac n3\ \approx\ \dfrac{n^3}3\)
Gauss-Jordan (solve) \(\dfrac{n^3}{2}+\dfrac{n^2}{2}\ \approx\ \dfrac{n^3}2\)
LU factorisation \(\approx\dfrac{n^3}{3}\); each further right side \(n^2\)
Inverse by Gauss-Jordan \(\approx n^3\)
Cramer’s rule about \(n\cdot n!\) with cofactor expansion: hopeless for large \(n\)
One Jacobi or Gauss-Seidel sweep (dense) \(n^2\)

An iterative method wins only when it needs fewer than about \(n/3\) sweeps (dense case) or when \(A\) is sparse.

Jacobi and Gauss-Seidel: the iterations

Write \(A=D+L+U\) with \(D\) the diagonal, \(L\) the strictly lower and \(U\) the strictly upper part (not the LU factors). Assume \(a_{ii}\neq0\).

Jacobi (method of simultaneous displacements): every component uses only old values.

\(x_i^{(k+1)}=\frac1{a_{ii}}\Big(b_i-\sum_{j\ne i}a_{ij}x_j^{(k)}\Big),\qquad D\mathbf x^{(k+1)}=\mathbf b-(L+U)\mathbf x^{(k)}.\)

Gauss-Seidel (successive displacements): use the newest values as soon as they are available.

\(x_i^{(k+1)}=\frac1{a_{ii}}\Big(b_i-\sum_{j<i}a_{ij}x_j^{(k+1)}-\sum_{j>i}a_{ij}x_j^{(k)}\Big),\qquad (D+L)\mathbf x^{(k+1)}=\mathbf b-U\mathbf x^{(k)}.\)

Both have the form \(\mathbf x^{(k+1)}=T\mathbf x^{(k)}+\mathbf c\) with iteration matrices

\(T_J=-D^{-1}(L+U),\qquad T_{GS}=-(D+L)^{-1}U.\)

Convergence

The error obeys \(\mathbf e^{(k+1)}=T\mathbf e^{(k)}\), so \(\mathbf e^{(k)}=T^k\mathbf e^{(0)}\).

Fundamental theorem. The iteration converges for every starting vector \(\mathbf x^{(0)}\) if and only if the spectral radius \(\rho(T)=\max\lvert\lambda_i(T)\rvert<1\). A sufficient condition is \(\lVert T\rVert<1\) in some induced norm; then

\(\lVert\mathbf x^{(k)}-\mathbf x\rVert\le\frac{\lVert T\rVert^k}{1-\lVert T\rVert}\lVert\mathbf x^{(1)}-\mathbf x^{(0)}\rVert.\)

Diagonal dominance (sufficient, not necessary). \(A\) is strictly diagonally dominant by rows if

\(\lvert a_{ii}\rvert>\sum_{j\ne i}\lvert a_{ij}\rvert\quad\text{for every }i.\)

Then both Jacobi and Gauss-Seidel converge for every \(\mathbf x^{(0)}\). (For Jacobi, \(\lVert T_J\rVert_\infty<1\) directly.) Rows may be re-ordered to create dominance. Weak dominance (with \(\ge\) and strict for at least one row) works if \(A\) is irreducible.

Other results.

  • If \(A\) is symmetric positive definite, Gauss-Seidel converges (Jacobi need not).
  • Rate: the smaller \(\rho(T)\), the faster. Digits gained per sweep \(\approx-\log_{10}\rho(T)\).
  • Stein-Rosenberg: for nonnegative \(T_J\), Jacobi and Gauss-Seidel converge or diverge together, and when they converge \(\rho(T_{GS})\le\rho(T_J)\).
  • Consistently ordered matrices (block tridiagonal systems from discretised PDEs): \(\rho(T_{GS})=\rho(T_J)^2\). So Gauss-Seidel needs about half as many iterations.
  • Convergence rate is linear.

Why Gauss-Seidel is usually faster

It uses the freshly computed components in the same sweep, so information propagates faster, and it needs less storage (it overwrites \(\mathbf x\) in place; Jacobi keeps two vectors). In typical diagonally dominant and PDE-type systems \(\rho(T_{GS})=\rho(T_J)^2\). But this is not a theorem for all matrices: there are matrices where Jacobi converges and Gauss-Seidel diverges, and vice versa. Example: \(A=\begin{pmatrix}1&2&-2\\1&1&1\\2&2&1\end{pmatrix}\) has \(\rho(T_J)=0\) (so Jacobi converges in \(3\) steps) but \(\rho(T_{GS})=2\) (Gauss-Seidel diverges). So the safe exam statement is: for diagonally dominant systems both converge and Gauss-Seidel generally converges faster.

Successive over-relaxation (statement only)

SOR takes \(\mathbf x^{(k+1)}=(1-\omega)\mathbf x^{(k)}+\omega\,\mathbf x^{(k+1)}_{GS}\). For \(0<\omega<2\) it can converge (necessary: \(0<\omega<2\)); \(\omega=1\) is Gauss-Seidel; the best \(\omega\) can improve the rate dramatically.

Condition number (basic level)

For nonsingular \(A\) and a matrix norm:

\(\kappa(A)=\lVert A\rVert\,\lVert A^{-1}\rVert\ \ge1.\)

For the \(2\)-norm and symmetric positive definite \(A\), \(\kappa_2=\lambda_{\max}/\lambda_{\min}\). It measures sensitivity to data errors: if \(A\mathbf x=\mathbf b\) and \(A(\mathbf x+\delta\mathbf x)=\mathbf b+\delta\mathbf b\),

\(\frac{\lVert\delta\mathbf x\rVert}{\lVert\mathbf x\rVert}\le\kappa(A)\,\frac{\lVert\delta\mathbf b\rVert}{\lVert\mathbf b\rVert}.\)

  • \(\kappa\) close to \(1\): well-conditioned; \(\kappa\) large: ill-conditioned.
  • The same bound holds for errors in \(A\) (to first order). A small residual \(\mathbf r=\mathbf b-A\hat{\mathbf x}\) does not mean a small error if \(\kappa\) is large: \(\dfrac{\lVert\mathbf e\rVert}{\lVert\mathbf x\rVert}\le\kappa\dfrac{\lVert\mathbf r\rVert}{\lVert\mathbf b\rVert}\).
  • Ill-conditioning is a property of the problem, not of the algorithm. Pivoting cannot cure it.
  • Classic ill-conditioned examples: Hilbert matrices (\(\kappa_\infty(H_3)=748\), growing fast with \(n\)), nearly parallel lines.
  • \(\det A\) small does not by itself mean ill-conditioned (scaling \(A\) changes \(\det\) but not \(\kappa\)).

Formulas and results

  • Back substitution: \(x_i=\frac1{u_{ii}}\big(c_i-\sum_{j>i}u_{ij}x_j\big)\); \(\det A=(-1)^s\prod u_{ii}\).
  • Doolittle: \(l_{ii}=1\); Crout: \(u_{ii}=1\); Cholesky: \(A=LL^T\) (SPD).
  • \(A=LU\) exists if all leading principal minors are nonzero; \(PA=LU\) in general.
  • Jacobi: \(x_i^{(k+1)}=\frac1{a_{ii}}\big(b_i-\sum_{j\ne i}a_{ij}x_j^{(k)}\big)\); \(T_J=-D^{-1}(L+U)\).
  • Gauss-Seidel: new values used at once; \(T_{GS}=-(D+L)^{-1}U\).
  • Converges \(\forall\,\mathbf x^{(0)}\iff\rho(T)<1\); sufficient: \(\lVert T\rVert<1\) or \(A\) strictly diagonally dominant.
  • Consistently ordered: \(\rho(T_{GS})=\rho(T_J)^2\).
  • Gauss \(\approx n^3/3\), Gauss-Jordan \(\approx n^3/2\), per sweep \(n^2\).
  • \(\kappa(A)=\lVert A\rVert\lVert A^{-1}\rVert\ge1\); \(\frac{\lVert\delta x\rVert}{\lVert x\rVert}\le\kappa\frac{\lVert\delta b\rVert}{\lVert b\rVert}\).

Worked examples

Example 1: Gauss elimination

Solve \(x+y+z=6,\ 2x-y+z=3,\ x+2y-z=2\).

Step 1 (pivot \(1\)): \(R_2-2R_1\) gives \((0,-3,-1\mid-9)\) and \(R_3-R_1\) gives \((0,1,-2\mid-4)\). Step 2: \(R_3+\tfrac13R_2\) gives \((0,0,-\tfrac73\mid-7)\), so \(z=3\). Back substitution: \(-3y-3=-9\Rightarrow y=2\); \(x+2+3=6\Rightarrow x=1\). Solution \((1,2,3)\).

Example 2: why pivot

Solve \(0.0001x+y=1,\ x+y=2\) keeping \(3\) significant digits. True solution: \(x=1.0001,\ y=0.9999\).

Without pivoting: multiplier \(10^4\); \(y(1-10^4)=2-10^4\) rounds to \(-10^4y=-10^4\), so \(y=1.00\); then \(x=(1-1.00)/0.0001=0\). Wrong. With partial pivoting (swap rows: \(x+y=2\) first): \(y=\dfrac{1-0.0002}{1-0.0001}\approx1.00\), \(x=2-1.00=1.00\). Correct to 3 digits.

Example 3: Doolittle LU

\(A=\begin{pmatrix}2&1&1\\4&3&3\\8&7&9\end{pmatrix}\). Multipliers: \(l_{21}=2\), \(l_{31}=4\). After step 1 the lower block is \(\begin{pmatrix}1&1\\3&5\end{pmatrix}\), \(l_{32}=3\), \(u_{33}=5-3=2\).

\(L=\begin{pmatrix}1&0&0\\2&1&0\\4&3&1\end{pmatrix},\quad U=\begin{pmatrix}2&1&1\\0&1&1\\0&0&2\end{pmatrix},\quad\det A=2\cdot1\cdot2=4.\)

Check row 3 of \(LU\): \(4(2,1,1)+3(0,1,1)+(0,0,2)=(8,7,9)\). The Crout form has \(u_{ii}=1\): \(L'=\begin{pmatrix}2&0&0\\4&1&0\\8&3&2\end{pmatrix}\), \(U'=\begin{pmatrix}1&\frac12&\frac12\\0&1&1\\0&0&1\end{pmatrix}\).

Example 4: Jacobi versus Gauss-Seidel

Solve \(10x+y+z=15,\ x+10y+z=24,\ x+y+10z=33\) (strictly diagonally dominant; solution \((1,2,3)\)), \(\mathbf x^{(0)}=\mathbf 0\).

Sweep Jacobi Gauss-Seidel
1 \((1.5,\ 2.4,\ 3.3)\) \((1.5,\ 2.25,\ 2.925)\)
2 \((0.93,\ 1.92,\ 2.91)\) \((0.9825,\ 2.00925,\ 3.00083)\)
3 \((1.017,\ 2.016,\ 3.015)\) \((0.99899,\ 2.00002,\ 3.0001)\)
4 \((0.9969,\ 1.9968,\ 2.9967)\) \((0.99999,\ 1.99999,\ 3.0000)\)

Gauss-Seidel step 1: \(x=\frac{15}{10}=1.5\); then \(y=\frac{24-1.5}{10}=2.25\) using the new \(x\); then \(z=\frac{33-1.5-2.25}{10}=2.925\). After \(4\) sweeps GS is accurate to about \(10^{-5}\), Jacobi only to \(3\times10^{-3}\).

Example 5: iteration matrices

\(A=\begin{pmatrix}4&1\\2&5\end{pmatrix}\). \(T_J=-D^{-1}(L+U)=\begin{pmatrix}0&-\frac14\\-\frac25&0\end{pmatrix}\), eigenvalues \(\pm\sqrt{1/10}\), \(\rho(T_J)=0.3162\). \(T_{GS}=-(D+L)^{-1}U=\begin{pmatrix}0&-\frac14\\0&\frac1{10}\end{pmatrix}\), eigenvalues \(0,\ \tfrac1{10}\), \(\rho(T_{GS})=0.1=\rho(T_J)^2\). Both \(<1\); Gauss-Seidel is twice as fast.

Example 6: condition number

\(A=\begin{pmatrix}1&1\\1&1.0001\end{pmatrix}\). \(A^{-1}=10^4\begin{pmatrix}1.0001&-1\\-1&1\end{pmatrix}\). \(\lVert A\rVert_\infty=2.0001\), \(\lVert A^{-1}\rVert_\infty=20001\), so \(\kappa_\infty\approx4\times10^4\).

Effect: \(x+y=2,\ x+1.0001y=2.0001\) gives \((1,1)\). Changing the right side by \(10^{-4}\) to \((2,2)\) gives \((2,0)\): a \(10^{-4}\) change in data moves the solution by \(1\).

Common traps

  • Convergence needs \(\rho(T)<1\); strict diagonal dominance is only sufficient. A system may converge without dominance. The reverse “converges \(\Rightarrow\) dominant” is false.
  • Dominance is about \(\lvert a_{ii}\rvert\) versus the sum of the other entries in the row (absolute values), not versus the largest one.
  • Gauss-Seidel is usually faster, not always. Options saying “always faster” or “never slower” are unsafe; options saying “diverges” for a diagonally dominant system are wrong.
  • Jacobi uses only old values (simultaneous), Gauss-Seidel uses new ones (successive). Exams swap the names.
  • Gauss-Jordan costs more than Gauss elimination (\(n^3/2\) vs \(n^3/3\)).
  • Pivoting does not change the solution and cannot fix an ill-conditioned problem.
  • Doolittle has \(1\)’s on the diagonal of \(L\); Crout has them on \(U\).
  • Rows are used for diagonal dominance, so re-order equations, not variables, when you need to make a system dominant (reordering columns also works but renames the unknowns).
  • \(\kappa(A)\ge1\) always; \(\kappa(I)=1\). Large \(\kappa\) is not the same as small determinant.
  • Cramer’s rule is not a numerical method for large systems.

Previous-year questions

2026-Q59 (worked key: B; unofficial key, flagged “med” confidence)

Question. Gauss-Seidel is applied to a diagonally dominant linear system arising from the discretisation of a PDE. Compared with the Jacobi method, its rate of convergence is: (A) slower (B) faster (C) the same (D) it diverges. Answer: B (faster). Diagonal dominance guarantees convergence of both, so D is out. For consistently ordered (PDE-type) matrices \(\rho(T_{GS})=\rho(T_J)^2\), so Gauss-Seidel needs about half the sweeps. Note from the key: “faster” is the usual textbook statement, not a theorem for every diagonally dominant system.

Quick revision

  • Gauss elimination: forward elimination to \(U\), then back substitution; \(\det=\pm\prod\) pivots.
  • Partial pivoting: swap in the largest \(\lvert a_{ik}\rvert\) in the column; for stability.
  • Gauss-Jordan reduces to \(I\); gives the inverse; \(n^3/2\) vs \(n^3/3\).
  • Doolittle: \(l_{ii}=1\); Crout: \(u_{ii}=1\); Cholesky \(A=LL^T\) for SPD.
  • Jacobi uses old values; Gauss-Seidel uses new values at once.
  • \(T_J=-D^{-1}(L+U)\), \(T_{GS}=-(D+L)^{-1}U\).
  • Converges for all starts iff \(\rho(T)<1\); strict diagonal dominance is sufficient for both.
  • Consistently ordered: \(\rho(T_{GS})=\rho(T_J)^2\), GS about twice as fast.
  • \(\kappa(A)=\lVert A\rVert\lVert A^{-1}\rVert\); relative error \(\le\kappa\times\) relative data error.
  • LU: solve \(Ly=b\) then \(Ux=y\); new right side costs \(n^2\).
