  1. Question 1Easy
    In the Doolittle factorisation \(A=LU\),

    Why

    Doolittle: \(l_{ii}=1\). Crout: \(u_{ii}=1\). \(L=U^T\) is not required (Cholesky has \(A=LL^T\) for SPD matrices).
  2. Question 2Easy
    In Gauss elimination without row interchanges, the pivots turn out to be \(2,\ 3,\ -1\). Then \(\det A=\)

    Why

    \(\det A=\pm\) product of pivots; with no interchanges the sign is \(+\): \(2\cdot3\cdot(-1)=-6\).
  3. Question 3Easy
    Which statement about Gauss elimination with partial pivoting is correct?

    Why

    Partial pivoting exchanges rows only; it does not change the exact solution and does not reduce the cost (\(\approx n^3/3\)). Searching the whole matrix is complete pivoting.
  4. Question 4Easy
    Which matrix is strictly diagonally dominant by rows?

    Why

    D: \(3>2,\ 4>3,\ 5>2\). B has \(2=2\) (only weak). C: \(1<2\). A: \(5=5\) in row 1 and \(1<2\) in row 3.
  5. Question 5Medium
    Solve \(4x+y=6,\ x+3y=7\) by Gauss-Seidel from \((0,0)\). After the first sweep, \(y=\)

    Why

    \(x^{(1)}=6/4=1.5\). Then \(y^{(1)}=(7-1.5)/3=11/6\), using the new \(x\). (\(7/3\) is the Jacobi value, which uses the old \(x=0\).)
  6. Question 6Medium
    The Jacobi or Gauss-Seidel iteration \(\mathbf x^{(k+1)}=T\mathbf x^{(k)}+\mathbf c\) converges for every starting vector if and only if

    Why

    The error is \(T^k\mathbf e^{(0)}\), which tends to \(0\) for all \(\mathbf e^{(0)}\) iff the spectral radius is below \(1\). Diagonal dominance is only sufficient.
  7. Question 7Medium
    For \(A=\begin{pmatrix}4&1\\2&5\end{pmatrix}\), the spectral radius of the Gauss-Seidel iteration matrix \(-(D+L)^{-1}U\) is

    Why

    \(T_{GS}=\begin{pmatrix}0&-1/4\\0&1/10\end{pmatrix}\) with eigenvalues \(0,\,0.1\). (Jacobi has \(\rho=\sqrt{0.1}=0.316\); note \(\rho_{GS}=\rho_J^2\) here.)
  8. Question 8Medium
    Consider: (I) strict diagonal dominance by rows implies that both Jacobi and Gauss-Seidel converge; (II) if Gauss-Seidel converges then Jacobi must converge; (III) Gauss-Seidel uses the newest available components in the same sweep. Which are correct?

    Why

    I and III are correct. II is false: there are matrices (for example \(\begin{pmatrix}2&-1&1\\2&2&2\\-1&-1&2\end{pmatrix}\) has \(\rho(T_J)=\sqrt5/2>1\) but \(\rho(T_{GS})=\tfrac12\)) where Gauss-Seidel converges and Jacobi diverges, and the other way round.
  9. Question 9Medium
    For large \(n\), the number of multiplications and divisions in Gauss elimination for \(A\mathbf x=\mathbf b\) is approximately

    Why

    Exactly \(\tfrac{n^3}3+n^2-\tfrac n3\). Gauss-Jordan needs about \(n^3/2\) (\(n=100\): \(343{,}300\) vs \(505{,}000\)).
  10. Question 10Medium
    Using Doolittle’s method for \(A=\begin{pmatrix}2&1\\6&5\end{pmatrix}\), the entry \(u_{22}\) is

    Why

    \(l_{21}=6/2=3\), \(u_{22}=a_{22}-l_{21}u_{12}=5-3\cdot1=2\).
  11. Question 11Hard
    Assertion (A): In Gauss elimination one chooses the pivot as the largest available entry in the column. Reason (R): A small pivot gives a large multiplier, which magnifies rounding errors.

    Why

    Dividing by a tiny pivot makes \(\lvert m_{ik}\rvert\) huge and swamps the other entries, so the computed answer is wrong (see \(0.0001x+y=1,\ x+y=2\) in 3-digit arithmetic). Pivoting avoids this.
  12. Question 12Hard
    The diagonal matrix \(A=\operatorname{diag}(1,\ 0.001)\) has \(2\)-norm condition number

    Why

    \(\kappa_2=\sigma_{\max}/\sigma_{\min}=1/0.001=1000\). Note \(\det A=0.001\) is small, but scaling \(A\) would change \(\det\) and not \(\kappa\).
  13. Question 13Hard
    Which statement about Jacobi and Gauss-Seidel is correct?

    Why

    For \(A=\begin{pmatrix}1&2&-2\\1&1&1\\2&2&1\end{pmatrix}\), \(T_J\) is nilpotent (\(\rho=0\)) but \(T_{GS}\) has eigenvalues \(0,2,2\) (\(\rho=2\)). For strictly diagonally dominant \(A\) both converge.
