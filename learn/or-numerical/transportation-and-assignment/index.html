Why it matters for the exam

The syllabus names balanced and unbalanced transportation problems and the Hungarian method explicitly, but the papers have asked only one question so far (2026 Q94, on multiple optima after VAM and MODI). Expect conceptual questions: number of basic cells, degeneracy, what a zero opportunity cost means, how to balance a problem, and what the Hungarian steps do. Numerical questions are feasible in two minutes if the method is mechanical.

Core ideas

Transportation problem

\(m\) sources with supplies \(a_i\) and \(n\) destinations with demands \(b_j\); unit cost \(c_{ij}\) from source \(i\) to destination \(j\).

\[\min Z=\sum_{i=1}^{m}\sum_{j=1}^{n}c_{ij}x_{ij}\quad\text{s.t. }\sum_j x_{ij}=a_i,\ \ \sum_i x_{ij}=b_j,\ \ x_{ij}\ge0.\]
  • \(mn\) variables and \(m+n\) equality constraints.
  • Balanced if \(\sum a_i=\sum b_j\). A balanced problem always has a feasible solution (for example the north-west corner solution) and, because the feasible region is bounded, an optimal solution.
  • The constraint matrix has rank \(m+n-1\): one equation is the sum of the others when the problem is balanced. A basic feasible solution therefore has exactly \(m+n-1\) basic variables.
  • Total unimodularity: if all \(a_i,b_j\) are integers, every BFS is integral. Reason: the basic cells form a spanning tree of the bipartite graph of sources and destinations, so the basic equations can be solved leaf by leaf using only additions and subtractions of the \(a_i,b_j\). The same holds for the optimal BFS, so an integral optimum always exists.
  • A set of cells is a valid basis (basic solution) if it has \(m+n-1\) cells and contains no closed loop (no cycle of horizontal and vertical moves through basic cells).
  • Every nonbasic cell closes exactly one loop with the basic cells. The loop has an even number of cells and turns at every cell, and the direction in which it is traced does not matter.

Unbalanced problems

  • Supply exceeds demand (\(\sum a>\sum b\)): add a dummy destination with demand \(\sum a-\sum b\) and costs \(0\). The units “shipped” to the dummy stay at their source.
  • Demand exceeds supply: add a dummy source with supply \(\sum b-\sum a\) and costs \(0\). The dummy shipments are shortages.
  • A prohibited route gets cost \(M\) (huge) in a minimisation problem.
  • Dummy costs may be positive (storage or penalty costs) if the problem says so. Otherwise they are \(0\).
  • A maximisation transportation problem (profits \(p_{ij}\)) is converted to minimisation with \(c_{ij}=p_{\max}-p_{ij}\) (or \(c_{ij}=-p_{ij}\)), and the optimal allocation is read for the original profit. Without converting, the optimality test reverses: optimal when every \(\Delta_{ij}\le0\).
  • Transshipment (statement): shipments may pass through intermediate nodes; every node is treated as both a source and a destination, with the total flow as buffer.

Initial basic feasible solutions

All three give a BFS with \(m+n-1\) cells, unless degenerate.

Method Rule Quality
North-West Corner Rule (NWCR) start at top-left cell, allocate \(\min(\text{supply},\text{demand})\), move right or down ignores costs; usually the worst start
Least Cost Method (LCM, matrix minimum) allocate in the cheapest remaining cell first better than NWCR
Vogel’s Approximation (VAM, penalty) row/column penalty = difference between the two smallest costs; pick the largest penalty and allocate in the cheapest cell of that line usually closest to optimal

After an allocation, strike out the row if its supply is exhausted, the column if its demand is exhausted.

Degeneracy at the start: if a row and a column are exhausted together, strike out only one of them. The other line stays with zero remaining quantity, and the next allocation is \(0\) (written \(\varepsilon\)). This keeps \(m+n-1\) basic cells.

Degeneracy

A BFS is degenerate if it has fewer than \(m+n-1\) positive allocations (a basic cell carries \(0\)). It happens exactly when a partial sum of supplies equals a partial sum of demands over proper subsets of sources and destinations. Treat the zero as a small \(\varepsilon>0\), place it in a cell that does not close a loop with the other basic cells, solve, and let \(\varepsilon\to0\) at the end. Degeneracy can also appear during MODI when two “\(-\)” cells tie for the minimum in \(\theta\): only one leaves, the other stays basic at \(0\).

MODI (u-v) method and optimality test

  1. Start from a BFS with \(m+n-1\) basic cells.
  2. Solve \(u_i+v_j=c_{ij}\) for all basic cells, after setting one multiplier (usually \(u_1\)) equal to \(0\).
  3. For each nonbasic cell compute the opportunity cost (net evaluation) \(\Delta_{ij}=c_{ij}-u_i-v_j\).
  4. Minimisation: the solution is optimal if all \(\Delta_{ij}\ge0\). If some \(\Delta_{ij}<0\), the cell with the most negative \(\Delta_{ij}\) enters.
  5. Draw the closed loop from the entering cell through basic cells with alternating signs, \(+\) at the entering cell. \(\theta=\) minimum allocation in the “\(-\)” cells. Add \(\theta\) to “\(+\)” cells, subtract from “\(-\)” cells; a “\(-\)” cell that reaches \(0\) leaves.
  6. Recompute \(u,v,\Delta\). Each iteration changes the cost by \(\theta\,\Delta_{\text{entering}}\le0\).

Meaning of \(\Delta_{ij}\): the change in total cost per unit shipped on the nonbasic route \((i,j)\) after rebalancing. \(u_i,v_j\) are the dual variables of the transportation LP, and \(\Delta_{ij}\) is the dual slack (reduced cost).

The dual of the balanced problem is

\[\max\ \sum_i a_iu_i+\sum_j b_jv_j\quad\text{s.t. }u_i+v_j\le c_{ij}\ \text{for every cell},\ u_i,v_j\ \text{free}.\]

The multipliers are free because the primal constraints are equalities. MODI makes \(u_i+v_j=c_{ij}\) on the basic cells (complementary slackness) and the optimality test \(\Delta_{ij}\ge0\) is exactly dual feasibility \(u_i+v_j\le c_{ij}\) on the rest. Strong duality then says the optimal cost equals \(\sum a_iu_i+\sum b_jv_j\).

Outcomes at the end:

Final \(\Delta_{ij}\) Meaning
all \(>0\) unique optimal solution
some \(\Delta_{ij}=0\) for a nonbasic cell alternative optimal solutions; entering that cell gives another optimal BFS with the same cost
optimal tableau degenerate an \(\varepsilon\) stays at a basic cell, value \(0\) in the true solution

Geometrically, the feasible solutions form a convex polytope (the transportation polytope). If a nonbasic cell has \(\Delta=0\) and the move has \(\theta>0\), the new BFS is an adjacent vertex with the same cost, so the optimal solutions form an edge (or higher-dimensional face) of the polytope: infinitely many optimal solutions, all convex combinations of the two vertices.

The stepping-stone method evaluates each nonbasic cell by tracing its loop and summing \(\pm c_{ij}\) around it. It gives the same \(\Delta_{ij}\) as MODI.

Assignment problem

\(n\) workers, \(n\) jobs, cost \(c_{ij}\) of worker \(i\) on job \(j\). Choose a one-to-one assignment minimising total cost:

\[\min\sum c_{ij}x_{ij},\quad \sum_j x_{ij}=1,\ \sum_i x_{ij}=1,\ x_{ij}\in\{0,1\}.\]
  • It is a transportation problem with all \(a_i=b_j=1\). Its LP relaxation has integral vertices (the assignment polytope, a Birkhoff polytope), so the \(0\)-\(1\) condition may be replaced by \(x\ge0\).
  • There are \(n!\) feasible assignments.
  • A basic solution has \(2n-1\) basic variables of which only \(n\) equal \(1\); the rest are \(0\), so every BFS is highly degenerate. This is why transportation methods are slow for assignment and the Hungarian method is used instead.
  • Reduction theorem: adding a constant to every entry of a row or a column changes the cost of every assignment by the same amount, so the optimal assignment is unchanged.

Hungarian method

  1. Row reduction: subtract the smallest entry of each row from that row.
  2. Column reduction: subtract the smallest entry of each column from that column. Every row and column now contains at least one zero.
  3. Cover all zeros with the minimum number of horizontal and vertical lines.
  4. If the number of lines equals \(n\), an optimal assignment exists among the zero cells: stop. Otherwise go to step 5.
  5. Let \(k\) be the smallest uncovered entry. Subtract \(k\) from every uncovered entry and add \(k\) to every entry covered twice (at line intersections). Entries covered once are unchanged. Return to step 3.
  6. Make the assignment on zeros: start with rows or columns having a single zero, cross out the rest of that row and column, and repeat. Read the cost from the original matrix.

Facts:

  • Lines needed \(=\) size of the maximum set of independent zeros (König’s theorem). Optimal exactly when it equals \(n\).
  • Several assignments among the zeros means alternative optima.
  • The test is “lines \(=n\)”, not “the matrix has zeros”: a reduced matrix always has zeros, but they may not allow \(n\) independent ones.

Variants of assignment

  • Unbalanced (workers \(\ne\) jobs): add dummy rows or columns of zeros to make a square matrix. A job (or worker) paired with a dummy is left unassigned.
  • Maximisation (profit matrix \(p_{ij}\)): convert to opportunity loss \(\ell_{ij}=p_{\max}-p_{ij}\) and minimise, or minimise \(-p_{ij}\). The optimal profit is read from the original matrix.
  • Prohibited assignment: cost \(M\) (minimisation) so the cell is never chosen.
  • Different workers may do more than one job: duplicate rows.
  • Bottleneck (minimax) assignment: minimise the largest single cost rather than the sum. Find the smallest threshold \(t\) such that the cells with \(c_{ij}\le t\) still admit a complete assignment.

Travelling salesman problem (basic level)

A salesman visits each of \(n\) cities once and returns to the start at minimum total cost (distance matrix \(c_{ij}\), with \(c_{ii}=M\)).

  • Number of distinct tours: \((n-1)!\) for an asymmetric matrix, \(\tfrac12(n-1)!\) if \(c_{ij}=c_{ji}\).
  • Assignment relaxation: solve the assignment problem on the matrix. If the optimal assignment forms one single cycle through all cities, it is an optimal tour. If it forms several subtours, its cost is only a lower bound.
  • To break subtours, branch and bound: forbid one arc of a subtour (set its cost to \(M\)) and re-solve; keep the best tour found; prune branches whose lower bound is worse.
  • Heuristics such as nearest neighbour give a tour (an upper bound) with no optimality guarantee.

Formulas and results

  • Variables \(mn\); constraints \(m+n\); rank \(m+n-1\); basic cells \(m+n-1\); integer data give integral BFS.
  • Balanced iff \(\sum a_i=\sum b_j\). Unbalanced: add a dummy with the difference and zero costs.
  • VAM penalty = second smallest minus smallest cost in a line.
  • MODI: \(u_i+v_j=c_{ij}\) on basic cells; \(\Delta_{ij}=c_{ij}-u_i-v_j\) on nonbasic cells.
  • Optimal (min) iff all \(\Delta_{ij}\ge0\) (that is, \(u_i+v_j\le c_{ij}\)); some \(\Delta=0\) means alternative optima.
  • \(\theta=\min\) allocation of “\(-\)” cells in the loop; cost change \(=\theta\,\Delta\).
  • Degenerate iff fewer than \(m+n-1\) positive allocations (partial supply sum equals partial demand sum).
  • Assignment: \(n!\) solutions; Hungarian optimal iff minimum lines \(=n\).
  • Max to min: \(\ell_{ij}=p_{\max}-p_{ij}\).
  • TSP tours: \((n-1)!\) (asymmetric), \((n-1)!/2\) (symmetric).

Worked examples

Example 1: balanced problem, three starts, MODI

Sources \(S_1,S_2,S_3\) with supplies \(7,9,18\); destinations \(D_1,\dots,D_4\) with demands \(5,8,7,14\) (total \(34\) both sides). Costs:

\(D_1\) \(D_2\) \(D_3\) \(D_4\) Supply
\(S_1\) 19 30 50 10 7
\(S_2\) 70 30 40 60 9
\(S_3\) 40 8 70 20 18
Demand 5 8 7 14

Number of basic cells: \(3+4-1=6\).

NWCR: \(x_{11}=5\), \(x_{12}=2\), \(x_{22}=6\), \(x_{23}=3\), \(x_{33}=4\), \(x_{34}=14\). Cost \(5\cdot19+2\cdot30+6\cdot30+3\cdot40+4\cdot70+14\cdot20=1015\).

LCM: \(x_{14}=7\), \(x_{21}=2\), \(x_{23}=7\), \(x_{31}=3\), \(x_{32}=8\), \(x_{34}=7\). Cost \(814\).

VAM:

Step Row penalties Column penalties Allocation
1 9, 10, 12 21, 22, 10, 10 largest 22 (column 2): \(x_{32}=8\)
2 9, 20, 20 21, -, 10, 10 largest 21 (column 1): \(x_{11}=5\)
3 40, 20, 50 -, -, 10, 10 largest 50 (row 3): \(x_{34}=10\)
4 40, 20, - -, -, 10, 50 largest 50 (column 4): \(x_{14}=2\)
5 -, 20, - -, -, 40, 60 largest 60 (column 4): \(x_{24}=2\)
6 remaining: \(x_{23}=7\)

VAM gives \(x_{11}=5\), \(x_{14}=2\), \(x_{23}=7\), \(x_{24}=2\), \(x_{32}=8\), \(x_{34}=10\) with cost \(5\cdot19+2\cdot10+7\cdot40+2\cdot60+8\cdot8+10\cdot20=779\).

MODI from the VAM solution. With \(u_1=0\): \(v_1=19\), \(v_4=10\), \(u_2=50\), \(u_3=10\), \(v_2=-2\), \(v_3=-10\). Opportunity costs of nonbasic cells:

Cell \(\Delta_{ij}=c_{ij}-u_i-v_j\)
\((1,2)\) \(30-0+2=32\)
\((1,3)\) \(50-0+10=60\)
\((2,1)\) \(70-50-19=1\)
\((2,2)\) \(30-50+2=-18\)
\((3,1)\) \(40-10-19=11\)
\((3,3)\) \(70-10+10=70\)

Only \((2,2)\) is negative: it enters. Loop: \((2,2)\ (+),\ (2,4)\ (-),\ (3,4)\ (+),\ (3,2)\ (-)\). \(\theta=\min(2,8)=2\), so \((2,4)\) leaves. New allocation \(x_{22}=2\), \(x_{34}=12\), \(x_{32}=6\), \(x_{24}=0\) (nonbasic). Cost drops by \(2\cdot18=36\) to \(743\). Recomputing, all \(\Delta_{ij}\ge0\) (the smallest nonbasic value is \(11\)), so \(743\) is the unique optimum. As a dual check, \(u=(0,32,10)\), \(v=(19,-2,8,10)\) satisfy \(u_i+v_j\le c_{ij}\) in every cell and \(\sum a_iu_i+\sum b_jv_j=288+180+95-16+56+140=743\).

The optimal allocation is:

\(x_{11}=5\), \(x_{14}=2\), \(x_{22}=2\), \(x_{23}=7\), \(x_{32}=6\), \(x_{34}=12\).

From NWCR (1015) MODI reaches the same optimum in two pivots: \(1015\to807\to743\). A better start means fewer iterations.

Example 2: unbalanced problem with a dummy and a degenerate start

Supplies \(45,25,30\) (total \(100\)), demands \(30,30,30\) (total \(90\)). Costs:

\(D_1\) \(D_2\) \(D_3\)
\(S_1\) 8 6 10
\(S_2\) 9 12 13
\(S_3\) 14 9 16

Supply exceeds demand by \(10\): add a dummy destination \(D_4\) with demand \(10\) and costs \(0\). Basic cells needed: \(3+4-1=6\).

VAM: the first penalties are rows \(6,9,9\) and columns \(1,3,3,0\). The largest is \(9\), tied between rows 2 and 3; breaking the tie in favour of row 2 gives \(x_{24}=10\) (its cheapest cell is the dummy, cost \(0\)). Then \(x_{32}=30\) exhausts row 3 and column 2 together: strike out only row 3 and keep column 2 with \(0\) demand. The next allocation is \(x_{12}=0\) (the \(\varepsilon\) cell). Then \(x_{21}=15\), \(x_{13}=30\), \(x_{11}=15\). Cost \(825\) with \(6\) basic cells, one of them zero (degenerate).

MODI: \(u=(0,1,3)\), \(v=(8,6,10,-1)\). The only negative opportunity cost is \(\Delta_{34}=0-3+1=-2\). Loop \((3,4)\,(+)\), \((3,2)\,(-)\), \((1,2)\,(+)\), \((1,1)\,(-)\), \((2,1)\,(+)\), \((2,4)\,(-)\); \(\theta=10\) and \((2,4)\) leaves. Cost \(825-2\cdot10=805\). All \(\Delta>0\) at the next step, so \(805\) is the unique optimum:

\(x_{11}=5\), \(x_{12}=10\), \(x_{13}=30\), \(x_{21}=25\), \(x_{32}=20\), and \(x_{34}=10\). The dummy shipment \(x_{34}=10\) means \(S_3\) keeps \(10\) units unshipped.

Example 3: Hungarian method

Minimise the total cost for four workers and four jobs:

\(J_1\) \(J_2\) \(J_3\) \(J_4\)
\(W_1\) 11 7 10 17
\(W_2\) 13 21 7 11
\(W_3\) 13 13 15 13
\(W_4\) 18 10 13 16

Row minima \(7,7,13,10\) give

\(J_1\) \(J_2\) \(J_3\) \(J_4\)
\(W_1\) 4 0 3 10
\(W_2\) 6 14 0 4
\(W_3\) 0 0 2 0
\(W_4\) 8 0 3 6

Column minima are \(0,0,0,0\), so the matrix is unchanged. The zeros can be covered by \(3\) lines (row \(W_2\), row \(W_3\), column \(J_2\)), fewer than \(4\). The smallest uncovered entry is \(3\). Subtract \(3\) from uncovered entries, add \(3\) at the intersections (the cells \((W_2,J_2)\) and \((W_3,J_2)\)):

\(J_1\) \(J_2\) \(J_3\) \(J_4\)
\(W_1\) 1 0 0 7
\(W_2\) 6 17 0 4
\(W_3\) 0 3 2 0
\(W_4\) 5 0 0 3

Again \(3\) lines suffice (row \(W_3\), columns \(J_2\) and \(J_3\)); the smallest uncovered entry is \(1\). Adjusting gives

\(J_1\) \(J_2\) \(J_3\) \(J_4\)
\(W_1\) 0 0 0 6
\(W_2\) 5 17 0 3
\(W_3\) 0 4 3 0
\(W_4\) 4 0 0 2

Now \(4\) lines are needed. Assign: row \(W_2\) has one zero, so \(W_2\to J_3\); row \(W_3\): \(W_3\to J_1\) or \(J_4\), column \(J_4\) has only \(W_3\)’s zero, so \(W_3\to J_4\); then \(W_1\to J_1\); and \(W_4\to J_2\). Cost from the original matrix: \(11+7+13+10=41\). Other valid choices of covering lines lead to the same optimal cost \(41\).

Example 4: unbalanced and maximisation assignment

Unbalanced: three workers and four jobs, costs

\(J_1\) \(J_2\) \(J_3\) \(J_4\)
\(W_1\) 18 24 28 32
\(W_2\) 8 13 17 19
\(W_3\) 10 15 19 22

Add a dummy worker \(W_4\) with zero costs. The Hungarian method gives minimum cost \(50\), with two optimal assignments: \(W_1\to J_1\), \(W_2\to J_2\), \(W_3\to J_3\) (\(18+13+19\)), or \(W_1\to J_1\), \(W_2\to J_3\), \(W_3\to J_2\) (\(18+17+15\)). In both, the dummy takes \(J_4\), so job \(J_4\) is not done.

Maximisation: profit matrix

\(J_1\) \(J_2\) \(J_3\) \(J_4\)
\(W_1\) 16 10 14 11
\(W_2\) 14 11 15 15
\(W_3\) 15 15 13 12
\(W_4\) 13 12 14 15

Subtract each entry from the maximum \(16\) to get the loss matrix with rows \((0,6,2,5)\), \((2,5,1,1)\), \((1,1,3,4)\), \((3,4,2,1)\), then minimise. The optimal assignment is \(W_1\to J_1\), \(W_2\to J_3\), \(W_3\to J_2\), \(W_4\to J_4\). Total loss \(0+1+1+1=3\), and the profit read from the original matrix is \(16+15+15+15=61\) (also \(4\cdot16-3=61\)).

Example 5: travelling salesman

Four cities with symmetric distances \(AB=2\), \(AC=9\), \(AD=10\), \(BC=10\), \(BD=9\), \(CD=2\). Put \(M\) on the diagonal and solve the assignment problem. The optimum is \(A\to B\), \(B\to A\), \(C\to D\), \(D\to C\) with cost \(2+2+2+2=8\), which is two subtours, not a tour. So \(8\) is only a lower bound.

There are \(\tfrac12\cdot3!=3\) distinct tours: \(A\text{-}B\text{-}C\text{-}D\text{-}A\) costs \(2+10+2+10=24\), \(A\text{-}B\text{-}D\text{-}C\text{-}A\) costs \(2+9+2+9=22\), and \(A\text{-}C\text{-}B\text{-}D\text{-}A\) costs \(9+10+9+10=38\). The optimal tour costs \(22\), well above the assignment bound.

Common traps

  • Basic cells are \(m+n-1\), not \(m+n\) and not \(mn\).
  • Adding a dummy row or column of zero costs does not change the optimum cost of the real shipments; the dummy’s quantity is the unshipped surplus or shortage.
  • NWCR ignores costs; it is the fastest but typically the poorest start. VAM usually gives the lowest initial cost; no method guarantees optimality, and LCM or VAM can occasionally equal the optimum.
  • The optimality test for minimisation is \(\Delta_{ij}\ge0\) for every nonbasic cell. For a maximisation problem solved directly with profits, the sign reverses. Mixing the two is a common error.
  • \(\Delta_{ij}=0\) on a nonbasic cell means alternative optima, not degeneracy. Degeneracy is a basic cell at value \(0\) (fewer than \(m+n-1\) positive cells).
  • In a loop the signs alternate starting with \(+\) at the entering cell, and \(\theta\) comes from the “\(-\)” cells only.
  • MODI needs \(m+n-1\) basic cells to fix all \(u_i,v_j\); with fewer, add an \(\varepsilon\) at a cell that does not make a loop.
  • Hungarian: optimal when the minimum number of lines equals \(n\), not when “some zeros exist”. Entries covered twice are increased, entries uncovered are decreased, entries covered once are unchanged.
  • Alternative optima in assignment show up as several possible zero-assignments; the cost is the same.
  • For maximisation assignment, the usual loss matrix subtracts every entry from the largest entry of the whole matrix (a different constant per row would also work, since row constants do not change the optimum). The answer is the original profit, not the loss total.
  • Hungarian applies only to square matrices; unbalanced problems need dummy rows or columns first.
  • TSP: an assignment solution with subtours is not a tour; its cost is a lower bound. Number of tours is \((n-1)!\), not \(n!\).

2026 Q94

An unbalanced transportation problem has a non-degenerate basic feasible solution obtained by VAM. At the MODI optimality test a nonbasic cell has opportunity cost \(0\) (multiple optima). What is the geometric implication? Answer (worked key): B, the optimal solutions lie on an edge (face) of the feasible polytope, so there are infinitely many optimal solutions. The option wording is not available.

Solution: with all \(\Delta_{ij}\ge0\) and one \(\Delta=0\), entering that cell moves along an edge of the transportation polytope to an adjacent BFS with the same cost (the shift \(\theta>0\) because the BFS is non-degenerate). Both vertices are optimal, hence so is every convex combination of them: the whole edge. Balancing with a dummy does not change this.

Quick revision

  • Transportation LP: \(mn\) variables, \(m+n\) constraints, rank \(m+n-1\), so \(m+n-1\) basic cells.
  • Balanced: \(\sum a=\sum b\); if not, add a dummy with zero costs and the difference as quantity.
  • NWCR (ignores cost), LCM (cheapest cell), VAM (largest penalty, usually best).
  • Exhausting a row and a column together creates degeneracy: allocate \(\varepsilon=0\) to keep \(m+n-1\) cells.
  • MODI: \(u_i+v_j=c_{ij}\) on basic cells, \(\Delta_{ij}=c_{ij}-u_i-v_j\); minimisation optimal iff all \(\Delta\ge0\).
  • A zero \(\Delta\) on a nonbasic cell gives alternative optima along an edge of the polytope.
  • Loop: alternating \(+/-\), \(\theta=\) minimum of “\(-\)” cells; cost change \(=\theta\Delta\).
  • Assignment is a transportation problem with all supplies and demands \(1\): \(n!\) assignments, degenerate BFS.
  • Hungarian: row reduce, column reduce, cover zeros; optimal iff lines \(=n\); else subtract \(k\) from uncovered, add \(k\) at double-covered.
  • Unbalanced assignment: dummy rows or columns of zeros. Maximisation: loss \(=p_{\max}-p_{ij}\).
  • TSP: \((n-1)!\) tours; assignment solution with subtours is only a lower bound; branch and bound removes subtours.
