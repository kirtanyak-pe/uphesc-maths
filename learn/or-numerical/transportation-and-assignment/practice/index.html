  1. Question 1Easy
    A balanced transportation problem has \(4\) sources and \(5\) destinations. The number of basic variables in a basic feasible solution is

    Why

    The \(m+n\) constraints have rank \(m+n-1\), so a BFS has \(m+n-1=4+5-1=8\) basic cells. \(9=m+n\) forgets the dependent equation.
  2. Question 2Easy
    In a transportation problem total supply is \(100\) and total demand is \(90\). To balance it we add

    Why

    Surplus supply is absorbed by a dummy destination of demand \(100-90=10\). Zero costs mean the units simply stay at their sources. A cost \(M\) would forbid using the dummy and make the problem infeasible.
  3. Question 3Medium
    Supplies \(30,40\), demands \(20,30,20\) and costs \(\begin{pmatrix}4&6&8\\5&3&7\end{pmatrix}\). The cost of the North-West Corner solution is

    Why

    NWCR: \(x_{11}=20\), \(x_{12}=10\), \(x_{22}=20\), \(x_{23}=20\). Cost \(20\cdot4+10\cdot6+20\cdot3+20\cdot7=340\). (The least-cost start costs \(320\).)
  4. Question 4Easy
    In Vogel’s approximation method, a row has unit costs \(13,\ 9,\ 17,\ 11\). Its penalty is

    Why

    Penalty \(=\) second smallest \(-\) smallest \(=11-9=2\). \(4=13-9\) uses the wrong entry; \(8=17-9\) uses the largest; \(9\) is the smallest cost itself.
  5. Question 5Medium
    In a MODI iteration \(u_1=0\), \(u_2=3\) and \(v_1=5\), \(v_2=2\), \(v_3=6\). For the nonbasic cell \((2,3)\) with unit cost \(c_{23}=7\) the opportunity cost \(\Delta_{23}\) and its meaning are

    Why

    \(\Delta_{23}=c_{23}-u_2-v_3=7-3-6=-2<0\). In a minimisation problem a negative opportunity cost means the current solution can be improved by shipping on that route: each unit changes the cost by \(-2\). Optimality needs all \(\Delta\ge0\).
  6. Question 6Medium
    A transportation problem has \(3\) sources and \(4\) destinations and its initial feasible solution has \(5\) positive allocations placed in independent cells. The solution is

    Why

    A nondegenerate BFS has exactly \(m+n-1=6\) positive cells. With \(5\), one basic cell carries \(0\), so we add \(\varepsilon\) in a cell that does not form a loop. Comparing with \(mn\) is irrelevant.
  7. Question 7Medium
    At the end of the MODI test for a minimisation transportation problem, all opportunity costs are \(\ge0\) and exactly one nonbasic cell has \(\Delta_{ij}=0\). Then

    Why

    All \(\Delta\ge0\) gives optimality. A zero on a nonbasic cell allows an entering move that leaves the cost unchanged, giving an alternative optimal BFS (and every convex combination). Degeneracy concerns basic cells with value \(0\), not nonbasic \(\Delta=0\).
  8. Question 8Hard
    Supplies \(20,30\), demands \(10,25,15\), costs \(\begin{pmatrix}5&4&6\\3&7&2\end{pmatrix}\). The minimum transportation cost is

    Why

    The optimum is found by MODI or by listing the basic solutions (here \(2+3-1=4\) cells). The optimal plan has cost \(175\). The NWCR start has cost \(225\) and is not optimal.
  9. Question 9Medium
    The minimum total cost of the assignment problem with cost matrix \(\begin{pmatrix}10&12&19\\5&10&7\\8&15&11\end{pmatrix}\) is

    Why

    Of the \(3!=6\) assignments the cheapest is \(W_1\to J_2\), \(W_2\to J_3\), \(W_3\to J_1\) with cost \(27\) (the Hungarian method finds it after row and column reduction).
  10. Question 10Medium
    In the Hungarian method for a \(4\times4\) cost matrix, after row and column reduction the zeros can be covered by only \(3\) lines. The next step is to

    Why

    An optimal assignment needs \(n=4\) lines. With \(3\) lines, uncovered entries are decreased by the smallest uncovered entry \(k\) and doubly covered entries are increased by \(k\); singly covered entries are unchanged. This creates a new zero while keeping the existing ones in the covered lines.
  11. Question 11Medium
    The profit matrix of three salesmen and three territories is \(\begin{pmatrix}12&8&15\\10&14&9\\16&11&13\end{pmatrix}\). The maximum total profit is

    Why

    Convert to losses \(16-p_{ij}\) and minimise (or maximise directly). The best assignment gives profit \(45\); the minimum total loss is \(3\), which is \(3\cdot16-45\), not the profit.
  12. Question 12Hard
    Assertion (A): every basic feasible solution of an \(n\times n\) assignment problem is degenerate. Reason (R): a basic feasible solution has \(2n-1\) basic variables, but exactly \(n\) of them equal \(1\).

    Why

    The assignment problem is a transportation problem with \(m=n\) sources and \(n\) destinations, so a BFS has \(2n-1\) basic cells. A feasible assignment has only \(n\) cells equal to \(1\) (the rest of the basic cells are \(0\)), so \(n-1\) basic variables are zero: every BFS is degenerate.
  13. Question 13Medium
    A salesman must visit \(6\) cities once each and return to the start. If the distance matrix is symmetric the number of distinct tours is

    Why

    Fix the start city: \((6-1)!=120\) orderings; each tour is counted twice (once in each direction) when distances are symmetric, so \(120/2=60\). \(120\) is the asymmetric count and \(720=6!\) forgets fixing the start.
