Why it matters for the exam

The syllabus names “Game theory” in one word, and none of the 2019, 2025 or 2026 papers has a question on it. The unit has a few OR slots, so treat it as a cheap topic: it is short, fully mechanical and every question type is predictable. Expect one of these: find a saddle point and the value, apply the \(2\times2\) formula, reduce by dominance, use the graphical method on a \(2\times n\) game, or write the LP of a game. A single-statement question on the minimax theorem is also likely.

Core ideas

Two-person zero-sum game

Two players, A (rows) and B (columns). A has \(m\) pure strategies and B has \(n\). If A plays row \(i\) and B plays column \(j\), B pays A the amount \(a_{ij}\). Whatever one player wins, the other loses, so the sum of the payoffs is zero.

  • The payoff matrix \(A=(a_{ij})\) is written from A’s point of view. A is the maximiser, B is the minimiser. A negative \(a_{ij}\) means A pays B.
  • The game is played once with both players choosing without knowing the other’s choice. Each tries to guard against the worst.

Maximin and minimax (pure strategies)

If A plays row \(i\), the worst that can happen is the row minimum \(\min_j a_{ij}\). A chooses the row with the best worst case:

\[\underline v=\max_i\min_j a_{ij}\quad\text{(maximin, lower value)}.\]

If B plays column \(j\), the worst for B is the column maximum. B chooses

\[\overline v=\min_j\max_i a_{ij}\quad\text{(minimax, upper value)}.\]

Procedure: write the row minima beside the matrix, the column maxima below it, take the maximum of the first and the minimum of the second.

Always \(\underline v\le\overline v\). Reason: for any \(i,j\), \(\min_{j'}a_{ij'}\le a_{ij}\le\max_{i'}a_{i'j}\). Take the maximum over \(i\) on the left and the minimum over \(j\) on the right.

Saddle point

An entry \(a_{rs}\) is a saddle point if it is the smallest in its row and the largest in its column:

\[a_{rj}\ge a_{rs}\ \ (\forall j),\qquad a_{is}\le a_{rs}\ \ (\forall i).\]
  • A saddle point exists if and only if \(\underline v=\overline v\).
  • Then the game is strictly determined. The common number is the value \(v=a_{rs}\), and the pure strategies \(r\) (for A) and \(s\) (for B) are optimal.
  • A game can have several saddle points, but they all have the same value. Moreover, if \((r,s)\) and \((r',s')\) are saddle points then so are \((r,s')\) and \((r',s)\) (the saddle points form a “rectangle” of equal entries). Proof: \(a_{rs}\le a_{rs'}\le a_{r's'}\) and symmetrically \(a_{r's'}\le a_{rs}\), so all four are equal.
  • A fair game has value \(v=0\). A game with \(v=0\) need not have a saddle point.

Mixed strategies and the minimax theorem

When there is no saddle point, A and B randomise. A mixed strategy for A is a probability vector \(x=(x_1,\dots,x_m)\), \(x_i\ge0\), \(\sum x_i=1\). For B it is \(y=(y_1,\dots,y_n)\). The expected payoff to A is

\[E(x,y)=\sum_{i,j}x_i\,a_{ij}\,y_j=x^{T}Ay.\]

Minimax theorem (von Neumann). For every finite matrix game (finite \(m\) and \(n\)) there are mixed strategies \(x^*,y^*\) and a number \(v\) such that

\[\max_x\min_y x^TAy=\min_y\max_x x^TAy=v=E(x^*,y^*).\]
  • \(v\) is the value and is unique. Optimal strategies need not be unique.
  • Pure strategies are special mixed strategies, so \(\underline v\le v\le\overline v\).
  • The finiteness hypothesis matters. For infinite games the theorem can fail without extra conditions.

Test for optimality. \(x^*\) is optimal for A with value \(v\) exactly when every column payoff is at least \(v\):

\[\sum_i x^*_i a_{ij}\ge v\quad\text{for all }j.\]

Similarly \(y^*\) is optimal for B when \(\sum_j a_{ij}y^*_j\le v\) for all \(i\).

Equalising property. If \(y^*\) is optimal for B and \(x^*_i>0\), then row \(i\) gives exactly \(v\) against \(y^*\) (a row in the support of an optimal strategy cannot be better or worse than \(v\)). The same holds for columns. This is what makes the \(2\times2\) formulas work: in the interior of the mixture, both pure strategies give the same payoff.

Games with a \(2\times2\) matrix

Let the matrix be \(\begin{pmatrix}a&b\\c&d\end{pmatrix}\).

When is there no saddle point? Exactly when the two diagonal entries are both larger than both off-diagonal entries, or both smaller:

\[\min(a,d)>\max(b,c)\quad\text{or}\quad\max(a,d)<\min(b,c).\]

In that case the matrix has no saddle point, \(D=a+d-b-c\ne0\) and the optimal strategies are completely mixed.

Formulas (no saddle point). With \(D=a+d-b-c\):

\[x_1=\frac{d-c}{D},\ \ x_2=\frac{a-b}{D},\qquad y_1=\frac{d-b}{D},\ \ y_2=\frac{a-c}{D},\qquad v=\frac{ad-bc}{D}.\]

How to remember (method of oddments). Take the difference of the two entries in each row and each column, ignoring the sign.

  • A plays row 1 with frequency proportional to the difference in row 2 (\(\lvert c-d\rvert\)), and row 2 with frequency proportional to the difference in row 1 (\(\lvert a-b\rvert\)). The two “oddments” are swapped.
  • B plays column 1 in proportion to the difference in column 2, and column 2 in proportion to the difference in column 1.
  • Divide each pair by its sum to get probabilities. Then find \(v\) from \(v=ax_1+cx_2\).

Equalising derivation. If A mixes \((x_1,1-x_1)\), B’s two columns must give the same payoff: \(ax_1+c(1-x_1)=bx_1+d(1-x_1)\). Solving gives \(x_1=(d-c)/D\). The common payoff is \(v\).

Always check for a saddle point first. If there is one, the formulas give nonsense (for example probabilities outside \([0,1]\)).

Dominance

Dominance removes strategies that are never worth playing, shrinking the matrix before solving.

  • Row \(i\) dominates row \(k\) (for the maximiser A) if \(a_{ij}\ge a_{kj}\) for every \(j\). Delete row \(k\).
  • Column \(j\) dominates column \(l\) (for the minimiser B) if \(a_{ij}\le a_{il}\) for every \(i\). Delete the larger column \(l\).
  • Dominance by a convex combination: row \(k\) can be deleted if some average of other rows is entrywise \(\ge\) row \(k\). Likewise column \(l\) can be deleted if an average of other columns is entrywise \(\le\) column \(l\).
  • Deleting a dominated strategy does not change the value. After solving the small game, give the deleted strategies probability \(0\).
  • Repeat: a deletion can create new dominance. After each deletion, check both rows and columns again.
  • Strict dominance never loses an optimal strategy. Weak dominance (some equalities) keeps the value but may drop some optimal strategies.

Example of dominance by an average: in \(\begin{pmatrix}6&0\\0&6\\2&2\end{pmatrix}\) no single row dominates row 3, but the average of rows 1 and 2 is \((3,3)\ge(2,2)\). So row 3 can be deleted, leaving \(\begin{pmatrix}6&0\\0&6\end{pmatrix}\) with value \(3\).

Graphical method

It handles a game with two strategies for one player, that is \(2\times n\) or \(m\times2\).

\(2\times n\) game (A has two rows). Let A play row 1 with probability \(p\) and row 2 with probability \(1-p\), \(0\le p\le1\). Against column \(j\) A gets

\[E_j(p)=a_{1j}\,p+a_{2j}(1-p).\]
  1. Draw the \(n\) lines \(E_j(p)\) on \(0\le p\le1\).
  2. A’s guaranteed payoff is the lower envelope \(\min_jE_j(p)\).
  3. A maximises this: take the highest point of the lower envelope. Its height is \(v\) and its abscissa is \(p^*\).
  4. The two lines meeting at that point (columns \(s,t\)) give a \(2\times2\) game. B plays only those two columns. Solve it by the formulas; all other columns get probability \(0\).
  5. If the highest point is at \(p=0\) or \(p=1\), a pure strategy of A is optimal. If the top of the envelope is a flat segment, every \(p\) on it is optimal.

\(m\times 2\) game (B has two columns). Let B play column 1 with probability \(q\). Against row \(i\) A gets \(E_i(q)=a_{i1}q+a_{i2}(1-q)\). B minimises the upper envelope \(\max_iE_i(q)\): take the lowest point of the upper envelope. The two lines through it identify the two rows A uses.

Linear programming formulation

Every matrix game is an LP, and the two players’ LPs are dual to each other. This is also how the minimax theorem is proved from strong duality.

Step 0 (make the value positive). Add a constant \(k\) to every entry so that all entries are positive, for example \(k=1-\min a_{ij}\). Then \(v'=v+k>0\). Strategies do not change, only the value does.

Player A (maximiser). Maximise \(v\) subject to

\[\sum_i a_{ij}x_i\ge v\ (j=1..n),\quad \sum x_i=1,\ x_i\ge0.\]

Divide by \(v>0\) and put \(X_i=x_i/v\). Then \(\sum X_i=1/v\) and maximising \(v\) means minimising \(\sum X_i\):

\[\min\ \sum_iX_i\quad\text{s.t.}\ \sum_i a_{ij}X_i\ge1\ (\forall j),\ X_i\ge0.\]

Player B (minimiser). Put \(Y_j=y_j/v\):

\[\max\ \sum_jY_j\quad\text{s.t.}\ \sum_j a_{ij}Y_j\le1\ (\forall i),\ Y_j\ge0.\]

Recover the game. \(v'=1/\sum X_i=1/\sum Y_j\) (the two optima are equal by strong duality). Then \(x_i=v'X_i\), \(y_j=v'Y_j\), and the value of the original game is \(v=v'-k\).

Practical tip. If every entry is already positive, no shift is needed (\(k=0\)). B’s LP has “\(\le1\)” constraints with positive right sides, so the origin is a feasible start and the ordinary simplex works with no artificial variables. A’s optimal \(X_i\) are read from the final tableau as the \(Z_j-C_j\) entries under the slack columns (the dual solution). Do not solve A’s LP by Big-M unless you must.

Special games

  • Symmetric (skew-symmetric) game, \(A^T=-A\): the value is \(0\) and both players have the same optimal strategies. Reason: the roles of the two players are interchangeable, so \(v=-v\).
  • Rock-paper-scissors and matching pennies have value \(0\). Optimal strategies are uniform: \((1/3,1/3,1/3)\) and \((1/2,1/2)\).
  • Adding a constant \(k\) to all payoffs adds \(k\) to the value and keeps the optimal strategies. Multiplying all payoffs by \(c>0\) multiplies the value by \(c\) and keeps the strategies.
  • Fair game: \(v=0\). Strictly determined game: a saddle point exists.

Non-zero-sum games: Nash equilibrium and the prisoner’s dilemma

In a non-zero-sum (bimatrix) game each player has their own payoff matrix, and the two payoffs need not add to zero. A pair of strategies is a Nash equilibrium if neither player gains by changing their own strategy alone: each strategy is a best reply to the other.

  • For a zero-sum game a pure Nash equilibrium is exactly a saddle point. With mixed strategies, the optimal pair \((x^*,y^*)\) of the minimax theorem is a Nash equilibrium.
  • Nash’s theorem: every finite bimatrix game has at least one equilibrium, possibly in mixed strategies.
  • A strategy is dominant if it is a best reply to every choice of the opponent. If both players have one, they form the equilibrium.

Prisoner’s dilemma. Two suspects are questioned separately. Each can Confess (C) or Deny (D). The payoffs (years of freedom lost, written as negatives; first number is for player 1) are \((C,C)=(-5,-5)\), \((C,D)=(0,-10)\), \((D,C)=(-10,0)\), \((D,D)=(-1,-1)\). Whatever the other does, Confess is better: against C it gives \(-5>-10\) and against D it gives \(0>-1\). So \((C,C)\) is the unique Nash equilibrium. Yet \((D,D)\) gives both players more, so the equilibrium is not Pareto-optimal: individual rationality leads to a worse joint outcome.

Formulas and results

Item Statement
Lower value \(\underline v=\max_i\min_ja_{ij}\) (A’s maximin)
Upper value \(\overline v=\min_j\max_ia_{ij}\) (B’s minimax)
Basic inequality \(\underline v\le v\le\overline v\) always
Saddle point smallest in its row, largest in its column; exists iff \(\underline v=\overline v\)
Several saddle points all entries equal, and the rectangle of “crossing” entries is also saddle
Minimax theorem finite matrix game: \(\max_x\min_yx^TAy=\min_y\max_xx^TAy\)
Optimality test \(x\) optimal iff \(\sum_ix_ia_{ij}\ge v\ \forall j\); \(y\) optimal iff \(\sum_ja_{ij}y_j\le v\ \forall i\)
\(2\times2\) no saddle \(\min(a,d)>\max(b,c)\) or \(\max(a,d)<\min(b,c)\)
\(2\times2\) formulas \(x_1=\frac{d-c}{D},\ x_2=\frac{a-b}{D},\ y_1=\frac{d-b}{D},\ y_2=\frac{a-c}{D},\ v=\frac{ad-bc}{D}\), \(D=a+d-b-c\)
Row dominance row \(i\) over row \(k\) if \(a_{ij}\ge a_{kj}\) for all \(j\) (delete row \(k\))
Column dominance column \(j\) over column \(l\) if \(a_{ij}\le a_{il}\) for all \(i\) (delete column \(l\))
Graphical method \(2\times n\): highest point of lower envelope; \(m\times2\): lowest point of upper envelope
LP of A \(\min\sum X_i\) s.t. \(\sum_ia_{ij}X_i\ge1\), \(X_i=x_i/v\)
LP of B \(\max\sum Y_j\) s.t. \(\sum_ja_{ij}Y_j\le1\), \(Y_j=y_j/v\)

Worked examples

Example 1: saddle point

Find the value of the game with \(A=\begin{pmatrix}6&2&5\\4&3&6\\8&1&4\end{pmatrix}\).

Row minima: \(2,\ 3,\ 1\). So \(\underline v=\max(2,3,1)=3\). Column maxima: \(8,\ 3,\ 6\). So \(\overline v=\min(8,3,6)=3\).

\(\underline v=\overline v=3\), so there is a saddle point: it is \(a_{22}=3\), the smallest in row 2 and the largest in column 2. The value is \(v=3\); A plays row 2 and B plays column 2. This is the only saddle point.

Example 2: \(2\times2\) game with no saddle point

Solve \(\begin{pmatrix}5&1\\3&4\end{pmatrix}\).

Row minima \(1,3\), so \(\underline v=3\). Column maxima \(5,4\), so \(\overline v=4\). No saddle point (and \(\min(a,d)=4>\max(b,c)=3\)).

\(D=5+4-1-3=5\).

\[x_1=\frac{4-3}{5}=\frac15,\quad x_2=\frac45,\qquad y_1=\frac{4-1}{5}=\frac35,\quad y_2=\frac25,\qquad v=\frac{20-3}{5}=\frac{17}{5}.\]

Check by equalising: against column 1, A gets \(5\cdot\frac15+3\cdot\frac45=\frac{17}{5}\); against column 2, \(1\cdot\frac15+4\cdot\frac45=\frac{17}{5}\). B’s side: row 1 gives \(5\cdot\frac35+1\cdot\frac25=\frac{17}{5}\) and row 2 gives \(3\cdot\frac35+4\cdot\frac25=\frac{17}{5}\). As expected \(3\le\frac{17}{5}\le4\).

Example 3: dominance, then the \(2\times2\) formula

Solve \(A=\begin{pmatrix}1&7&2\\6&2&7\\5&1&6\end{pmatrix}\).

Columns (B minimises): column 3 is \((2,7,6)\) and column 1 is \((1,6,5)\). Every entry of column 1 is smaller, so column 3 is dominated. Delete column 3:

\[\begin{pmatrix}1&7\\6&2\\5&1\end{pmatrix}.\]

Rows (A maximises): row 3 is \((5,1)\) and row 2 is \((6,2)\). Row 2 is larger in both places, so delete row 3:

\[\begin{pmatrix}1&7\\6&2\end{pmatrix}.\]

No saddle point (\(\underline v=2\), \(\overline v=6\)). \(D=1+2-7-6=-10\).

\[x_1=\frac{2-6}{-10}=\frac25,\ x_2=\frac35,\qquad y_1=\frac{2-7}{-10}=\frac12,\ y_2=\frac12,\qquad v=\frac{2-42}{-10}=4.\]

Full strategies: A plays \(\left(\frac25,\frac35,0\right)\), B plays \(\left(\frac12,\frac12,0\right)\), value \(4\). Check on the original matrix: A’s payoffs against the three columns are \(4,4,5\), all \(\ge4\). B’s payoffs against the three rows are \(4,4,3\), all \(\le4\). Both optimality tests pass.

Example 4: graphical method, \(2\times3\)

Solve \(A=\begin{pmatrix}1&3&11\\8&5&2\end{pmatrix}\).

A plays row 1 with probability \(p\). The three lines are

\[E_1=p+8(1-p)=8-7p,\qquad E_2=3p+5(1-p)=5-2p,\qquad E_3=11p+2(1-p)=2+9p.\]

The lower envelope starts at \(2\) (line \(E_3\)), rises along \(E_3\), and turns downward where \(E_3\) meets \(E_2\). That crossing is its highest point:

\[5-2p=2+9p\ \Rightarrow\ p=\frac{3}{11},\qquad v=5-\frac{6}{11}=\frac{49}{11}.\]

At \(p=\frac{3}{11}\) line \(E_1\) has height \(\frac{67}{11}>\frac{49}{11}\), so column 1 is not used. So B mixes columns 2 and 3 only: solve \(\begin{pmatrix}3&11\\5&2\end{pmatrix}\) with \(D=3+2-11-5=-11\):

\[y_2=\frac{2-11}{-11}=\frac{9}{11},\quad y_3=\frac{2}{11},\qquad x_1=\frac{2-5}{-11}=\frac{3}{11},\ x_2=\frac{8}{11}.\]

Answer: A plays \(\left(\frac3{11},\frac8{11}\right)\), B plays \(\left(0,\frac9{11},\frac2{11}\right)\), \(v=\frac{49}{11}\). Check B’s side: row 1 gives \(\frac{27+22}{11}=\frac{49}{11}\) and row 2 gives \(\frac{45+4}{11}=\frac{49}{11}\).

Example 5: graphical method, \(3\times2\)

Solve \(A=\begin{pmatrix}1&8\\3&5\\11&2\end{pmatrix}\).

B plays column 1 with probability \(q\). The three row lines are \(E_1=8-7q\), \(E_2=5-2q\), \(E_3=2+9q\). B minimises the upper envelope \(\max(E_1,E_2,E_3)\).

The envelope falls along \(E_1\) and rises along \(E_3\). They meet where \(8-7q=2+9q\), so \(q=\frac38\) and \(v=8-\frac{21}{8}=\frac{43}{8}\). At \(q=\frac38\), \(E_2=\frac{17}{4}<\frac{43}{8}\), so row 2 is not used.

A uses rows 1 and 3 in the \(2\times2\) game \(\begin{pmatrix}1&8\\11&2\end{pmatrix}\), \(D=-16\):

\[x_1=\frac{2-11}{-16}=\frac{9}{16},\quad x_3=\frac{7}{16},\quad y_1=\frac{2-8}{-16}=\frac38,\quad y_2=\frac58,\quad v=\frac{2-88}{-16}=\frac{43}{8}.\]

Note that \(\underline v=3\), \(\overline v=8\), and \(3\le\frac{43}{8}\le8\).

Example 6: LP formulation with a shift

Solve \(A=\begin{pmatrix}3&-1\\-2&4\end{pmatrix}\) by linear programming.

The smallest entry is \(-2\), so add \(k=3\):

\[A'=\begin{pmatrix}6&2\\1&7\end{pmatrix}.\]

B’s LP: \(\max Y_1+Y_2\) s.t. \(6Y_1+2Y_2\le1\), \(Y_1+7Y_2\le1\), \(Y\ge0\). The origin is feasible. Both constraints are tight at the optimum:

\[6Y_1+2Y_2=1,\ Y_1+7Y_2=1\ \Rightarrow\ Y_1=Y_2=\tfrac18,\qquad \sum Y_j=\tfrac14.\]

So \(v'=1/\tfrac14=4\) and \(y=v'Y=\left(\tfrac12,\tfrac12\right)\). The dual (A’s LP, \(\min X_1+X_2\) s.t. \(6X_1+X_2\ge1\), \(2X_1+7X_2\ge1\)) gives \(X=\left(\tfrac3{20},\tfrac1{10}\right)\), \(\sum X_i=\tfrac14\) again, so \(x=4X=\left(\tfrac35,\tfrac25\right)\).

Value of the original game: \(v=v'-k=4-3=1\). The \(2\times2\) formula agrees: \(D=3+4+1+2=10\), \(v=\frac{12-2}{10}=1\).

Common traps

  • Row minima, then max. A (rows) uses maximin: write row minima, take the largest. B (columns) uses minimax: column maxima, take the smallest. Swapping the two gives the wrong pair of numbers.
  • Saddle point is min of row AND max of column. Entries that are the max of the row and the min of the column are a different (reversed) condition and do not give a saddle point.
  • The minimax theorem does not need a saddle point. It needs only finite strategy sets. A saddle point is the special case where pure strategies are already optimal.
  • Using the \(2\times2\) formula when a saddle point exists. Example: \(\begin{pmatrix}4&2\\6&3\end{pmatrix}\) has the saddle point \(3\), but \(\frac{ad-bc}{D}=\frac{12-12}{-1}=0\) is wrong, and \(x_1=\frac{3-6}{-1}=3\) is not a probability. Check for a saddle point first.
  • Swapping the oddments. Row 1’s probability uses the difference in row 2, \((d-c)\), not \((b-a)\). Row and column roles are different: \(y_1=(d-b)/D\) uses the column-2 difference.
  • Dominance for the column player goes the other way. A deletes the smaller row (the dominated one), B deletes the larger column. Deleting the smaller column of B throws away B’s best option.
  • Weak dominance can drop an optimal strategy, though the value is unaffected.
  • After dominance, rows may become dominated that were not before. Recheck rows and columns repeatedly.
  • Graphical method, wrong envelope. For a \(2\times n\) game A maximises the lower envelope. For an \(m\times2\) game B minimises the upper envelope. Use the highest point of the lower envelope, not the lowest.
  • LP: forgetting the shift. If the matrix has zero or negative entries, add \(k\) first. The final value is \(1/\sum X_i-k\), not \(1/\sum X_i\).
  • Fair is not the same as no saddle point. Fair means \(v=0\). A skew-symmetric matrix always gives a fair game; it may or may not have a saddle point.
  • Value is unique, optimal strategies are not. Do not claim the optimal strategy is unique unless shown.
  • A Nash equilibrium need not be best for the players. In the prisoner’s dilemma the equilibrium \((C,C)\) is worse for both than \((D,D)\). Equilibrium only means that no player gains by deviating alone.

Quick revision

  • Game matrix is written for A (rows, maximiser); B (columns) minimises.
  • \(\underline v=\max_i\min_ja_{ij}\le v\le\overline v=\min_j\max_ia_{ij}\).
  • Saddle point: smallest in its row and largest in its column; exists iff \(\underline v=\overline v\); value is that entry.
  • Several saddle points have equal value and form a rectangle.
  • Von Neumann: every finite matrix game has a value in mixed strategies.
  • \(2\times2\) with \(D=a+d-b-c\): \(x_1=\frac{d-c}{D}\), \(y_1=\frac{d-b}{D}\), \(v=\frac{ad-bc}{D}\).
  • Check for a saddle point before using the formula.
  • Delete dominated rows (smaller) for A and dominated columns (larger) for B; averages count.
  • \(2\times n\): highest point of the lower envelope; \(m\times2\): lowest point of the upper envelope.
  • LP: add \(k\) to make all entries positive; \(X_i=x_i/v\); \(v=1/\sum X_i-k\).
  • B’s LP and A’s LP are dual to each other; B’s LP has the origin as a start.
  • Skew-symmetric game has value \(0\).
  • Non-zero-sum game: Nash equilibrium means each strategy is a best reply to the other; prisoner’s dilemma has the equilibrium (Confess, Confess), worse for both than (Deny, Deny).
