Formula sheet

Every formula and result of the unit. Each topic page explains where they come from.

Linear programming

  • Standard form: \(\max Z=c^Tx\), \(Ax=b\), \(x\ge0\), with slack (\(\le\)), surplus (\(\ge\)) and artificial variables (\(\ge\) and \(=\)).
  • Number of basic solutions \(\le\binom nm\) (\(n\) variables, \(m\) equations). Basic feasible solution \(\Longleftrightarrow\) extreme point.
  • The feasible region is convex; the optimum of a linear objective over a bounded feasible region is at an extreme point; the set of optimal solutions is convex.
  • \(\min Z=-\max(-Z)\).
  • Simplex (\(\max\)): enter the variable with the most negative \(Z_j-C_j\); leave by the minimum ratio \(b_i/a_{ik}\) over \(a_{ik}>0\). Optimal when all \(Z_j-C_j\ge0\).
  • Unbounded: some \(Z_j-C_j<0\) with an entering column \(\le0\). Alternative optima: a nonbasic \(Z_j-C_j=0\) at the optimum. Degenerate: a basic variable equals \(0\) (ties in the ratio test).
  • Big-M: artificial variables get \(-M\) in a maximisation and \(+M\) in a minimisation. Infeasible if an artificial stays positive at the optimum.
  • Two-phase: Phase I minimises \(W=\sum\) artificials; infeasible iff \(\min W>0\). Phase II uses the original objective.
  • Extra variables: \(\le\) one slack; \(\ge\) one surplus and one artificial; \(=\) one artificial.

Duality

  • \(\max c^Tx\), \(Ax\le b\), \(x\ge0\) has dual \(\min b^Ty\), \(A^Ty\ge c\), \(y\ge0\). Dual of the dual is the primal.
  • For a maximisation primal: \(\le\) constraint \(\to y\ge0\); \(\ge\to y\le0\); \(=\to y\) free; \(x\ge0\to\) constraint \(\ge\); \(x\) free \(\to\) constraint \(=\).
  • Weak duality: \(c^Tx\le b^Ty\) for feasible \(x,y\). Strong duality: both optima exist and are equal.
  • Complementary slackness: \(y_i(b_i-a_i^Tx)=0\), \(x_j(a_j^Ty-c_j)=0\).
  • Dual solution from a tableau: \(y^T=c_B^TB^{-1}\), read from the \(Z_j-C_j\) of the slack columns. Shadow price \(y_i^*=\partial Z^*/\partial b_i\).
  • Primal unbounded \(\Rightarrow\) dual infeasible (and symmetrically, dual unbounded \(\Rightarrow\) primal infeasible); both can also be infeasible.
  • Dual simplex: leave on the most negative right-hand side; enter by the minimum of \(\left\lvert (Z_j-C_j)/a_{rj}\right\rvert\) over \(a_{rj}<0\).

Transportation and assignment

  • Balanced: \(\sum a_i=\sum b_j\); otherwise add a dummy row or column of the difference with zero costs.
  • \(mn\) variables, \(m+n\) constraints, rank \(m+n-1\), so a BFS has \(m+n-1\) basic cells (no closed loop). Fewer positive cells means degenerate: add \(\varepsilon\).
  • VAM penalty = second smallest minus smallest cost in a line.
  • MODI: \(u_i+v_j=c_{ij}\) on basic cells; \(\Delta_{ij}=c_{ij}-u_i-v_j\) on the others. Optimal (min) iff all \(\Delta_{ij}\ge0\); a zero \(\Delta\) on a nonbasic cell means alternative optima. Cost change \(=\theta\Delta_{ij}\).
  • Assignment: \(n!\) assignments. Hungarian: row and column reduce, cover zeros with the minimum number of lines; optimal when that number is \(n\); otherwise subtract the smallest uncovered entry from uncovered entries and add it at line crossings.
  • Maximisation: convert with \(\ell_{ij}=p_{\max}-p_{ij}\). Travelling salesman: \((n-1)!\) tours (asymmetric).

Game theory

  • Payoff matrix is written for the row player (maximiser). \(\underline v=\max_i\min_ja_{ij}\le v\le\overline v=\min_j\max_ia_{ij}\).
  • Saddle point: smallest in its row and largest in its column; exists iff \(\underline v=\overline v\). All saddle points have the same value.
  • Minimax theorem: every finite matrix game has a value in mixed strategies.
  • \(2\times2\) without a saddle point, \(D=a+d-b-c\): \(x_1=\frac{d-c}{D}\), \(y_1=\frac{d-b}{D}\), \(v=\frac{ad-bc}{D}\).
  • Dominance: delete the smaller row (A) and the larger column (B); averages count. Graphical: \(2\times n\), highest point of the lower envelope; \(m\times2\), lowest point of the upper envelope.
  • LP form: add \(k\) to make all entries positive, \(\min\sum X_i\) s.t. \(\sum_ia_{ij}X_i\ge1\), \(v=1/\sum X_i-k\). Skew-symmetric matrix \(\Rightarrow v=0\).

Roots of equations

  • Bisection: \(c=\frac{a+b}2\); steps \(n\ge\log_2\frac{b-a}{\varepsilon}\); order \(1\).
  • Regula falsi: \(c=\frac{af(b)-bf(a)}{f(b)-f(a)}\); order \(1\). Secant: order \(\frac{1+\sqrt5}2\approx1.618\).
  • Fixed point \(x_{n+1}=g(x_n)\) converges if \(\lvert g'\rvert\le k<1\) on an interval mapped into itself; \(e_{n+1}\approx g'(\alpha)e_n\) (order \(1\)).
  • Newton-Raphson: \(x_{n+1}=x_n-\frac{f(x_n)}{f'(x_n)}\); \(e_{n+1}\approx\frac{f''(\alpha)}{2f'(\alpha)}e_n^2\) (order \(2\)). Multiple root of multiplicity \(m\): linear, ratio \(1-\frac1m\); fix with \(x-m\frac{f}{f'}\).
  • Special cases: \(\sqrt N\): \(\frac12\left(x+\frac Nx\right)\); \(\frac1N\): \(x(2-Nx)\); \(\sqrt[3]N\): \(\frac13\left(2x+\frac N{x^2}\right)\).

Linear systems

  • Gauss elimination: reduce to upper triangular, back substitute; \(\det A=(-1)^s\prod u_{ii}\); cost \(\approx n^3/3\). Gauss-Jordan \(\approx n^3/2\).
  • \(A=LU\) exists if all leading principal minors are nonzero. Doolittle \(l_{ii}=1\); Crout \(u_{ii}=1\); Cholesky \(A=LL^T\) for symmetric positive definite \(A\).
  • Jacobi: \(x_i^{(k+1)}=\frac1{a_{ii}}\left(b_i-\sum_{j\ne i}a_{ij}x_j^{(k)}\right)\). Gauss-Seidel: same, but use new values at once.
  • Convergence for every start iff \(\rho(T)<1\); sufficient: \(A\) strictly diagonally dominant (or \(\lVert T\rVert<1\)). For consistently ordered matrices \(\rho(T_{GS})=\rho(T_J)^2\).
  • Condition number \(\kappa(A)=\lVert A\rVert\lVert A^{-1}\rVert\ge1\).

Interpolation and finite differences

  • \(\Delta=E-1\), \(\nabla=1-E^{-1}\), \(\delta=E^{1/2}-E^{-1/2}\), \(E=e^{hD}\), \(hD=\ln(1+\Delta)\).
  • A polynomial of degree \(n\) has \(\Delta^ny=a_nn!h^n\) and \(\Delta^{n+1}y=0\).
  • Newton forward: \(y_0+p\Delta y_0+\frac{p(p-1)}{2!}\Delta^2y_0+\cdots\), \(p=\frac{x-x_0}h\). Backward: \(y_n+p\nabla y_n+\frac{p(p+1)}{2!}\nabla^2y_n+\cdots\).
  • Lagrange: \(P(x)=\sum_iy_i\prod_{j\ne i}\frac{x-x_j}{x_i-x_j}\). Divided difference \(f[x_0..x_n]=\sum_i\frac{f(x_i)}{\prod_{j\ne i}(x_i-x_j)}=\frac{f^{(n)}(\xi)}{n!}\).
  • For \(f(x)=\frac1x\): \(f[x_0,\dots,x_n]=\frac{(-1)^n}{x_0x_1\cdots x_n}\), for example \(f[a,b,c,d]=-\frac1{abcd}\).
  • Error: \(\frac{f^{(n+1)}(\xi)}{(n+1)!}\prod(x-x_i)\). Hermite on \(n+1\) nodes: degree \(\le2n+1\), error \(\frac{f^{(2n+2)}(\xi)}{(2n+2)!}\prod(x-x_i)^2\).
  • Natural cubic spline: piecewise cubic, \(C^2\), \(S''=0\) at both ends; \(M_{i-1}+4M_i+M_{i+1}=\frac6{h^2}\delta^2y_i\).

Numerical differentiation and integration

  • \(f'(x_0)=\frac1h\left[\Delta y_0-\frac12\Delta^2y_0+\frac13\Delta^3y_0-\cdots\right]\); \(f''(x_0)=\frac1{h^2}\left[\Delta^2y_0-\Delta^3y_0+\frac{11}{12}\Delta^4y_0-\cdots\right]\).
  • Central: \(f'\approx\frac{f(x+h)-f(x-h)}{2h}\) (error \(O(h^2)\)); \(f''\approx\frac{f(x+h)-2f(x)+f(x-h)}{h^2}\) (error \(O(h^2)\)).
  • Trapezoid: \(\frac h2[y_0+2\sum y_i+y_n]\), error \(-\frac{(b-a)h^2}{12}f''\), exact for degree \(\le1\).
  • Simpson \(\frac13\) (\(n\) even): \(\frac h3[y_0+4\sum_{\text{odd}}+2\sum_{\text{even}}+y_n]\), error \(-\frac{(b-a)h^4}{180}f^{(4)}\), exact for degree \(\le3\).
  • Simpson \(\frac38\) (\(3\mid n\)): error \(-\frac{(b-a)h^4}{80}f^{(4)}\). Weddle (\(6\mid n\)): exact for degree \(\le5\).
  • Gauss-Legendre with \(n\) points is exact for degree \(\le2n-1\); \(2\)-point nodes \(\pm\frac1{\sqrt3}\), weights \(1,1\).
  • Romberg: \(R_{k,j}=\frac{4^jR_{k,j-1}-R_{k-1,j-1}}{4^j-1}\).

ODEs

  • Picard: \(y_{n+1}(x)=y_0+\int_{x_0}^xf(t,y_n(t))\,dt\). Taylor: \(y=y_0+hy_0'+\frac{h^2}{2!}y_0''+\cdots\).
  • Euler: \(y_{n+1}=y_n+hf(x_n,y_n)\); local \(O(h^2)\), global \(O(h)\).
  • Modified Euler (Heun): \(y_{n+1}=y_n+\frac h2[f(x_n,y_n)+f(x_{n+1},y_n+hf(x_n,y_n))]\); local \(O(h^3)\), global \(O(h^2)\).
  • RK4: \(y_{n+1}=y_n+\frac h6(k_1+2k_2+2k_3+k_4)\); local \(O(h^5)\), global \(O(h^4)\). A method of order \(p\) has local error \(O(h^{p+1})\) and global error \(O(h^p)\).
  • Stability on \(y'=\lambda y\): Euler needs \(h<2/\lvert\lambda\rvert\).
  • Milne predictor \(y_{n+1}=y_{n-3}+\frac{4h}3(2f_n-f_{n-1}+2f_{n-2})\), corrector \(y_{n+1}=y_{n-1}+\frac h3(f_{n+1}+4f_n+f_{n-1})\).
