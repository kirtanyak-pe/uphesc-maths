Analytic functions

  1. Question 1Easy
    The principal value of \(i^{\,i}\) is

    Why

    \(i^i=e^{i\operatorname{Log}i}=e^{i\cdot i\pi/2}=e^{-\pi/2}\). All values \(e^{-\pi/2-2\pi k}\) are real.
  2. Question 2Easy
    Which of the following functions is analytic on the whole of \(\mathbb C\)?

    Why

    \(\cosh z=\frac{e^z+e^{-z}}2\) is entire. \(\tan z\) has poles at \(\frac\pi2+n\pi\), \(\operatorname{Log}z\) is not defined (or analytic) on \((-\infty,0]\), and \(\frac1{z^2+1}\) has poles at \(\pm i\).
  3. Question 3Medium
    The analytic function \(f=u+iv\) with \(u=x^2-y^2-y\) and \(f(0)=0\) is

    Why

    \(u_x=2x\), \(u_y=-2y-1\). Milne-Thomson: \(f'(z)=u_x(z,0)-iu_y(z,0)=2z-i(-1)=2z+i\), so \(f=z^2+iz+C\) and \(f(0)=0\) gives \(C=0\). Check: \(\operatorname{Re}(iz)=\operatorname{Re}(ix-y)=-y\).
  4. Question 4Medium
    An analytic function \(f=u+iv\) has \(v=e^x\sin y\) and \(f(0)=1\). Then \(f(z)=\)

    Why

    \(v_y=e^x\cos y\), \(v_x=e^x\sin y\), so \(f'(z)=v_y(z,0)+iv_x(z,0)=e^z\). \(f=e^z+C\) with \(C\) real; \(f(0)=1\) gives \(C=0\). \(\operatorname{Im}(e^z)=e^x\sin y\).
  5. Question 5Medium
    The Cauchy-Riemann equations in polar form (\(z=re^{i\theta}\), \(f=u+iv\), \(r>0\)) are

    Why

    For \(f=z=re^{i\theta}\): \(u=r\cos\theta\), \(v=r\sin\theta\); \(u_r=\cos\theta=\frac1rv_\theta\) and \(v_r=\sin\theta=-\frac1ru_\theta\). The other options fail this test.
  6. Question 6Medium
    Which one of the following statements is true?

    Why

    \(u+iv=x^2-y^2+2ixy=z^2\) is analytic, so \(v=2xy\) is a conjugate of \(u\). \(\Delta(x^2+y^2)=4\ne0\); the only conjugate of \(\ln r\) is \(\theta\), which is not single valued on \(\mathbb C\setminus\{0\}\); \(x+ix\) fails Cauchy-Riemann.
  7. Question 7Medium
    The value of \(a\) for which \(u(x,y)=x^3+axy^2\) is harmonic is

    Why

    \(u_{xx}=6x\) and \(u_{yy}=2ax\). Harmonic means \(6x+2ax=0\) for all \(x\), so \(a=-3\) (then \(u=\operatorname{Re}z^3\)).
  8. Question 8Hard
    For \(z_1=z_2=-1+i\), the value of \(\operatorname{Log}z_1+\operatorname{Log}z_2-\operatorname{Log}(z_1z_2)\) is (Log = principal value)

    Why

    \(\operatorname{Arg}z_1=\frac{3\pi}4\), so \(\operatorname{Log}z_1+\operatorname{Log}z_2=\ln2+\frac{3\pi i}2\). \(z_1z_2=(-1+i)^2=-2i\), \(\operatorname{Log}(-2i)=\ln2-\frac{\pi i}2\). The difference is \(2\pi i\).
  9. Question 9Hard
    The value of \(|\sin(\tfrac\pi2+i)|\) is

    Why

    \(|\sin(x+iy)|^2=\sin^2x+\sinh^2y\). With \(x=\frac\pi2\), \(y=1\): \(1+\sinh^21=\cosh^21\), so the value is \(\cosh1\approx1.543>1\) (\(\sin z\) is unbounded on \(\mathbb C\)).
  10. Question 10Easy
    The function \(e^z\) is periodic with period

    Why

    \(e^{z+2\pi i}=e^ze^{2\pi i}=e^z\). The fundamental period is \(2\pi i\) (not \(\pi i\), since \(e^{\pi i}=-1\)).
  11. Question 11Medium
    Assertion (A): \(f(z)=|z|^2\) is differentiable at \(z=0\) but is not analytic at any point of \(\mathbb C\). Reason (R): For \(f=|z|^2\) the Cauchy-Riemann equations hold only at the origin.

    Why

    \(u=x^2+y^2\), \(v=0\): \(u_x=2x=v_y=0\) and \(u_y=2y=-v_x=0\) only at \((0,0)\). The partials are continuous, so \(f\) is differentiable at \(0\); no disc around any point lies in \(\{0\}\), so \(f\) is analytic nowhere. R gives exactly why A holds.
  12. Question 12Medium
    The number of distinct values of \(1^{\sqrt2}\) is

    Why

    \(1^{\sqrt2}=e^{\sqrt2\log1}=e^{2\pi ik\sqrt2}\), \(k\in\mathbb Z\). Since \(\sqrt2\) is irrational no two values coincide, so there are infinitely many (only \(k=0\) gives \(1\)).
  13. Question 13Easy
    If \(f\) is analytic on a domain \(D\) and \(\operatorname{Re}f\) is constant on \(D\), then

    Why

    \(u_x=u_y=0\), so by Cauchy-Riemann \(v_x=v_y=0\); \(u,v\) are constant on the connected set \(D\) and \(f\) is constant. (Example: \(f=ic\) has \(\operatorname{Im}f=c\), not \(0\).)
