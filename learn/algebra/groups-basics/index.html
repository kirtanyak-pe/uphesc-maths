Why it matters for the exam

Every other group question rests on this topic. Lagrange’s theorem and the order of an element are used in almost every group problem (2025 Q31 tests Lagrange directly). Expect one or two questions per paper that are really “find the order of an element or subgroup, then divide”. The converse of Lagrange and the union of subgroups are favourite false options.

Core ideas

Group axioms

A group is a set \(G\) with an operation \(\cdot\) that is closed, associative, has an identity \(e\), and gives every element an inverse. Consequences you may use without proof:

  • The identity and each inverse are unique.
  • Cancellation holds: \(ab=ac\Rightarrow b=c\) and \(ba=ca\Rightarrow b=c\).
  • \((ab)^{-1}=b^{-1}a^{-1}\) and \((a^{-1})^{-1}=a\).
  • \(G\) is abelian if \(ab=ba\) for all \(a,b\). The order \(\lvert G\rvert\) is the number of elements.

A finite set with an associative, closed operation and cancellation is already a group. An infinite one need not be (\(\mathbb N\) under \(+\) has cancellation but no inverses).

Subgroup tests

\(H\subseteq G\) is a subgroup iff one of these holds:

Test Condition
One-step \(H\neq\varnothing\) and \(ab^{-1}\in H\) for all \(a,b\in H\)
Two-step \(e\in H\), \(H\) closed under products and inverses
Finite test \(H\) finite, nonempty, closed under products (inverses come free)

Useful facts about subgroups:

  • An intersection of subgroups is a subgroup.
  • A union \(H\cup K\) is a subgroup iff \(H\subseteq K\) or \(K\subseteq H\). A group is never a union of two proper subgroups.
  • The cyclic subgroup \(\langle a\rangle=\{a^k:k\in\mathbb Z\}\) is the smallest subgroup containing \(a\).
  • The centre, centralisers and normalisers are subgroups (defined below).
  • \(HK=\{hk\}\) is a subgroup iff \(HK=KH\) (always true if one of them is normal).

Centre, centraliser and normaliser

For \(a\in G\) and a subgroup \(H\le G\):

Name Definition Basic facts
Centre \(Z(G)\) \(\{z: zg=gz\ \forall g\in G\}\) abelian normal subgroup; \(Z(G)=\bigcap_a C_G(a)\); \(G\) abelian iff \(Z(G)=G\)
Centraliser \(C_G(a)\) \(\{g: ga=ag\}\) subgroup containing \(\langle a\rangle\) and \(Z(G)\); \(a\in Z(G)\) iff \(C_G(a)=G\)
Normaliser \(N_G(H)\) \(\{g: gHg^{-1}=H\}\) the largest subgroup of \(G\) in which \(H\) is normal; \(H\trianglelefteq G\) iff \(N_G(H)=G\)
  • Counting conjugates. The conjugacy class of \(a\) has \([G:C_G(a)]\) elements, and \(H\) has \([G:N_G(H)]\) conjugate subgroups. Both divide \(\lvert G\rvert\).
  • \(C_G(a)\le N_G(\langle a\rangle)\), and \(C_G(H)\trianglelefteq N_G(H)\) with \(N_G(H)/C_G(H)\) embedding in \(\operatorname{Aut}(H)\).
  • Examples. In \(S_3\): \(Z(S_3)=\{e\}\), \(C_{S_3}((1\,2\,3))=A_3\) (order \(3\)), so the class of \((1\,2\,3)\) has \(6/3=2\) elements; \(N_{S_3}(\langle(1\,2)\rangle)=\langle(1\,2)\rangle\), so \(\langle(1\,2)\rangle\) has \(3\) conjugates. In \(S_4\): \(N_{S_4}(\langle(1\,2\,3)\rangle)\) has order \(6\), so there are \(24/6=4\) subgroups of order \(3\). In \(D_4\): \(Z(D_4)=\{e,r^2\}\) and \(C_{D_4}(r)=\langle r\rangle\).
  • Trap. \(N_G(H)\supseteq H\) always, but \(N_G(H)=H\) is possible (as for \(\langle(1\,2)\rangle\subset S_3\)); a centraliser \(C_G(a)\) need not be normal in \(G\).

Order of an element

\(o(a)\) is the least \(n\ge1\) with \(a^n=e\) (infinite if none). Rules:

  • \(a^k=e\iff o(a)\mid k\).
  • \(o(a^k)=\dfrac{o(a)}{\gcd(o(a),k)}\).
  • \(o(a)=o(a^{-1})=o(gag^{-1})\), and \(o(ab)=o(ba)\).
  • If \(ab=ba\) and \(\gcd(o(a),o(b))=1\) then \(o(ab)=o(a)\,o(b)\). If \(ab=ba\) in general, \(o(ab)\) divides \(\operatorname{lcm}(o(a),o(b))\).
  • If \(ab\ne ba\) none of this holds. In \(S_3\), \((1\,2)\) and \((1\,3)\) both have order 2 but their product is a 3-cycle.
  • For a finite group, \(o(a)\mid\lvert G\rvert\) (Lagrange).

Cosets and Lagrange’s theorem

For \(H\le G\), the left coset is \(aH=\{ah:h\in H\}\). Facts:

  • \(aH=bH\iff a^{-1}b\in H\).
  • Distinct left cosets are disjoint and every coset has \(\lvert H\rvert\) elements (the map \(h\mapsto ah\) is a bijection).
  • So the cosets partition \(G\).

Lagrange’s theorem. If \(G\) is finite and \(H\le G\) then \(\lvert H\rvert\) divides \(\lvert G\rvert\), and \(\lvert G\rvert=[G:H]\lvert H\rvert\) where the index \([G:H]\) is the number of left cosets.

Proof: the \([G:H]\) cosets each have \(\lvert H\rvert\) elements and cover \(G\) exactly once.

Consequences:

  • \(o(a)\mid\lvert G\rvert\), hence \(a^{\lvert G\rvert}=e\). (Taking \(G=U(n)\) gives Euler’s theorem, taking \(G=\mathbb Z_p^\times\) gives Fermat’s.)
  • A group of prime order \(p\) is cyclic, generated by any non-identity element, and has no subgroups except \(\{e\}\) and itself. So it is simple.
  • Tower law: \(K\le H\le G\Rightarrow [G:K]=[G:H][H:K]\).
  • Product formula: \(\lvert HK\rvert=\dfrac{\lvert H\rvert\lvert K\rvert}{\lvert H\cap K\rvert}\) for subgroups \(H,K\) of a finite group (as a set count, even if \(HK\) is not a subgroup).
  • \(\lvert H\cap K\rvert\) divides \(\gcd(\lvert H\rvert,\lvert K\rvert)\). If \(\gcd=1\), \(H\cap K=\{e\}\).
  • A subgroup of index 2 is normal (left cosets equal right cosets).
  • A group of order \(p^2\) is abelian (proved in the notes on group actions).

The converse of Lagrange is false

If \(d\mid\lvert G\rvert\), \(G\) need not have a subgroup of order \(d\). The standard counterexample is \(A_4\) (order 12): it has no subgroup of order 6.

The converse does hold for:

  • cyclic groups (exactly one subgroup for each divisor),
  • finite abelian groups,
  • groups of prime-power order (\(p\)-groups have a subgroup of every order \(p^k\) dividing \(\lvert G\rvert\)),
  • and for prime power divisors in any finite group (first Sylow theorem).

Standard groups to know

Group Order Facts
\(\mathbb Z_n\) (under \(+\)) \(n\) cyclic; \(o(k)=n/\gcd(n,k)\)
\(U(n)\) (units mod \(n\) under \(\times\)) \(\varphi(n)\) abelian; cyclic iff \(n=1,2,4,p^k,2p^k\) (\(p\) odd prime)
\(D_n\) (symmetries of a regular \(n\)-gon) \(2n\) \(\langle r,s\mid r^n=s^2=e,\ srs=r^{-1}\rangle\); nonabelian for \(n\ge3\)
\(Q_8\) 8 \(\{\pm1,\pm i,\pm j,\pm k\}\), \(i^2=j^2=k^2=ijk=-1\)
\(S_n\) \(n!\) all permutations
\(A_n\) \(n!/2\) even permutations
\(GL_n(F)\) for \(F=\mathbb F_q\): \(\prod_{i=0}^{n-1}(q^n-q^i)\) invertible matrices; centre = scalar matrices
\(SL_n(F)\) \(\lvert GL_n(\mathbb F_q)\rvert/(q-1)\) determinant 1

Notation warning: some books write \(D_{2n}\) for the dihedral group of order \(2n\). Here \(D_4\) has order 8. The exam gives the order when it matters.

Details worth memorising:

  • \(U(n)\). \(U(p)\) is cyclic of order \(p-1\). \(U(8)=\{1,3,5,7\}\cong\mathbb Z_2\times\mathbb Z_2\) is not cyclic (every element squares to 1). \(U(9)\) is cyclic of order 6 (2 is a generator). \(U(12)\cong\mathbb Z_2\times\mathbb Z_2\). \(U(20)\cong\mathbb Z_2\times\mathbb Z_4\). For coprime \(m,n\): \(U(mn)\cong U(m)\times U(n)\).
  • \(D_n\). Elements \(r^k\) (\(n\) rotations) and \(sr^k\) (\(n\) reflections, each of order 2). \(Z(D_n)=\{e\}\) for \(n\) odd; \(Z(D_n)=\{e,r^{n/2}\}\) for \(n\) even. \(D_3\cong S_3\). \(D_4\) has 5 elements of order 2, 2 of order 4.
  • \(Q_8\). One element of order 2 (\(-1\)), six of order 4, \(Z(Q_8)=\{\pm1\}\). Every subgroup is normal although \(Q_8\) is nonabelian. \(D_4\) and \(Q_8\) both have order 8, both nonabelian, but are not isomorphic (different counts of elements of order 2).
  • \(GL_2(\mathbb F_p)\). Order \((p^2-1)(p^2-p)\). \(\lvert GL_2(\mathbb F_2)\rvert=6\) and \(GL_2(\mathbb F_2)\cong S_3\). \(\lvert SL_2(\mathbb F_p)\rvert=p(p^2-1)\).

Group Subgroups Orders of the subgroups

\(\mathbb Z_2\times\mathbb Z_2\) 5 \(1,2,2,2,4\)
\(S_3\) 6 \(1,2,2,2,3,6\)
\(D_4\) 10 \(1,2,2,2,2,2,4,4,4,8\)
\(Q_8\) 6 \(1,2,4,4,4,8\)
\(A_4\) 10 \(1,2,2,2,3,3,3,3,4,12\)
\(\mathbb Z_p\times\mathbb Z_p\) \(p+3\) \(1\), then \(p+1\) of order \(p\), then \(p^2\)
\(\mathbb Z_{p^2}\times\mathbb Z_p\) \(2p+4\) \(1\), \(p+1\) of order \(p\), \(p+1\) of order \(p^2\), \(p^3\)
\(\mathbb Z_2^3\) \(16\) \(1\), \(7\) of order \(2\), \(7\) of order \(4\), \(8\)

Counting in \(\mathbb Z_p\times\mathbb Z_p\). It has \(p^2-1\) elements of order \(p\), and each subgroup of order \(p\) holds \(p-1\) of them, so there are \((p^2-1)/(p-1)=p+1\) subgroups of order \(p\). Adding the trivial group and the whole group gives \(p+3\): \(5\) for \(p=2\), \(6\) for \(p=3\), \(8\) for \(p=5\). For \(\mathbb Z_{p^2}\times\mathbb Z_p\) the elements of order \(p^2\) number \(p^3-p^2\), and each cyclic subgroup of order \(p^2\) has \(p^2-p\) generators, so there are \(p\) cyclic subgroups of order \(p^2\); with the one subgroup \(\mathbb Z_p\times\mathbb Z_p\) of that order this gives \(p+1\) subgroups of order \(p^2\). If \(\gcd(m,n)=1\) then \(\mathbb Z_m\times\mathbb Z_n\cong\mathbb Z_{mn}\) and the count is \(d(mn)\), so \(\mathbb Z_2\times\mathbb Z_3\) has \(4\) subgroups while \(\mathbb Z_2\times\mathbb Z_2\) has \(5\).

Any group of order \(pq\) with primes \(p<q\) is cyclic unless \(p\mid q-1\), in which case there is exactly one nonabelian group as well.

Elementary results used in many problems

  • If \(g^2=e\) for all \(g\in G\) then \(G\) is abelian. (Reason: \(ab=(ab)^{-1}=b^{-1}a^{-1}=ba\).)
  • \(G\) is abelian iff \((ab)^2=a^2b^2\) for all \(a,b\).
  • A group of even order has an element of order 2, and the number of elements of order 2 is odd. (Pair each \(g\ne g^{-1}\) with its inverse; the rest have \(g^2=e\).)
  • If \(G\) has exactly one element of order 2, that element is central.
  • In a finite group the number of elements with \(g\ne g^{-1}\) is even.

Formulas and results

  • \(\lvert G\rvert=[G:H]\,\lvert H\rvert\) (Lagrange); \([G:K]=[G:H][H:K]\).
  • \(\lvert HK\rvert=\lvert H\rvert\lvert K\rvert/\lvert H\cap K\rvert\).
  • \(o(a^k)=o(a)/\gcd(o(a),k)\); \(a^k=e\iff o(a)\mid k\).
  • Commuting elements of coprime orders: \(o(ab)=o(a)o(b)\).
  • \(a^{\lvert G\rvert}=e\) for every \(a\) in a finite group.
  • Prime order \(\Rightarrow\) cyclic and simple. Index 2 \(\Rightarrow\) normal.
  • \(\lvert U(n)\rvert=\varphi(n)=n\prod_{p\mid n}(1-1/p)\).
  • \(\lvert D_n\rvert=2n\), \(\lvert S_n\rvert=n!\), \(\lvert A_n\rvert=n!/2\), \(\lvert Q_8\rvert=8\).
  • \(\lvert GL_n(\mathbb F_q)\rvert=(q^n-1)(q^n-q)\cdots(q^n-q^{n-1})\).
  • \(\mathbb Z_n\) has one subgroup per divisor of \(n\); converse of Lagrange fails in \(A_4\).
  • Subgroup counts: \(\mathbb Z_2^2\): 5, \(S_3\): 6, \(D_4\): 10, \(Q_8\): 6, \(A_4\): 10, \(\mathbb Z_p\times\mathbb Z_p\): \(p+3\), \(\mathbb Z_{p^2}\times\mathbb Z_p\): \(2p+4\).
  • Class size \(=[G:C_G(a)]\); number of conjugates of \(H=[G:N_G(H)]\).

Worked examples

Example 1: Elements of \(U(20)\)

\(U(20)=\{1,3,7,9,11,13,17,19\}\), order \(\varphi(20)=8\). Compute powers:

  • \(3^2=9,\ 3^3=27\equiv7,\ 3^4\equiv21\equiv1\), so \(o(3)=4\).
  • \(9^2=81\equiv1\), so \(o(9)=2\). Likewise \(o(11)=o(19)=2\).
  • \(7\), \(13\), \(17\) all have order 4.

So there are 1 element of order 1, 3 of order 2, 4 of order 4 and none of order 8. \(U(20)\) is not cyclic; it is \(\cong\mathbb Z_2\times\mathbb Z_4\).

Example 2: Elements of order 2 in \(D_6\)

\(D_6\) has order 12. The 6 reflections \(sr^k\) have order 2. Among rotations \(r^k\) (\(o(r^k)=6/\gcd(6,k)\)) only \(k=3\) gives order 2. Total: \(6+1=7\) elements of order 2. (Odd, as it must be for even order.)

Example 3: Smallest group containing subgroups of orders 6 and 8

\(\lvert G\rvert\) is divisible by 6 and 8, hence by \(\operatorname{lcm}(6,8)=24\). So \(\lvert G\rvert\ge24\). The value 24 is attained: \(S_4\) contains \(S_3\) (order 6) and \(D_4\) (order 8).

Example 4: Subgroup or not?

Is \(H=\{A\in GL_2(\mathbb R):\det A\in\mathbb Q^\times\}\) a subgroup? Yes: \(\det(AB^{-1})=\det A/\det B\in\mathbb Q^\times\) (one-step test). Is \(K=\{A:\det A=2\}\)? No: \(I\notin K\) (and \(A,B\in K\Rightarrow\det AB=4\)).

Example 5: Order of a power

\(a\) has order 30. Then \(o(a^{12})=30/\gcd(30,12)=30/6=5\), \(o(a^7)=30\), \(o(a^{15})=2\).

Example 6: Order of a product when elements do not commute

In \(S_3\) take \(a=(1\,2)\), \(b=(1\,3)\). Then \(o(a)=o(b)=2\) but \(ab\) is a 3-cycle, so \(o(ab)=3\), not dividing \(\operatorname{lcm}(2,2)=2\). The rule “\(o(ab)\mid\operatorname{lcm}\)” needs \(ab=ba\).

Common traps

  • Converse of Lagrange. “If \(d\) divides \(\lvert G\rvert\) there is a subgroup of order \(d\)” is false (\(A_4\), order 6). It is true for cyclic groups and for prime-power \(d\) (Sylow).
  • Unions. The union of two subgroups is not a subgroup unless one contains the other. Example: \(2\mathbb Z\cup3\mathbb Z\) is not a subgroup of \(\mathbb Z\) (\(2+3=5\)).
  • \(HK\) as a subgroup. \(HK\) is a subgroup only when \(HK=KH\). Example: \(H=\langle(1\,2)\rangle\), \(K=\langle(1\,3)\rangle\) in \(S_3\): \(\lvert HK\rvert=4\) does not divide 6.
  • Order of product. \(o(ab)=o(a)o(b)\) needs commuting and coprime orders. “\(o(ab)=\operatorname{lcm}(o(a),o(b))\)” is not a general rule even for commuting elements: \(b=a^{-1}\) gives \(ab=e\).
  • \(U(n)\) cyclic? \(U(8)\) and \(U(12)\) are not cyclic. \(U(n)\) for \(n=2^k\) (\(k\ge3\)) is never cyclic.
  • Same order, different group. Order 8 has five groups, order 4 has two. Compare element orders, centre size, abelian or not.
  • Same order, same number of subgroups? \(\mathbb Z_4\times\mathbb Z_2\) has \(8\) subgroups, \(\mathbb Z_2^3\) has \(16\), \(D_4\) has \(10\), \(Q_8\) has \(6\); all have order \(8\).
  • Notation. \(D_4\) (order 8) versus \(D_8\) (order 8 in some books). Check the order, not the name.
  • Cyclic of prime order is simple. The reason is Lagrange: no proper nontrivial subgroups exist. The converse (simple \(\Rightarrow\) prime order) is false: \(A_5\) is simple.

Previous-year questions

2025 Q31 (assertion and reason)

Question. Assertion (A): every cyclic group of prime order is a simple group. Reason (R): the order of a subgroup of a finite group divides the order of the group. Choose the correct option: (A) both correct and R explains A; (B) both correct but R does not explain A; (C) A correct, R not correct; (D) A not correct, R correct.

Answer: A (official key).

Solution. Let \(G\) be cyclic of prime order \(p\). By Lagrange (R, which is true) any subgroup has order dividing \(p\), so it is \(\{e\}\) or \(G\). A normal subgroup is in particular a subgroup, so \(G\) has no proper nontrivial normal subgroup: \(G\) is simple (A is true). The explanation of A is exactly R, so option A.

Quick revision

  • Lagrange: \(\lvert H\rvert\) divides \(\lvert G\rvert\); \(\lvert G\rvert=[G:H]\lvert H\rvert\). Converse fails (\(A_4\) has no subgroup of order 6).
  • \(o(a^k)=o(a)/\gcd(o(a),k)\); \(a^k=e\iff o(a)\mid k\).
  • Prime order means cyclic and simple.
  • Index 2 means normal; \(\lvert HK\rvert=\lvert H\rvert\lvert K\rvert/\lvert H\cap K\rvert\).
  • A union of two subgroups is a subgroup only if one contains the other.
  • \(U(n)\) is cyclic only for \(n=1,2,4,p^k,2p^k\); \(U(8)\) is \(\mathbb Z_2^2\).
  • \(D_n\) has order \(2n\); \(Z(D_n)\) is trivial for odd \(n\) and \(\{e,r^{n/2}\}\) for even \(n\).
  • \(Q_8\): one element of order 2, six of order 4, centre \(\{\pm1\}\), all subgroups normal.
  • \(\lvert GL_2(\mathbb F_p)\rvert=(p^2-1)(p^2-p)\).
  • If \(g^2=e\) for all \(g\) the group is abelian; even order forces an element of order 2.
  • Subgroup counts: \(\mathbb Z_2^2\) 5, \(S_3\) 6, \(D_4\) 10, \(Q_8\) 6, \(A_4\) 10; \(\mathbb Z_p\times\mathbb Z_p\) has \(p+3\) (\(p+1\) of order \(p\)).
  • \(Z(G)\le C_G(a)\le G\); \(H\trianglelefteq N_G(H)\); class size \([G:C_G(a)]\).
