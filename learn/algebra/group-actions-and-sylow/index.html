Why it matters for the exam

Group action, class equation and Sylow theorems are named in the syllabus. In 2026 two questions came from here (Q56 on the class equation of a group of order \(p^3\), Q64 on the conjugation action); in 2019 the centre of a nonabelian group of order \(p^3\) was asked. Sylow counts (“how many Sylow 3-subgroups?”, “is a group of order \(n\) simple?”) are the natural next questions, so learn the counting arguments in full.

Core ideas

Group actions

A (left) action of \(G\) on a set \(X\) is a map \(G\times X\to X\), \((g,x)\mapsto g\cdot x\), with \(e\cdot x=x\) and \(g\cdot(h\cdot x)=(gh)\cdot x\). Equivalently, a homomorphism \(\rho:G\to\operatorname{Sym}(X)\). The action is faithful if \(\ker\rho=\{e\}\).

Definitions for \(x\in X\):

  • Orbit \(Gx=\{g\cdot x:g\in G\}\). Orbits partition \(X\). The action is transitive if there is one orbit.
  • Stabiliser \(G_x=\{g:g\cdot x=x\}\), a subgroup of \(G\).
  • Fixed points \(X^g=\{x:g\cdot x=x\}\) and \(X^G=\{x: g\cdot x=x\ \forall g\}\).
  • \(\ker\rho=\bigcap_x G_x\).

Orbit–stabiliser theorem. \(\lvert Gx\rvert=[G:G_x]\), so for finite \(G\): \(\lvert G\rvert=\lvert Gx\rvert\,\lvert G_x\rvert\). In particular every orbit size divides \(\lvert G\rvert\). Points in the same orbit have conjugate stabilisers: \(G_{g\cdot x}=gG_xg^{-1}\).

Counting orbits (Burnside’s lemma). The number of orbits is \(\dfrac1{\lvert G\rvert}\sum_{g\in G}\lvert X^g\rvert\).

Standard actions.

Action Orbit of \(x\) Stabiliser Kernel
\(G\) on itself by left multiplication all of \(G\) (regular, transitive) \(\{e\}\) \(\{e\}\) (gives Cayley)
\(G\) on cosets \(G/H\) by \(g\cdot aH=gaH\) all of \(G/H\) \(aHa^{-1}\) \(\bigcap_a aHa^{-1}\) (core of \(H\))
\(G\) on itself by conjugation \(g\cdot x=gxg^{-1}\) conjugacy class of \(x\) \(C_G(x)\) (centraliser) \(Z(G)\)
\(G\) on subgroups by conjugation conjugates of \(H\) \(N_G(H)\) (normaliser) intersection of the normalisers of all the subgroups acted on

For the action on cosets, the kernel is the largest normal subgroup of \(G\) contained in \(H\) (the core). This is why a simple group with a subgroup of index \(n>1\) embeds in \(S_n\).

Example of Burnside. Count 2-colourings of the 6 beads of a necklace up to rotation. The rotation by \(k\) steps (\(k=0,\dots,5\)) splits the beads into \(\gcd(6,k)\) cycles and fixes \(2^{\gcd(6,k)}\) colourings: \(64,2,4,8,4,2\). The number of orbits is \(84/6=14\).

Conjugation and the class equation

The orbits of the conjugation action are the conjugacy classes. The class of \(x\) has size

\[\lvert\operatorname{cl}(x)\rvert=[G:C_G(x)],\]

which divides \(\lvert G\rvert\). The class of \(x\) has size 1 iff \(x\in Z(G)\). Consequently:

  • \(G\) is abelian iff all conjugacy classes have size 1 (iff \(Z(G)=G\)). This is 2026 Q64; the options “trivial”, “simple” and “cyclic” are too strong.
  • Class equation. For finite \(G\), choose representatives \(x_1,\dots,x_k\) of the classes of size greater than 1:
\[\lvert G\rvert=\lvert Z(G)\rvert+\sum_{i=1}^k[G:C_G(x_i)].\]

Each term of the sum is a divisor of \(\lvert G\rvert\) larger than 1.

  • Number of conjugacy classes \(=\dfrac1{\lvert G\rvert}\sum_{g}\lvert C_G(g)\rvert\) (Burnside again).
  • A normal subgroup is a union of conjugacy classes, so its order is a sum of class sizes that includes the 1 from the identity. This is the quickest way to find the possible normal subgroups of a small group (in \(S_4\) the normal subgroups have orders \(1\), \(1+3=4\), \(1+3+8=12\) and \(24\)).

Conjugacy classes in \(S_n\). Two permutations are conjugate iff they have the same cycle type, so the number of classes equals the number of partitions of \(n\) (\(3,5,7\) for \(n=3,4,5\)). The class of cycle type \((k^{m_k})\) has size \(n!/\prod_k k^{m_k}m_k!\). Class equations:

Group Class sizes Equation
\(S_3\) \(1,3,2\) \(6=1+3+2\)
\(S_4\) \(1,3,6,6,8\) \(24=1+3+6+6+8\)
\(S_5\) \(1,10,15,20,20,24,30\) \(120=1+10+15+20+20+24+30\)
\(A_4\) \(1,3,4,4\) \(12=1+3+4+4\)
\(A_5\) \(1,12,12,15,20\) \(60=1+12+12+15+20\)
\(D_4\) \(1,1,2,2,2\) \(8=1+1+2+2+2\)
\(Q_8\) \(1,1,2,2,2\) \(8=1+1+2+2+2\)

In \(S_4\) the classes are the identity, transpositions (6), double transpositions (3), 3-cycles (8), 4-cycles (6). In \(A_4\) the eight 3-cycles split into two classes of size 4, because \(C_{A_4}(g)=\langle g\rangle\) has order 3. In \(A_5\) the twenty-four 5-cycles split into two classes of 12, but the 3-cycles (20) and double transpositions (15) do not split.

Classes in dihedral groups. For \(D_n\) with \(n\) odd there are \((n+3)/2\) classes (identity, \((n-1)/2\) rotation pairs \(\{r^k,r^{-k}\}\), one class of all \(n\) reflections). For \(n\) even there are \((n+6)/2\) classes (two central elements \(e,r^{n/2}\), \((n-2)/2\) rotation pairs, two classes of \(n/2\) reflections).

\(p\)-groups and their centres

A \(p\)-group has order \(p^n\), \(n\ge1\).

Theorem. A nontrivial \(p\)-group has nontrivial centre.

Proof from the class equation: every term in the sum is a power of \(p\) greater than 1, so divisible by \(p\). Since \(p\) divides \(\lvert G\rvert\) and the sum, \(p\) divides \(\lvert Z(G)\rvert\), so \(\lvert Z(G)\rvert\ge p\).

Consequences:

  • A group of order \(p^2\) is abelian: \(\lvert Z\rvert\in\{p,p^2\}\); if \(\lvert Z\rvert=p\) then \(G/Z\) has order \(p\), is cyclic, so \(G\) is abelian, contradiction. So \(G\cong\mathbb Z_{p^2}\) or \(\mathbb Z_p\times\mathbb Z_p\).
  • A nonabelian group of order \(p^3\) has \(\lvert Z(G)\rvert=p\) exactly (2019 question): \(\lvert Z\rvert=p^2\) would make \(G/Z\) cyclic, and \(\lvert Z\rvert=p^3\) means abelian. Then \(G/Z\cong\mathbb Z_p\times\mathbb Z_p\).
  • Number of conjugacy classes of a nonabelian group of order \(p^3\) is \(p^2+p-1\). Central elements: \(p\) classes of size 1. Every non-central element has centraliser of order \(p^2\) (it contains \(Z\) and the element, and is a proper subgroup), so its class has size \(p\). The remaining \(p^3-p\) elements give \((p^3-p)/p=p^2-1\) classes of size \(p\). Total \(p+(p^2-1)=p^2+p-1\). For example \(p=2\) gives 5 (\(D_4\), \(Q_8\)), \(p=3\) gives 11 and \(p=5\) gives 29.
  • For an abelian group of order \(p^3\) the number of classes is \(p^3\).
  • Groups of order \(p^3\): exactly five. Abelian: \(\mathbb Z_{p^3}\), \(\mathbb Z_{p^2}\times\mathbb Z_p\), \(\mathbb Z_p^3\). Non-abelian: the Heisenberg group of upper unitriangular \(3\times3\) matrices over \(\mathbb F_p\) (every element has order dividing \(p\) when \(p\) is odd) and the semidirect product \(\mathbb Z_{p^2}\rtimes\mathbb Z_p\) (it has elements of order \(p^2\)). For \(p=2\) the two non-abelian groups are \(D_4\) and \(Q_8\). Order \(27\): three abelian and two non-abelian groups. Tell non-abelian ones apart by element orders: \(D_4\) has five elements of order \(2\), \(Q_8\) has one.
  • A \(p\)-group has normal subgroups of every order \(p^k\) dividing \(\lvert G\rvert\), and every maximal subgroup is normal of index \(p\).
  • If a \(p\)-group acts on a finite set \(X\) then \(\lvert X\rvert\equiv\lvert X^G\rvert\pmod p\) (orbits outside the fixed points have size divisible by \(p\)). In particular if \(p\nmid\lvert X\rvert\) there is a fixed point.

Cauchy’s theorem

If a prime \(p\) divides \(\lvert G\rvert\), then \(G\) has an element of order \(p\) (hence a subgroup of order \(p\)).

Proof idea: let \(\mathbb Z_p\) act by cyclic shift on the set of \(p\)-tuples \((g_1,\dots,g_p)\) with \(g_1\cdots g_p=e\). This set has \(\lvert G\rvert^{p-1}\) elements, divisible by \(p\), so the number of fixed tuples \((g,g,\dots,g)\) with \(g^p=e\) is divisible by \(p\). The identity tuple is one fixed point, so there are at least \(p-1\) more, i.e. elements of order \(p\).

Sylow theorems

Let \(\lvert G\rvert=p^am\) with \(p\nmid m\). A Sylow \(p\)-subgroup is a subgroup of order \(p^a\). Let \(n_p\) be the number of them.

  1. Existence. \(G\) has a Sylow \(p\)-subgroup (indeed subgroups of order \(p^k\) for every \(k\le a\)).
  2. Conjugacy. Any two Sylow \(p\)-subgroups are conjugate; every \(p\)-subgroup lies in some Sylow \(p\)-subgroup.
  3. Counting. \(n_p\equiv1\pmod p\), \(n_p\mid m\) and \(n_p=[G:N_G(P)]\) for any Sylow \(p\)-subgroup \(P\).

Corollaries:

  • \(n_p=1\) iff the Sylow \(p\)-subgroup is normal (iff it is the unique one), and then it is characteristic.
  • If \(n_p=1\) for all \(p\) then \(G\) is the direct product of its Sylow subgroups (nilpotent).
  • Sylow subgroups for different primes intersect trivially. Two distinct Sylow \(p\)-subgroups of prime order \(p\) intersect trivially, so there are exactly \(n_p(p-1)\) elements of order \(p\) in total.
  • If \(N\trianglelefteq G\) and \(P\) is Sylow in \(G\), then \(P\cap N\) is Sylow in \(N\) and \(PN/N\) is Sylow in \(G/N\).
  • \(P\) is normal in its normaliser \(N_G(P)\), so \(P\) is the only Sylow \(p\)-subgroup of \(N_G(P)\).

Known values of \(n_p\):

Group \(n_2\) \(n_3\) \(n_5\)
\(S_3\) 3 1
\(A_4\) 1 4
\(S_4\) 3 4
\(A_5\) 5 10 6
\(S_5\) 15 10 6

For \(S_p\) with \(p\) prime, \(n_p=(p-2)!\) (so \(S_5\): 6). Comparing with \(n_p\equiv1\pmod p\) gives Wilson’s theorem \((p-1)!\equiv-1\pmod p\).

Semidirect products

If \(N\trianglelefteq G\), \(H\le G\), \(N\cap H=\{e\}\) and \(NH=G\), then \(G\) is the semidirect product \(N\rtimes H\). Conversely, a homomorphism \(\varphi:H\to\operatorname{Aut}(N)\) gives a group on \(N\times H\) with \((n,h)(n',h')=(n\,\varphi_h(n'),\,hh')\), of order \(\lvert N\rvert\lvert H\rvert\). The product is direct exactly when \(\varphi\) is trivial.

  • \(D_n=\mathbb Z_n\rtimes\mathbb Z_2\) (the reflection acts by inversion), \(S_3=\mathbb Z_3\rtimes\mathbb Z_2\), \(A_4=V_4\rtimes\mathbb Z_3\), \(S_4=V_4\rtimes S_3\).
  • Order \(pq\), \(p\mid q-1\). A non-abelian group is \(\mathbb Z_q\rtimes\mathbb Z_p\) with \(\varphi\) sending a generator of \(\mathbb Z_p\) to an automorphism \(x\mapsto ax\) of order \(p\) in \(\operatorname{Aut}(\mathbb Z_q)\cong\mathbb Z_{q-1}\). All nontrivial choices of \(\varphi\) give isomorphic groups, so there is exactly one non-abelian group of order \(pq\). For \(21\): \(\mathbb Z_7\rtimes\mathbb Z_3\) with \(x\mapsto2x\) (\(2\) has order \(3\) mod \(7\)).
  • Order \(27\). \(\mathbb Z_9\rtimes\mathbb Z_3\) with \(x\mapsto4x\) (\(4\) has order \(3\) in \(U(9)\)) is non-abelian with elements of order \(9\).
  • Trap: a semidirect product depends on \(\varphi\), and a trivial \(\varphi\) is the direct product, so “\(G=N\rtimes H\)” alone does not say \(G\) is non-abelian.

Applying Sylow: groups of order \(pq\) and small orders

For primes \(p<q\) and \(\lvert G\rvert=pq\): \(n_q\mid p\) and \(n_q\equiv1\pmod q\) with \(p<q\) forces \(n_q=1\). So the Sylow \(q\)-subgroup is normal. If also \(q\not\equiv1\pmod p\) then \(n_p=1\) and \(G\cong\mathbb Z_{pq}\). If \(q\equiv1\pmod p\) there is a nonabelian group as well.

Order Groups
15 \(\mathbb Z_{15}\) only (\(5\not\equiv1\pmod3\))
21 \(\mathbb Z_{21}\) and one nonabelian (\(7\equiv1\pmod3\))
35 \(\mathbb Z_{35}\) only (\(7\not\equiv1\pmod5\))
10 \(\mathbb Z_{10}\), \(D_5\)
6 \(\mathbb Z_6\), \(S_3\)
55 \(\mathbb Z_{55}\) and one nonabelian (\(11\equiv1\pmod5\))

All groups of order \(n\) are cyclic iff \(\gcd(n,\varphi(n))=1\) (for example \(n=15,33,35,51\); not \(n=21\) or \(55\)).

Showing no group of order \(n\) is simple

Strategies, in the order to try them:

  1. Prime-power order. A \(p\)-group of order \(p^k\), \(k\ge2\), has nontrivial centre, so it is not simple.
  2. Some \(n_p=1\). List the divisors \(d\) of \(m\) with \(d\equiv1\pmod p\). If \(1\) is the only one, the Sylow subgroup is normal, proper and nontrivial.
  3. Counting elements. If \(n_p>1\) for two or more primes and the Sylow subgroups have prime order, count \(n_p(p-1)\) elements of order \(p\) for each prime. If the total exceeds \(\lvert G\rvert\), a contradiction. If it uses up all but a few elements, the leftover elements form a single Sylow subgroup, which is normal.
  4. Index argument. If \(G\) is simple with a proper subgroup of index \(n\) (for example \(n=n_p\), as \([G:N_G(P)]=n_p\)), the action on cosets embeds \(G\) in \(S_n\), in fact in \(A_n\) if \(G\) is nonabelian simple. So \(\lvert G\rvert\) divides \(n!/2\) (or \(n!\)). If it does not, \(G\) is not simple.
  5. Burnside’s \(p^aq^b\) theorem. No group of order \(p^aq^b\) (\(p,q\) primes) is simple (apart from \(\mathbb Z_p\)). Quote this when two primes appear. No nonabelian simple group has order below 60, and \(A_5\) (order 60) is the smallest.

Worked table of standard orders:

Order Argument

15, 20, 28, 35, 40, 42, 45, 55, 100 \(n_p=1\) for the largest prime \(p\) (only divisor \(\equiv1\pmod p\) is 1)

30 \(n_5\in\{1,6\}\), \(n_3\in\{1,10\}\). Both \(>1\) gives \(24+20=44>30\) elements, so one is \(1\); then there is a normal \(\mathbb Z_{15}\) and in fact \(n_5=n_3=1\) (Example 5)
36 \(n_3\in\{1,4\}\). If 4, \(G\to S_4\) has nontrivial kernel since \(36\nmid24\)
48 \(n_2\in\{1,3\}\). If 3, \(G\to S_3\) nontrivial kernel
56 \(n_7\in\{1,8\}\). If 8: \(48\) elements of order 7, 8 elements left form the unique Sylow 2-subgroup

Orders \(p^2q\) and \(pqr\). Some Sylow subgroup is always normal, so no such group is simple.

  • \(\lvert G\rvert=p^2q\). If \(n_q>1\) then \(n_q\in\{p,p^2\}\). If \(n_q=p^2\) there are \(p^2(q-1)\) elements of order \(q\) and exactly \(p^2\) elements left, which form the one Sylow \(p\)-subgroup. If \(n_q=p\) then \(q\mid p-1\), so \(q<p\), and \(n_p\mid q\) with \(n_p\equiv1\pmod p\) forces \(n_p=1\). (Orders \(12\), \(18\), \(20\), \(28\), \(45\), \(50\) are of this type.)
  • \(\lvert G\rvert=pqr\) with \(p<q<r\). If no Sylow subgroup were normal then \(n_r=pq\), \(n_q\ge r\), \(n_p\ge q\), and the number of elements of prime order would be at least \(pq(r-1)+r(q-1)+q(p-1)=pqr+(r-1)(q-1)-1\ge pqr\), leaving no room for the identity. So one is normal.

In the index argument, \(G\) acts by conjugation on the \(n_p>1\) Sylow \(p\)-subgroups. The action is transitive and the set has more than one point, so the kernel is a proper normal subgroup. If \(\lvert G\rvert\) does not divide \(n_p!\) (or \(n_p!/2\) when \(G\) would have to be nonabelian simple), the map cannot be injective, so the kernel is also nontrivial.

Formulas and results

  • Orbit–stabiliser: \(\lvert Gx\rvert=[G:G_x]\). Orbits partition \(X\); \(\lvert X\rvert=\sum\lvert\text{orbits}\rvert\).
  • Burnside: number of orbits \(=\frac1{\lvert G\rvert}\sum_g\lvert X^g\rvert\).
  • Conjugation action: orbit \(=\) class, stabiliser \(=C_G(x)\), \(\lvert\operatorname{cl}(x)\rvert=[G:C_G(x)]\), kernel \(=Z(G)\).
  • Class equation: \(\lvert G\rvert=\lvert Z(G)\rvert+\sum[G:C_G(x_i)]\).
  • \(G\) abelian \(\iff\) all classes have size 1.
  • Conjugacy classes in \(S_n\) = cycle types (\(p(n)\) of them); class size \(n!/\prod k^{m_k}m_k!\).
  • \(p\)-group: \(Z(G)\ne1\); order \(p^2\) abelian; nonabelian order \(p^3\) has \(\lvert Z\rvert=p\) and \(p^2+p-1\) classes.
  • \(p\)-group on a set \(X\): \(\lvert X\rvert\equiv\lvert X^G\rvert\pmod p\).
  • Cauchy: \(p\mid\lvert G\rvert\Rightarrow\) element of order \(p\).
  • Sylow: \(\lvert G\rvert=p^am\); \(n_p\equiv1\pmod p\), \(n_p\mid m\), \(n_p=[G:N_G(P)]\); all Sylow \(p\)-subgroups conjugate; \(n_p=1\iff\) normal.
  • Elements of order \(p\) (Sylow of order \(p\)): \(n_p(p-1)\).
  • Simple \(G\) with a subgroup of index \(n>1\): \(G\hookrightarrow A_n\) if nonabelian, so \(\lvert G\rvert\mid n!/2\).
  • Order \(pq\) (\(p<q\)): normal Sylow \(q\); cyclic unless \(p\mid q-1\), when one non-abelian \(\mathbb Z_q\rtimes\mathbb Z_p\) also exists. Burnside: order \(p^aq^b\) is never simple.
  • Five groups of order \(p^3\) (three abelian, Heisenberg, \(\mathbb Z_{p^2}\rtimes\mathbb Z_p\)). Every group of order \(30\) has a normal \(\mathbb Z_{15}\) (four groups). Orders \(p^2q\) and \(pqr\) always have a normal Sylow subgroup.

Worked examples

Example 1: Class size via orbit–stabiliser

\(G=S_6\) acts on itself by conjugation. The class of \((1\,2\,3\,4)\) has cycle type \((4,1,1)\): size \(6!/(4\cdot1^2\cdot2!)=720/8=90\). So \(\lvert C_{S_6}(1\,2\,3\,4)\rvert=720/90=8\). For a class of a different type, \((1\,2\,3\,4)(5\,6)\) in \(S_8\) has size \(8!/(4\cdot2\cdot1^2\cdot2!)=40320/16=2520\).

Example 2: Class equation of a group of order 8

Which of \(8=1+1+2+2+2\), \(8=1+1+1+1+4\), \(8=1+7\) can be the class equation of a nonabelian group of order 8? Class sizes must divide 8, and the 1’s count \(\lvert Z\rvert\).

  • \(1+7\): 7 does not divide 8. Impossible.
  • \(1+1+1+1+4\): \(\lvert Z\rvert=4\), so \(G/Z\) has order 2, cyclic, so \(G\) is abelian. Impossible.
  • \(1+1+2+2+2\): \(\lvert Z\rvert=2\), three classes of size 2. This is \(D_4\) and \(Q_8\).

Example 3: Not simple, order 56

\(56=2^3\cdot7\). \(n_7\mid8\) and \(n_7\equiv1\pmod7\) gives \(n_7\in\{1,8\}\). If \(n_7=8\), the eight Sylow 7-subgroups have order 7, intersect pairwise trivially and contain \(8\cdot6=48\) elements of order 7. Only \(8\) elements remain, and they must make up the (only possible) Sylow 2-subgroup of order 8. Hence \(n_2=1\). Either way a Sylow subgroup is normal and \(G\) is not simple.

Example 4: Not simple, order 36

\(36=4\cdot9\), \(n_3\mid4\), \(n_3\equiv1\pmod3\), so \(n_3\in\{1,4\}\). If \(n_3=4\), conjugation on the four Sylow 3-subgroups gives \(\rho:G\to S_4\). The action is transitive (nontrivial) so the kernel is a proper normal subgroup. Since \(\lvert S_4\rvert=24<36\), \(\rho\) is not injective, so the kernel is nontrivial. Either way \(G\) has a proper nontrivial normal subgroup.

Example 5: Order 30 (element counting)

\(n_5\in\{1,6\}\) and \(n_3\in\{1,10\}\). If \(n_5=6\), there are \(6\cdot4=24\) elements of order 5. If \(n_3=10\), there are \(10\cdot2=20\) elements of order 3. These sets are disjoint, so \(24+20=44>30\), impossible. Hence \(n_5=1\) or \(n_3=1\).

In fact both equal \(1\) and \(G\) has a normal cyclic subgroup of order \(15\). Let \(P\) be the normal Sylow subgroup (of order \(3\) or \(5\)) and \(Q\) a Sylow subgroup for the other prime. Then \(PQ\) is a subgroup of order \(15\), of index \(2\), so normal. Every group of order \(15\) is cyclic, so \(PQ\cong\mathbb Z_{15}\). All Sylow \(3\)- and \(5\)-subgroups of \(G\) lie in this normal subgroup, which has one subgroup of each of those orders, so \(n_3=n_5=1\). Then \(G=\mathbb Z_{15}\rtimes\mathbb Z_2\), and \(\operatorname{Aut}(\mathbb Z_{15})\cong\mathbb Z_2\times\mathbb Z_4\) has four elements of order at most \(2\), giving exactly four groups of order \(30\): \(\mathbb Z_{30}\), \(D_{15}\), \(\mathbb Z_3\times D_5\), \(\mathbb Z_5\times S_3\).

Example 6: Fixed points of a \(p\)-group

A group of order 25 acts on a set with 23 elements. Every orbit has size 1, 5 or 25. Orbits of size 5 or 25 contribute multiples of 5, so the number of fixed points \(f\equiv23\equiv3\pmod5\). The smallest possible \(f\) is 3 (e.g. \(23=3+4\cdot5\)).

Example 7: Possible numbers of Sylow subgroups of a group of order 21

\(21=3\cdot7\). \(n_7\mid3\) and \(n_7\equiv1\pmod7\): \(n_7=1\). \(n_3\mid7\) and \(n_3\equiv1\pmod3\): \(n_3\in\{1,7\}\). The cyclic group has \(n_3=1\); the nonabelian group of order 21 has \(n_3=7\).

Common traps

  • \(n_p\) conditions. \(n_p\equiv1\pmod p\) and \(n_p\mid m\) where \(m\) is the \(p'\)-part. A frequent slip is to require \(n_p\mid\lvert G\rvert\) and miss the restriction to \(m\); another is to accept \(n_p=1+p\) candidates not dividing \(m\).
  • Normal Sylow. \(n_p=1\) is equivalent to normal. Sylow subgroups are not normal in general (\(S_3\) has three Sylow 2-subgroups).
  • Class equation terms. Each noncentral term divides \(\lvert G\rvert\) and is \(>1\). The central part is the number of size-1 classes, which equals \(\lvert Z(G)\rvert\), not 1.
  • Conjugation action with all classes of size 1. This means \(G\) is abelian, not trivial, cyclic, or simple. (2026 Q64.)
  • Number of classes of order \(p^3\). It is \(p^2+p-1\), not \(p^2\), not \(p+2\). For an abelian group of order \(p^3\) it is \(p^3\).
  • Centre of nonabelian order \(p^3\). \(\lvert Z\rvert=p\), never \(p^2\).
  • Converse of Lagrange for Sylow. Sylow’s first theorem gives subgroups of prime-power order dividing \(\lvert G\rvert\), not of every order.
  • Simple needs two properties. Showing a Sylow subgroup is normal proves non-simplicity only if it is proper and nontrivial.
  • \(A_4\) and Sylow. \(n_2(A_4)=1\) (the Klein group), \(n_3(A_4)=4\).
  • Class sizes in \(A_n\). Classes of \(S_n\) can split in \(A_n\). In \(A_4\) the 3-cycles form two classes of size 4, not one of size 8.

2026 Q56

Question. Let \(G\) be a group of order \(p^3\). If the centre has order \(p\), then the number of conjugacy classes is: (A) \(p+2\) (B) \(p^2\) (C) \(p+1\) (D) \(p^3\).

Answer: B (worked key only; unverified, since the question appears to be misprinted).

Solution. The true count is \(p^2+p-1\) (for \(p=2,3,5\) this is \(5\), \(11\), \(29\)), which is not among the options. \(p\) central elements give \(p\) classes. Every non-central element has centraliser of order \(p^2\), so its class has size \(p\), giving \((p^3-p)/p=p^2-1\) further classes. The true value \(p^2+p-1\) matches no option, so the question is misprinted; the worked key marks B, but treat that as unverified and do not rely on it.

2026 Q64

Question. Let \(G\) act on itself by conjugation. If all conjugacy classes have size 1, then \(G\) is: (A) abelian (B) trivial (C) simple (D) cyclic.

Answer: A (worked key).

Solution. The class of \(x\) is \(\{gxg^{-1}\}\). Size 1 means \(gxg^{-1}=x\) for all \(g\), so \(x\) commutes with everything. All classes of size 1 means every element is central, which is exactly “\(G\) is abelian”. Trivial, simple and cyclic are each stronger (\(\mathbb Z_2\times\mathbb Z_2\) is abelian but not cyclic, not trivial, not simple).

2019 (unnumbered, no. 16 in the recovered list)

Question. The size of the centre of a nonabelian group of order \(p^3\) is to be found.

Answer: \(p\) (option b in the source video; the options themselves were not recovered).

Solution. \(Z(G)\ne1\) for a \(p\)-group. If \(\lvert Z\rvert=p^3\) the group is abelian. If \(\lvert Z\rvert=p^2\) then \(G/Z\) has order \(p\), hence cyclic, which forces \(G\) abelian. So \(\lvert Z\rvert=p\).

Quick revision

  • Orbit–stabiliser: \(\lvert Gx\rvert=[G:G_x]\); orbits partition \(X\); Burnside: \(\#\text{orbits}=\frac1{\lvert G\rvert}\sum\lvert X^g\rvert\).
  • Conjugation: orbit = class, stabiliser = centraliser, kernel = centre; class size \(=[G:C_G(x)]\).
  • Class equation: \(\lvert G\rvert=\lvert Z\rvert+\sum[G:C_G(x_i)]\); all classes size 1 means \(G\) abelian.
  • \(S_n\) classes = cycle types; \(S_4\): \(1+3+6+6+8\); \(A_4\): \(1+3+4+4\); \(D_4,Q_8\): \(1+1+2+2+2\).
  • \(p\)-groups have nontrivial centre; order \(p^2\) is abelian; nonabelian order \(p^3\): \(\lvert Z\rvert=p\), \(p^2+p-1\) classes.
  • A \(p\)-group acting on \(X\): \(\lvert X\rvert\equiv\lvert X^G\rvert\pmod p\).
  • Cauchy: \(p\mid\lvert G\rvert\Rightarrow\) element of order \(p\).
  • Sylow: \(n_p\equiv1\pmod p\), \(n_p\mid m\) (\(m=p'\)-part), all conjugate, \(n_p=[G:N_G(P)]\); normal iff \(n_p=1\).
  • \(n_p\) values: \(S_4\): 3,4; \(A_5\): 5,10,6; \(S_5\): 15,10,6.
  • Not simple: \(p\)-group, some \(n_p=1\), element counting, index argument (\(\lvert G\rvert\mid n!/2\)), Burnside \(p^aq^b\).
  • Order \(pq\) (\(p<q\)): normal Sylow \(q\); cyclic unless \(p\mid q-1\).
  • Order \(30\): normal \(\mathbb Z_{15}\), four groups; five groups of order \(p^3\); \(\mathbb Z_q\rtimes\mathbb Z_p\) is the non-abelian group of order \(pq\).
