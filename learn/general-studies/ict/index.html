Why it matters for the exam

ICT gave 4 questions in 2025 (Q12-Q15) and 5 in 2026 (Q2, Q6, Q11, Q15, Q22). Nearly all are definition-level: a number-system conversion, a unit of memory, which tool does what, an input device, what bandwidth or cloud computing means, expansions of internet protocols. These are fast marks if you hold a short list of definitions. A mathematics student can do the conversions in seconds.

Core ideas

Computer organisation

A computer takes input, processes it, stores it and gives output.

  • CPU (processor): the control unit directs operations, the arithmetic logic unit (ALU) does arithmetic and logic, registers hold data being worked on.
  • Memory. Primary (main) memory is fast and directly used by the CPU: RAM is volatile read-write memory; ROM is non-volatile and holds start-up instructions. Cache is a small, very fast memory between CPU and RAM. Secondary memory is permanent and larger: hard disk, SSD, pen drive, optical disc.
  • Input devices send data in: keyboard, mouse, scanner, microphone, webcam, touch screen, joystick, bar code reader, light pen, OCR and OMR readers.
  • Output devices send results out: monitor, printer, speaker, projector, plotter.
  • Some devices do both (touch screen, modem). A refreshable Braille display presents text as raised dots and is an output device, but in the 2025 paper the key treats the bar code reader as the input device among the four options.

Number systems

System Base Digits
Binary 2 0, 1
Octal 8 0-7
Decimal 10 0-9
Hexadecimal 16 0-9, A-F (A is 10, F is 15)

Decimal to binary: divide repeatedly by 2 and read the remainders from bottom to top. Decimal 10 gives remainders 0, 1, 0, 1 from the first to the last division; read upward: 1010. Binary to decimal: add the place values \(2^k\) of the 1 bits. Group bits in threes for octal and in fours for hexadecimal.

Binary addition: \(0+0=0\), \(0+1=1\), \(1+1=10\) (write 0, carry 1).

Units of memory

Unit Size
Bit A single binary digit
Nibble 4 bits
Byte 8 bits
Kilobyte (KB) 1024 bytes
Megabyte (MB) 1024 KB
Gigabyte (GB) 1024 MB
Terabyte (TB) 1024 GB
Petabyte (PB) 1024 TB

Each unit is 1024 times the one below it. A gigabyte is 1024 megabytes, not 1024 kilobytes and not 1024 gigabytes. In strict SI use a gigabyte is 1000 megabytes and the binary unit is called gibibyte (GiB); the exam follows the 1024 convention.

Software

  • System software manages the machine: operating systems (Windows, Linux, Android, macOS), utilities, device drivers, language translators (assembler, compiler, interpreter).
  • Application software serves the user: word processors, spreadsheets, browsers.
  • Open-source software lets users see and modify the code (Linux, LibreOffice).

Office tools and their job

Tool Main purpose
MS Word, Google Docs Word processing: writing and formatting documents
MS Excel Spreadsheet: calculation, data tabulation, formulae and charts
MS PowerPoint Presentations
MS Access Database management: tables, queries, forms
MS Outlook, Gmail Email

When a question asks for the tool used for calculating data, the answer is the spreadsheet. Excel formulas begin with = (for example =SUM(A1:A10)).

Networks and the internet

Network Meaning
PAN Personal area network (a few metres: Bluetooth)
LAN Local area network (a building or campus)
MAN Metropolitan area network (a city)
WAN Wide area network (countries; the internet is the largest)

Topologies: bus, star, ring, mesh, tree. Devices: a switch connects devices within a LAN, a router connects different networks, a modem converts between digital and analogue signals, a gateway joins networks that use different protocols, a repeater regenerates a weakening signal.

The World Wide Web (invented by Tim Berners-Lee at CERN around 1989-91) is the collection of pages reached by browsers; the internet is the network that carries it. An ISP is an internet service provider. A URL gives the protocol, domain name and path.

Protocols and their expansions

Short form Expansion and function
TCP Transmission Control Protocol: reliable, ordered delivery of data
UDP User Datagram Protocol: fast, connectionless, no delivery guarantee
IP Internet Protocol: addressing and routing of packets (IPv4 has 32-bit addresses, IPv6 has 128-bit)
HTTP Hypertext Transfer Protocol: transfer of web pages (HTTPS adds encryption)
FTP File Transfer Protocol: moving files between machines
SMTP Simple Mail Transfer Protocol: sending email
POP3 and IMAP Retrieving email from a server
DNS Domain Name System: converts a domain name to an IP address
DHCP Assigns IP addresses automatically

Standard ports worth knowing: HTTP 80, HTTPS 443, FTP 21, SMTP 25, DNS 53.

Bandwidth, latency, digital divide, cloud

  • Bandwidth is the maximum rate of data transfer of a communication channel, measured in bits per second. It is not the number of users, the width of a cable or the storage of a server. Latency is the delay of a transfer.
  • Digital divide is the unequal access to digital technologies across populations (by income, region, gender, age, skill). It is not about analogue versus digital signals, or wired versus wireless.
  • Cloud computing is on-demand network access to a shared pool of computing resources (servers, storage, applications) that can be provisioned quickly. The service models are IaaS (infrastructure), PaaS (platform) and SaaS (software); deployment models are public, private, hybrid and community. It does not mean exclusive hardware owned by each user or data held only on local computers.
  • ICT-driven knowledge management in universities rests on distributed digital repositories connected through network infrastructure: content is stored digitally, indexed, and shared over networks, instead of being locked in one offline catalogue.

Emerging technologies

  • Artificial intelligence (AI): machines performing tasks that normally need human intelligence. Machine learning (ML) is the part of AI in which a system learns patterns from data instead of being given explicit rules; deep learning uses many-layered neural networks. Generative AI creates new text, images or code from a prompt. A bias in the training data produces a bias in the output.
  • Internet of Things (IoT): everyday objects with sensors and network connections that send and receive data (a smart meter, a fitness band).
  • Big data: data too large or varied for ordinary tools, described by volume, velocity and variety.
  • Blockchain: a shared ledger in which records are grouped into blocks linked by cryptographic hashes, so an earlier entry cannot be changed without breaking the chain. It underlies cryptocurrencies but is not the same thing as one.
  • Augmented and virtual reality: AR overlays digital content on the real view; VR replaces the view with a simulated world.
  • 5G: the fifth generation of mobile networks, with higher speed and lower latency; India launched it on 1 October 2022. Quantum computing uses qubits, which can be in a superposition of 0 and 1.

Security and law

  • Threats: virus (attaches to files), worm (spreads by itself), trojan (disguised as useful software), ransomware (encrypts files for payment), phishing (fake messages that steal credentials), spoofing.
  • Defences: firewall, antivirus, encryption, two-factor authentication, digital signature, regular backups.
  • The Information Technology Act, 2000 is India’s main cyber law; CERT-In is the national agency for cyber incidents; the Digital Personal Data Protection Act was passed in 2023. The national cyber crime helpline is 1930. Under the IT Act, section 43 covers damage to computer systems, section 66 computer-related offences such as hacking, section 66C identity theft, section 66D cheating by impersonation and section 67 publishing obscene material. Section 66A was struck down by the Supreme Court in Shreya Singhal v. Union of India (2015). Encryption in one line: symmetric encryption uses one shared key; asymmetric uses a public and private key pair, and a digital signature is made with the sender’s private key and checked with the public key. HTTPS is HTTP over a secure layer.

ICT in education and governance

Digital India was launched on 1 July 2015. DigiLocker (2015), UPI (2016, by NPCI) and Aadhaar (UIDAI, 2009) are its building blocks. For education: SWAYAM, e-PG Pathshala, NDLI, Shodhganga (see the teaching and research topic). E-governance means delivery of government services through electronic means.

  • For education: DIKSHA (2017) is the national platform of school e-content; PM eVidya (2020) brings together digital, radio and television learning; SWAYAM serves school and higher-education courses; the Academic Bank of Credits stores credits digitally.
  • For governance: UMANG (2017) is a single mobile app to many central and state services; DigiLocker stores verified documents; GeM (2016) is the government’s public-procurement marketplace; Common Service Centres (2006) deliver services in villages; BharatNet is the project to take optical-fibre broadband to gram panchayats; UPI is the instant payment system; the National Informatics Centre (NIC) runs government IT infrastructure.
  • Digital divide measures: it is closed by three things together: access (devices and connectivity), affordability and skill. A scheme that gives devices but no connectivity or training narrows it only partly.

Formulas and results

  • \(1\text{ byte} = 8\text{ bits}\); \(1\text{ KB} = 2^{10}\) bytes; \(1\text{ MB} = 2^{10}\) KB; \(1\text{ GB} = 2^{10}\) MB.
  • Decimal \(10 = 1010_2\); decimal \(25 = 11001_2\); \(2\text{F}_{16} = 47\).
  • Binary place values: \(1, 2, 4, 8, 16, 32, 64, 128\).
  • IPv4: 32 bits (four bytes); IPv6: 128 bits.
  • Excel: spreadsheet for calculation; Access: database; PowerPoint: slides; Word: documents.
  • TCP reliable transport; HTTP hypertext transfer; FTP file transfer; DNS name resolution.
  • Bandwidth: maximum data rate of a channel.
  • Digital divide: unequal access to digital technology.

Worked examples

Example 1: Decimal to binary

Convert 10 to binary. \(10 = 8 + 2 = 1\cdot 2^3 + 0\cdot 2^2 + 1\cdot 2^1 + 0\cdot 2^0\), so \(10 = 1010_2\). Check the neighbouring options: 0110 is 6, 1001 is 9, 1100 is 12.

Example 2: Binary arithmetic

Add \(1011_2\) and \(110_2\). \(1011_2 = 11\) and \(110_2 = 6\), so the sum is 17, which is \(10001_2\). Column addition: bit 0: \(1+0=1\); bit 1: \(1+1=0\) carry 1; bit 2: \(0+1+1=0\) carry 1; bit 3: \(1+0+1=0\) carry 1; carry out gives the leading 1. Result \(10001\).

Example 3: Hexadecimal to decimal

\(\text{2F}_{16} = 2\cdot 16 + 15 = 47\). Also \(\text{A}_{16} = 10\), so \(\text{1A}_{16} = 26\).

Example 4: Memory arithmetic

How many megabytes in 2 GB? \(2 \times 1024 = 2048\) MB. How many bytes in 1 MB? \(1024 \times 1024 = 1\,048\,576 = 2^{20}\).

Example 5: Match the internet terms

Match FTP, HTTP, TCP, DNS with: a reliable transport protocol, b hypertext data transfer, c file transfer mechanism, d domain name resolution system. FTP with c, HTTP with b, TCP with a, DNS with d.

Example 6: Choose the tool

“Calculate the total marks of 500 students and plot a chart.” Calculation and charts belong to a spreadsheet: MS Excel. A database (Access) stores and queries records; a presentation tool shows slides.

Example 7: Binary to hexadecimal

Convert \(10110110_2\). Group the bits in fours from the right: \(1011\) and \(0110\). Then \(1011 = 11 = \text{B}\) and \(0110 = 6\), so the number is \(\text{B6}_{16}\), which is \(11\times 16 + 6 = 182\) in decimal.

Common traps

  • Bytes, kilobytes, megabytes. The unit just below a gigabyte is the megabyte.
  • Excel versus Access. Excel calculates; Access is a database. Google Docs is word processing.
  • Input versus output. Monitors, projectors and printers are output. A bar code reader, scanner and keyboard are input.
  • Bandwidth. It is a rate, not a count of users, cable thickness or storage.
  • Digital divide. It is about inequality of access, not signal types.
  • Cloud. It is shared and on demand; “exclusive hardware” and “local only” are the opposite.
  • TCP versus IP versus HTTP. Match each to its layer and job: TCP delivers reliably, IP addresses, HTTP carries web pages.
  • Binary place values. Read the remainders from bottom to top.
  • Decimal and hexadecimal letters. A to F stand for 10 to 15.
  • Blockchain and Bitcoin. Blockchain is the ledger technology; a cryptocurrency is one use of it.
  • AI, ML and deep learning. ML is a part of AI, and deep learning is a part of ML.
  • UMANG, DigiLocker, GeM. Services app, document store, procurement marketplace.
