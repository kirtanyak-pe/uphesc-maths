Countability and separation axioms

  1. Question 1Easy
    Using the standard definitions (\(T_3\) means regular and \(T_1\)), which implication holds for every topological space?

    Why

    In a \(T_3\) space points are closed, so a point \(x\ne y\) can be separated from the closed set \(\{y\}\) by disjoint open sets, which gives \(T_2\). The cofinite topology on an infinite set shows \(T_1\not\Rightarrow T_2\), the Sierpinski space shows \(T_0\not\Rightarrow T_1\), and the \(K\)-topology on \(\mathbb R\) shows \(T_2\not\Rightarrow T_3\).
  2. Question 2Easy
    Which of the following is \(T_1\) but not Hausdorff?

    Why

    In the cofinite topology points are closed, so it is \(T_1\), but two nonempty open sets always meet. The Sierpinski space is not even \(T_1\).
  3. Question 3Easy
    Which of the following is NOT true for every metric space?

    Why

    Every metric space is \(T_4\) and first countable. Second countable holds only for separable metric spaces; an uncountable discrete metric space (or \(\ell^\infty\)) is not second countable.
  4. Question 4Medium
    The lower limit topology \(\mathbb R_\ell\) (basis \([a,b)\)) is

    Why

    \(\mathbb Q\) is dense, so \(\mathbb R_\ell\) is separable. It has no countable basis, since each point \(a\) needs a basic set with minimum \(a\). A separable metrizable space is second countable, so \(\mathbb R_\ell\) is not metrizable either.
  5. Question 5Medium
    The number of Hausdorff topologies on a three-point set is

    Why

    A finite Hausdorff space is discrete, since each point is closed and finite sets are closed, hence every set is closed and also open. So only the discrete topology is Hausdorff (confirmed by brute force over all \(29\) topologies).
  6. Question 6Hard
    The number of regular topologies on a three-point set (no \(T_1\) assumption; regular means a point and a closed set not containing it have disjoint open neighbourhoods) is

    Why

    Brute force over the \(29\) topologies gives \(5\); they are the partition topologies, one for each of the five partitions of a three-element set (including the indiscrete and discrete topologies). Only the discrete one is \(T_0\).
  7. Question 7Medium
    Consider: (I) a compact Hausdorff space is normal; (II) every regular space is normal; (III) every regular Lindelöf space is normal. Which are true?

    Why

    (I) and (III) are standard theorems. (II) is false: the Sorgenfrey plane \(\mathbb R_\ell\times\mathbb R_\ell\) is regular (indeed completely regular and \(T_1\)) but not normal. So only (I) and (III) hold.
  8. Question 8Medium
    Assertion (A): A metrizable space need not be second countable. Reason (R): An uncountable set with the discrete topology is metrizable but not second countable.

    Why

    The discrete metric gives the discrete topology. A basis of an uncountable discrete space must contain every singleton, so it is uncountable. This is the example showing that Urysohn’s condition is sufficient, not necessary.
  9. Question 9Hard
    Assertion (A): Urysohn’s metrization theorem shows that \(\mathbb R_\ell\) is metrizable. Reason (R): \(\mathbb R_\ell\) is regular, \(T_1\) and separable.

    Why

    \(\mathbb R_\ell\) is regular, \(T_1\) and separable, so R is true. But the theorem needs second countability, which \(\mathbb R_\ell\) lacks, and \(\mathbb R_\ell\) is not metrizable. So A is false.
  10. Question 10Medium
    In which situation does Tietze’s extension theorem guarantee that a continuous \(f:A\to\mathbb R\) extends continuously to \(X=\mathbb R\)?

    Why

    \(\mathbb R\) is normal, so extensions exist for continuous \(f\) on a closed set \(A\). \(\mathbb Z\) is closed, and every function on \(\mathbb Z\) is continuous. \((0,1]\), \((0,1)\) and \(\mathbb Q\) are not closed, and the first two examples genuinely fail to extend.
  11. Question 11Hard
    Urysohn’s lemma states that if \(X\) is normal and \(A,B\) are disjoint closed sets, then there is a continuous \(f:X\to[0,1]\) with

    Why

    The lemma gives \(f=0\) on \(A\) and \(f=1\) on \(B\). The stronger requirement \(f^{-1}(0)=A\) holds only when \(A\) is a \(G_\delta\) set (perfectly normal spaces), not for all normal spaces.
  12. Question 12Easy
    Which of these spaces is second countable?

    Why

    \(\ell^2\) is a separable metric space, hence second countable. \(\ell^\infty\) is not separable; an uncountable discrete space and \(\mathbb R_\ell\) have no countable basis.
  13. Question 13Hard
    The Sorgenfrey plane \(\mathbb R_\ell\times\mathbb R_\ell\) is

    Why

    \(\mathbb R_\ell\) is regular and a product of regular spaces is regular. The antidiagonal \(\{(x,-x)\}\) is an uncountable closed discrete set, and the plane is separable; the standard argument shows it is not normal. So normality is not productive.
  14. Question 14Medium
    Every second countable regular \(T_1\) space embeds topologically in

    Why

    This is the content of the proof of Urysohn’s metrization theorem: countably many Urysohn functions \(f_n\) give an embedding \(x\mapsto(f_n(x))\) into \([0,1]^{\mathbb N}\), which is metrizable.
