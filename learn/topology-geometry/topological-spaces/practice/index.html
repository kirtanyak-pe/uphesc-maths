  1. Question 1Easy
    The number of different topologies on a two-point set \(\{a,b\}\) is

    Why

    The four are: indiscrete, discrete, \(\{\emptyset,\{a\},X\}\) and \(\{\emptyset,\{b\},X\}\). Note \(3\) is the count up to homeomorphism, not the count on the labelled set.
  2. Question 2Easy
    The number of different topologies on a three-point set is

    Why

    Brute force over all families of subsets gives \(29\). The number \(19\) counts only the \(T_0\) topologies and \(9\) counts them up to homeomorphism.
  3. Question 3Medium
    Let \(X=\{1,2,3,4\}\). Exactly one of the following families (each also contains \(\emptyset\) and \(X\)) is a topology on \(X\). Which one?

    Why

    A fails because \(\{1\}\cup\{2\}=\{1,2\}\) is missing. B fails because \(\{1,2\}\cup\{1,3\}=\{1,2,3\}\) is missing. D fails because \(\{1,2\}\cap\{2,3\}=\{2\}\) is missing. C is closed under unions and intersections.
  4. Question 4Medium
    The number of topologies on \(X=\{a,b,c\}\) in which \(\{a\}\) is an open set is

    Why

    Counting all \(29\) topologies on a three-point set and keeping those that contain \(\{a\}\) gives \(12\).
  5. Question 5Easy
    Let \(X\) be an infinite set with the cofinite topology. Which statement is true?

    Why

    Any open cover has a member that misses only finitely many points; finitely many more members cover the rest, so \(X\) is compact. Two nonempty open sets always meet, so \(X\) is not Hausdorff, hence not metrizable. Singletons are not open, so it is not discrete.
  6. Question 6Medium
    In the lower limit topology \(\mathbb R_\ell\) (basis \([a,b)\)), the closure of the interval \((0,1)\) is

    Why

    \(0\) is in the closure because every \([0,\varepsilon)\) meets \((0,1)\). \(1\) is not, because \([1,1+\varepsilon)\) misses \((0,1)\). So the closure is \([0,1)\).
  7. Question 7Medium
    In \(\mathbb R\) with the usual topology let \(A=\{1/n:n\ge1\}\cup(2,3]\). The derived set \(A'\) (set of limit points of \(A\)) is

    Why

    Each point \(1/n\) is isolated, so it is not a limit point; \(0\) is a limit point. Every point of \([2,3]\) (including the end \(2\)) is a limit point of \((2,3]\).
  8. Question 8Medium
    In \(\mathbb R\) with the usual topology consider: (I) \(\partial\mathbb Q=\mathbb R\); (II) \(\partial[0,1)=\{0,1\}\); (III) \(\partial\mathbb Z=\emptyset\). Which are correct?

    Why

    \(\mathbb Q\) is dense with empty interior, so (I) holds. (II) holds. \(\mathbb Z\) is closed with empty interior, so \(\partial\mathbb Z=\mathbb Z\), and (III) fails.
  9. Question 9Hard
    Which continuous functions \(f:(\mathbb R,\text{cofinite})\to(\mathbb R,\text{usual})\) exist?

    Why

    If \(f(x)\ne f(y)\), disjoint open intervals around the two values pull back to disjoint nonempty open sets of the cofinite topology, which is impossible. So \(f\) is constant.
  10. Question 10Medium
    Let \(\mathrm{id}:(\mathbb R,\mathbb R_\ell)\to(\mathbb R,\text{usual})\) be the identity, where \(\mathbb R_\ell\) is the lower limit topology. Then \(\mathrm{id}\) is

    Why

    Every usual-open set is \(\mathbb R_\ell\)-open, so \(\mathrm{id}\) is continuous. The image of the open set \([0,1)\) is \([0,1)\), which is not usual-open, so \(\mathrm{id}\) is not open and not a homeomorphism.
  11. Question 11Easy
    Which pair of subspaces of \(\mathbb R\) is homeomorphic?

    Why

    \(x\mapsto\tan\bigl(\pi(x-\tfrac12)\bigr)\) is a homeomorphism \((0,1)\to\mathbb R\). The others fail: \([0,1]\) is compact and the others are not; \([0,1)\) has a point whose removal leaves it connected, \((0,1)\) has none.
  12. Question 12Hard
    Assertion (A): The intersection of two topologies on a set \(X\) is again a topology on \(X\). Reason (R): The union of two topologies on \(X\) is always a topology on \(X\).

    Why

    Both axioms (unions, finite intersections) pass to an intersection of topologies, so A is true. On \(\{a,b,c\}\) the union of \(\{\emptyset,X,\{a\}\}\) and \(\{\emptyset,X,\{b\}\}\) lacks \(\{a,b\}\), so R is false.
  13. Question 13Easy
    In the indiscrete topology on a set \(X\) with at least two points, the constant sequence \((a,a,a,\dots)\) converges to

    Why

    The only neighbourhood of any point is \(X\) itself, which contains every term of the sequence. So the sequence converges to every point.
  14. Question 14Medium
    Let \(Y=[0,1]\) be a subspace of \(\mathbb R\). Which subset of \(Y\) is open in \(Y\) but not open in \(\mathbb R\)?

    Why

    \((\tfrac12,1]=(\tfrac12,2)\cap Y\) is open in \(Y\), but no open interval around \(1\) lies in it, so it is not open in \(\mathbb R\). \([0,\tfrac12]\) and \(\{\tfrac12\}\) are not open in \(Y\); \((0,1)\) is open in both.
  15. Question 15Medium
    Arrange these topologies on \(\mathbb R\) from coarsest to finest (each is contained in the next): cofinite, lower limit, usual, discrete.

    Why

    A cofinite set has finite complement, hence is open in the usual topology. Usual-open sets are \(\mathbb R_\ell\)-open, and everything is discrete-open. The lower limit topology is strictly finer than the usual one.
