Why it matters for the exam

Congruence arithmetic is the working language of every number-theory question. In 2025 and 2026 two questions are pure congruence computations (\(2^{340} \bmod 341\) and \(1003\times997 \bmod 13\)), and the divisor question 2026 Q37 also needed a mod-5 check. Expect a remainder computation, a statement about Fermat, Euler or Wilson, a count of solutions or primitive roots, or Carmichael numbers. Speed matters: most of these are two-line problems once the theorem is recognised.

Core ideas

Congruence and residue classes

\(a \equiv b \pmod m\) means \(m \mid (a - b)\). It is an equivalence relation whose classes are the residue classes modulo \(m\); there are \(m\) of them. A complete residue system has one representative from each class (\(0,1,\dots,m-1\)). A reduced residue system keeps only the classes coprime to \(m\): there are \(\varphi(m)\) of them.

Rules (for \(a\equiv b\), \(c\equiv d \pmod m\)):

  • \(a + c\equiv b + d\), \(a - c\equiv b - d\), \(ac\equiv bd\), \(a^k\equiv b^k\) for \(k\ge0\). So for any polynomial \(f\) with integer coefficients, \(f(a)\equiv f(b)\).
  • Cancellation: \(ac\equiv bc\pmod m\) implies \(a\equiv b\pmod{m/\gcd(c,m)}\). You may cancel \(c\) with the modulus unchanged only if \(\gcd(c,m) = 1\).
  • If \(a\equiv b\pmod m\) then \(a\equiv b\) modulo every divisor of \(m\). If \(a\equiv b\) modulo \(m\) and modulo \(n\) then modulo \(\operatorname{lcm}(m,n)\).
  • Exponents are not reduced modulo \(m\). \(a^k\bmod m\) depends on \(k\) only through \(k\) modulo the order of \(a\) (a divisor of \(\varphi(m)\)), not through \(k\bmod m\). For \(2^{100}\bmod7\) reduce \(100\) modulo \(3\), not modulo \(7\).
  • Digit tests: \(10\equiv1\pmod9\) and \(\pmod3\), so a number is divisible by \(9\) (or \(3\)) iff its digit sum is. \(10\equiv-1\pmod{11}\) gives the alternating-sum test. \(1001 = 7\cdot11\cdot13\) and \(10^3\equiv-1\pmod{1001}\) give the test for \(7,11,13\) by alternating sums of 3-digit blocks.

Linear congruence \(ax \equiv b \pmod m\)

Let \(d = \gcd(a,m)\).

  • It has a solution iff \(d \mid b\).
  • If \(d \mid b\), there are exactly \(d\) solutions modulo \(m\). They form one residue class modulo \(m/d\): \(x_0, x_0 + m/d, \dots, x_0 + (d-1)m/d\).
  • If \(d = 1\) there is exactly one solution \(x\equiv a^{-1}b\), and \(a^{-1}\) exists iff \(\gcd(a,m) = 1\) (Bezout: \(ax+my = 1\)).

Method: divide through by \(d\) to get \(a'x\equiv b'\pmod{m'}\) with \(\gcd(a',m') = 1\), find \(a'^{-1}\) by Euclid, then list the \(d\) solutions.

Chinese remainder theorem (CRT)

Statement. If \(m_1,\dots,m_k\) are pairwise coprime, the system \(x\equiv a_i\pmod{m_i}\) (\(i=1,\dots,k\)) has a solution, unique modulo \(M = m_1\cdots m_k\).

Construction: \(M_i = M/m_i\), \(y_i\equiv M_i^{-1}\pmod{m_i}\), then \(x\equiv\sum a_iM_iy_i\pmod M\).

Equivalent algebraic form: \(\mathbb Z_M\cong\mathbb Z_{m_1}\times\cdots\times\mathbb Z_{m_k}\) as rings, and \((\mathbb Z_M)^\times\cong\prod(\mathbb Z_{m_i})^\times\), which is why \(\varphi\) is multiplicative.

Moduli not coprime. The system \(x\equiv a\pmod m\), \(x\equiv b\pmod n\) is solvable iff \(a\equiv b\pmod{\gcd(m,n)}\), and then the solution is unique modulo \(\operatorname{lcm}(m,n)\). Without that condition there is no solution.

Counting roots of polynomial congruences. If \(m = \prod p_i^{a_i}\), then the number of solutions of \(f(x)\equiv0\pmod m\) is the product of the numbers of solutions modulo each \(p_i^{a_i}\). Lagrange: a polynomial of degree \(n\) has at most \(n\) roots modulo a prime \(p\). This fails for composite moduli: \(x^2\equiv1\pmod8\) has \(4\) roots (\(1,3,5,7\)) and \(x^2\equiv1\pmod{15}\) has \(4\) roots (\(1,4,11,14\)). In general \(x^2\equiv1\pmod m\) has \(2^{k}\) roots for odd \(m\) with \(k\) distinct prime factors.

Fermat’s little theorem

If \(p\) is prime and \(p\nmid a\) then \(a^{p-1}\equiv1\pmod p\). Equivalently \(a^p\equiv a\pmod p\) for all integers \(a\).

Uses: \(a^{-1}\equiv a^{p-2}\pmod p\). Also \(a^{n}\equiv a^{n \bmod (p-1)}\pmod p\) when \(p\nmid a\). Applying Fermat to each prime \(p\) with \((p-1)\mid(k-1)\) shows that \(n^5-n\) is divisible by \(2\cdot3\cdot5 = 30\), \(n^7-n\) by \(2\cdot3\cdot7 = 42\), and \(n^{13}-n\) by \(2\cdot3\cdot5\cdot7\cdot13 = 2730\).

Euler’s theorem

If \(\gcd(a,m) = 1\) then \(a^{\varphi(m)}\equiv1\pmod m\). This generalises Fermat (\(m = p\), \(\varphi = p-1\)). The hypothesis \(\gcd(a,m) = 1\) is essential: \(2^{\varphi(4)} = 2^2 = 4\not\equiv1\pmod4\).

Carmichael’s sharper exponent. The least \(\lambda(m)\) with \(a^{\lambda(m)}\equiv1\) for all \(a\) coprime to \(m\) is the exponent of the group \((\mathbb Z_m)^\times\). \(\lambda(p^k) = \varphi(p^k)\) except \(\lambda(2^k) = 2^{k-2}\) for \(k\ge3\), and \(\lambda(\operatorname{lcm}) = \operatorname{lcm}\) of the \(\lambda\)’s. For example \(\lambda(100) = \operatorname{lcm}(\lambda(4),\lambda(25)) = \operatorname{lcm}(2,20) = 20\) (instead of \(\varphi(100)=40\)) and \(\lambda(561) = 80\).

Wilson’s theorem

For an integer \(n>1\): \((n-1)!\equiv-1\pmod n\) iff \(n\) is prime.

Proof for prime \(p\): in \((p-1)! = 1\cdot2\cdots(p-1)\) pair each \(a\) with its inverse; only \(1\) and \(p-1\) are their own inverses (the roots of \(x^2\equiv1\)). So the product is \(1\cdot(p-1)\equiv-1\).

  • For composite \(n>4\): \((n-1)!\equiv0\pmod n\). (For \(n = 4\): \(3! = 6\equiv2\).)
  • Consequence: \(\bigl(\tfrac{p-1}2\bigr)!^2\equiv(-1)^{(p+1)/2}\pmod p\). So for \(p\equiv1\pmod4\) the number \(\bigl(\tfrac{p-1}2\bigr)!\) is a square root of \(-1\) modulo \(p\). Check: \(p = 13\), \(6! = 720\equiv5\) and \(5^2 = 25\equiv-1\).
  • Useful form: \((p-2)!\equiv1\pmod p\) and \((p-1-k)!\,k!\equiv(-1)^{k+1}\pmod p\).

Order of an element

For \(\gcd(a,m) = 1\), \(\operatorname{ord}_m(a)\) is the least \(k\ge1\) with \(a^k\equiv1\pmod m\).

  • \(a^n\equiv1\pmod m\) iff \(\operatorname{ord}_m(a)\mid n\). In particular \(\operatorname{ord}_m(a)\mid\varphi(m)\) (and \(\mid\lambda(m)\)).
  • \(\operatorname{ord}(a^k) = \operatorname{ord}(a)/\gcd(\operatorname{ord}(a),k)\).
  • If \(\operatorname{ord}(a) = r\), \(\operatorname{ord}(b) = s\) and \(\gcd(r,s) = 1\), then \(\operatorname{ord}(ab) = rs\).
  • If \(a^k\equiv1\) and \(a^l\equiv1\) then \(a^{\gcd(k,l)}\equiv1\).
  • Modulo a prime \(p\): the order of \(a\) divides \(p-1\), and for each \(d\mid p-1\) there are exactly \(\varphi(d)\) elements of order \(d\) (so \(\sum_{d\mid p-1}\varphi(d) = p-1\) is Gauss’s identity again).

Example: modulo \(13\) the orders of \(1,\dots,12\) are \(1,12,3,6,4,12,12,4,3,6,12,2\). The counts are \(\varphi(1)=1\) of order \(1\), \(1\) of order \(2\), \(2\) of order \(3\), \(2\) of order \(4\), \(2\) of order \(6\), \(4\) of order \(12\).

Primitive roots

\(g\) is a primitive root modulo \(m\) if \(\operatorname{ord}_m(g) = \varphi(m)\), i.e. \(g\) generates the group \((\mathbb Z_m)^\times\).

Existence theorem (Gauss). Primitive roots modulo \(m\) exist iff \(m = 1, 2, 4, p^k\) or \(2p^k\) with \(p\) an odd prime and \(k\ge1\).

Count. When they exist there are exactly \(\varphi(\varphi(m))\) of them. In particular modulo a prime \(p\) there are \(\varphi(p-1)\).

  • Test for a prime \(p\): \(g\) is a primitive root iff \(g^{(p-1)/q}\not\equiv1\pmod p\) for every prime \(q\mid p-1\).
  • If \(g\) is a primitive root modulo a prime \(p\), then \(g^{(p-1)/2}\equiv-1\) and \(-1\) is the only element of order \(2\).
  • If \(g\) is a primitive root modulo \(p\), then \(g\) or \(g+p\) is a primitive root modulo \(p^2\), and then modulo every \(p^k\).
  • Powers \(g^k\) (\(1\le k\le\varphi(m)\), \(\gcd(k,\varphi(m)) = 1\)) are exactly the primitive roots.
  • Modulo \(2^k\) with \(k\ge3\) the group is \(C_2\times C_{2^{k-2}}\), not cyclic: modulo \(8\) every odd number squares to \(1\).

Pseudoprimes and Carmichael numbers

Fermat’s theorem gives a primality filter: if \(2^{n-1}\not\equiv1\pmod n\), then \(n\) is composite. The converse fails.

  • A Fermat pseudoprime to base \(a\) is a composite \(n\) with \(a^{n-1}\equiv1\pmod n\). The smallest base-\(2\) pseudoprime is \(341 = 11\cdot31\). Others: \(561, 645, 1105, 1387, 1729,\dots\).
  • A Carmichael number is a composite \(n\) with \(a^{n-1}\equiv1\pmod n\) for every \(a\) coprime to \(n\). The smallest is \(561 = 3\cdot11\cdot17\). Next: \(1105, 1729, 2465, 2821, 6601, 8911\).
  • Korselt’s criterion. \(n\) is a Carmichael number iff \(n\) is composite, square-free, and \(p-1\mid n-1\) for every prime \(p\mid n\). Check \(561\): \(2\mid560\), \(10\mid560\), \(16\mid560\).
  • Every Carmichael number is odd and has at least three prime factors.
  • Alford, Granville and Pomerance (1994) proved there are infinitely many Carmichael numbers.
  • Why \(341\) is a pseudoprime: \(2^{10}\equiv1\pmod{11}\) and \(2^{5}\equiv1\pmod{31}\) with \(10, 5\mid340\), so \(2^{340}\equiv1\) modulo both, hence modulo \(341\). Also \(3^{340}\not\equiv1\pmod{341}\), so \(341\) is not Carmichael.

Remainder and last-digit problems

Toolbox:

  1. Last digit of \(a^n\): reduce \(a\) modulo \(10\); the last digits cycle with period dividing \(4\). Cycle of \(2\): \(2,4,8,6\); of \(3\): \(3,9,7,1\); of \(7\): \(7,9,3,1\); \(4\): \(4,6\); \(9\): \(9,1\); \(0,1,5,6\) fixed.
  2. Last two digits: work modulo \(100\) with \(\lambda(100) = 20\). For odd \(a\) coprime to \(5\), \(a^{20}\equiv1\); if \(a\equiv1\pmod{10}\) or \(a^4\equiv1\) the cycle is shorter (\(7^4 = 2401\equiv1\)).
  3. Remainder modulo a prime \(p\): reduce the exponent modulo \(p-1\) (Fermat) when \(p\nmid a\).
  4. Remainder modulo composite \(m\): use \(\varphi(m)\) or split with CRT.
  5. Factorials: \(n!\equiv0\pmod m\) for \(n\ge m\) when \(m\) is composite or equal to \(n\); Wilson for prime moduli.
  6. Special products: \((1000+3)(1000-3) = 10^6-9\); \(10^3\equiv-1\pmod{13}\) so \(10^6\equiv1\pmod{13}\).
  7. Tower \(a^{b^c}\): compute \(b^c\bmod\varphi(m)\) first.

Worked examples

Example 1: linear congruence with several solutions

Solve \(6x\equiv9\pmod{15}\).

\(\gcd(6,15) = 3\mid9\), so there are \(3\) solutions. Divide by \(3\): \(2x\equiv3\pmod5\). The inverse of \(2\) modulo \(5\) is \(3\), so \(x\equiv9\equiv4\pmod5\). The solutions modulo \(15\) are \(x = 4, 9, 14\).

Example 2: a system by CRT

Solve \(x\equiv2\pmod3\), \(x\equiv3\pmod5\), \(x\equiv2\pmod7\).

\(M = 105\). \(M_1 = 35\equiv2\pmod3\), inverse \(2\); \(M_2 = 21\equiv1\pmod5\), inverse \(1\); \(M_3 = 15\equiv1\pmod7\), inverse \(1\). So \(x\equiv2\cdot35\cdot2 + 3\cdot21\cdot1 + 2\cdot15\cdot1 = 140+63+30 = 233\equiv233-210 = 23\pmod{105}\). Check: \(23 = 3\cdot7+2\), \(23 = 4\cdot5+3\), \(23 = 3\cdot7+2\). Answer \(x\equiv23\pmod{105}\).

Example 3: moduli that are not coprime

Solve \(x\equiv5\pmod{12}\), \(x\equiv11\pmod{18}\).

\(\gcd(12,18) = 6\) and \(5\equiv11\pmod6\), so a solution exists, unique modulo \(\operatorname{lcm} = 36\). From \(x = 5+12t\): \(5+12t\equiv11\pmod{18}\) gives \(12t\equiv6\pmod{18}\), \(2t\equiv1\pmod3\), \(t\equiv2\pmod3\). Then \(x = 29\). Answer \(x\equiv29\pmod{36}\). If the second congruence had been \(x\equiv10\pmod{18}\), then \(5\not\equiv10\pmod6\) and there would be no solution.

Example 4: last two digits

Find the last two digits of \(7^{2025}\) and of \(3^{1000}\).

\(7^2 = 49\), \(7^4 = 2401\equiv1\pmod{100}\). \(2025 = 4\cdot506+1\), so \(7^{2025}\equiv7\): last two digits \(07\). For \(3\): \(\gcd(3,100) = 1\) and \(\lambda(100) = 20\), so \(3^{20}\equiv1\pmod{100}\); \(1000 = 20\cdot50\), so \(3^{1000}\equiv1\): last two digits \(01\).

Example 5: Fermat reduction and Wilson

(a) \(2^{100}\bmod7\): \(2^3 = 8\equiv1\), and \(100 = 3\cdot33+1\), so the remainder is \(2\). (b) \(15!\bmod17\): \(16!\equiv-1\pmod{17}\) (Wilson) and \(16\equiv-1\), so \(15!\equiv(-1)/(-1) = 1\). (c) \(7^{77}\bmod13\): \(7^{12}\equiv1\); \(77 = 12\cdot6+5\); \(7^2 = 49\equiv10\), \(7^4\equiv100\equiv9\), \(7^5\equiv63\equiv11\). The remainder is \(11\).

Example 6: pseudoprime

Show that \(2^{340}\equiv1\pmod{341}\) although \(341\) is composite.

\(341 = 11\cdot31\). By Fermat, \(2^{10}\equiv1\pmod{11}\) and \(340 = 34\cdot10\), so \(2^{340}\equiv1\pmod{11}\). Also \(2^5 = 32\equiv1\pmod{31}\) and \(340 = 68\cdot5\), so \(2^{340}\equiv1\pmod{31}\). By CRT (or since \(11\) and \(31\) are coprime) \(2^{340}\equiv1\pmod{341}\).

Example 7: counting primitive roots

How many primitive roots has \(13\)? \(\varphi(12) = 4\). They are \(2, 6, 7, 11\). How many has \(25\)? \(25 = 5^2\) has primitive roots; the count is \(\varphi(\varphi(25)) = \varphi(20) = 8\). Does \(15\) have any? No: \(15 = 3\cdot5\) is not of the form \(p^k\) or \(2p^k\).

Common traps

  • Euler’s theorem needs \(\gcd(a,m) = 1\). \(2^{\varphi(9)}= 2^6 = 64\equiv1\pmod9\) is fine but \(3^{6}\equiv0\pmod9\).
  • Wilson is “iff prime”. \((n-1)!\equiv-1\pmod n\) characterises primes; \((n-1)!\equiv0\) for composite \(n>4\).
  • Fermat’s theorem is not an “iff”. \(2^{340}\equiv1\pmod{341}\) and \(341\) is composite. Primality via a single base is unreliable.
  • Carmichael numbers fool every base coprime to \(n\). \(561\) is the smallest, not \(341\) (that is the smallest base-\(2\) pseudoprime).
  • Number of solutions of \(ax\equiv b\pmod m\) is \(\gcd(a,m)\) (when solvable), not \(1\) and not \(\gcd(a,b)\).
  • Cancelling a common factor changes the modulus: \(6x\equiv6\cdot4\pmod{15}\) gives \(x\equiv4\pmod5\), not mod \(15\).
  • CRT needs pairwise coprime moduli (or a compatibility check). Solving modulo \(4\) and \(6\) independently can give a contradiction.
  • Reduce exponents modulo \(\varphi(m)\), not modulo \(m\). \(2^{100}\bmod 7\) uses \(100\bmod 6\) (or the order \(3\)), not \(100\bmod7\).
  • Number of primitive roots is \(\varphi(\varphi(m))\), not \(\varphi(m)\). And \(m = 8, 12, 15\) have none.
  • \(\mathbb Z_m^\times\) cyclic does not mean \(m\) prime. \(m = 9, 10, 18, 25\) also have primitive roots.
  • Last digit cycles have period \(4\) in the exponent (for \(2,3,7,8\)), so reduce the exponent mod \(4\) and use \(4\) (not \(0\)) when the remainder is \(0\).
  • Polynomial root count: at most \(\deg f\) roots modulo a prime only; \(x^2\equiv1\pmod8\) has four roots.

Previous-year questions

2025 Q90. The remainder when \(2^{340}\) is divided by \(341\) is: (A) 5 (B) 3 (C) 2 (D) 1. Answer: D (official key). Solution: \(341 = 11\cdot31\). \(2^{10}\equiv1\pmod{11}\) and \(2^5\equiv1\pmod{31}\), and both \(10\) and \(5\) divide \(340\). So \(2^{340}\equiv1\) modulo \(11\) and \(31\), hence modulo \(341\). (This is the standard pseudoprime example.)

2026 Q48. Using the Vedic method and congruences, if \(x = 1003\times997\), then \(x\pmod{13}\) equals: (A) 1 (B) 3 (C) 12 (D) 9. Worked key: B (3), but the question is defective. The correct value is \(5\), which is not an option. Solution: \(1003\times997 = (1000+3)(1000-3) = 10^6-9 = 999991\). \(10^3 = 1000\equiv-1\pmod{13}\) (since \(1001 = 7\cdot11\cdot13\)), so \(10^6\equiv1\) and \(x\equiv1-9 = -8\equiv5\pmod{13}\). Directly: \(1003\equiv2\), \(997\equiv9\), product \(18\equiv5\). The value \(3\) is what the same product gives modulo \(11\); the options may belong to a different modulus. If this appears with options that include \(5\), answer \(5\).

Quick revision

  • \(ax\equiv b\pmod m\): solvable iff \(\gcd(a,m)\mid b\); then \(\gcd(a,m)\) solutions modulo \(m\).
  • CRT: pairwise coprime moduli give a unique solution modulo the product; otherwise check \(a\equiv b\pmod{\gcd}\), solution modulo the lcm.
  • Fermat: \(a^{p-1}\equiv1\pmod p\) for \(p\nmid a\); \(a^p\equiv a\) for all \(a\).
  • Euler: \(a^{\varphi(m)}\equiv1\pmod m\) when \(\gcd(a,m)=1\); \(\lambda(100) = 20\).
  • Wilson: \((n-1)!\equiv-1\pmod n\) iff \(n\) is prime; \((p-2)!\equiv1\).
  • \(\operatorname{ord}_m(a)\mid\varphi(m)\); \(a^n\equiv1\) iff \(\operatorname{ord}\mid n\).
  • Primitive roots exist iff \(m = 1,2,4,p^k,2p^k\); there are \(\varphi(\varphi(m))\) of them.
  • Primitive roots: \(13\) has \(4\) (\(2,6,7,11\)); \(11\) has \(4\) (\(2,6,7,8\)); \(7\) has \(2\) (\(3,5\)); \(8\) and \(15\) have none.
  • \(341 = 11\cdot31\) is the least base-\(2\) pseudoprime: \(2^{340}\equiv1\pmod{341}\).
  • Carmichael: square-free and \(p-1\mid n-1\) for all \(p\mid n\); smallest is \(561 = 3\cdot11\cdot17\).
  • \(1003\times997 = 10^6-9\equiv5\pmod{13}\) because \(10^6\equiv1\pmod{13}\).
  • Last digits: reduce the exponent mod \(4\); last two digits: work mod \(100\) with period dividing \(20\).
