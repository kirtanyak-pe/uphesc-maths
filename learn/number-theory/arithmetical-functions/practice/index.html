Arithmetical functions and Mobius inversion

  1. Question 1Easy
    The number of positive divisors of \(720\) is

    Why

    \(720 = 2^4\cdot3^2\cdot5\), so \(d(720) = (4+1)(2+1)(1+1) = 30\).
  2. Question 2Easy
    \(\sigma(72)\), the sum of all positive divisors of \(72\), equals

    Why

    \(72 = 2^3\cdot3^2\), so \(\sigma = (1+2+4+8)(1+3+9) = 15\cdot13 = 195\).
  3. Question 3Easy
    \(\varphi(100) =\)

    Why

    \(\varphi(100) = 100(1-\tfrac12)(1-\tfrac15) = 40\). Option \(99\) would be \(n-1\), valid only for primes.
  4. Question 4Medium
    The number of positive integers \(n\) with \(\varphi(n) = 8\) is

    Why

    \(\varphi(n) = 8\) for \(n = 15, 16, 20, 24, 30\), exactly five values (no larger \(n\) works because \(\varphi(n)\ge\sqrt{n/2}\)).
  5. Question 5Medium
    Which of the following arithmetical functions are completely multiplicative? (I) \(f(n) = n^2\) (II) \(\varphi(n)\) (III) \(\sigma(n)\) (IV) \(\mu(n)\)

    Why

    \(n^2\) satisfies \(f(mn) = f(m)f(n)\) for all \(m,n\). \(\varphi(4) = 2\ne\varphi(2)^2\), \(\sigma(4) = 7\ne 9\), \(\mu(4) = 0\ne\mu(2)^2 = 1\). The last three are only multiplicative.
  6. Question 6Easy
    \(\displaystyle\sum_{d\mid 36}\varphi(d) =\)

    Why

    By Gauss’s identity \(\sum_{d\mid n}\varphi(d) = n\), so the sum is \(36\). (\(\varphi(36) = 12\) is the single term for \(d = 36\).)
  7. Question 7Medium
    \(\displaystyle\sum_{d\mid 60}\mu(d)^2 =\)

    Why

    \(\mu(d)^2 = 1\) exactly for square-free \(d\). \(60 = 2^2\cdot3\cdot5\) has \(3\) distinct primes, so there are \(2^3 = 8\) square-free divisors.
  8. Question 8Medium
    The product of all positive divisors of \(36\) is

    Why

    The product is \(n^{d(n)/2}\). Here \(d(36) = 9\), so it is \(36^{9/2} = 6^9\) (the divisors pair up as \(d\cdot36/d = 36\), with \(6\) in the middle).
  9. Question 9Hard
    The number of integers in \(\{1,2,\dots,1000\}\) divisible by none of \(2,3,5\) is

    Why

    Inclusion-exclusion: \(1000 - 500 - 333 - 200 + 166 + 100 + 66 - 33 = 266\). (Using \(1000\cdot\tfrac12\cdot\tfrac23\cdot\tfrac45 = 266.67\) without floors gives an approximation, not the count.)
  10. Question 10Medium
    \(\displaystyle\sum_{k=1}^{20}\left\lfloor\frac{20}{k}\right\rfloor =\)

    Why

    The sum counts pairs \((j,k)\) with \(jk\le 20\) in two ways, so it equals \(\sum_{m\le20}d(m) = 66\). Direct: \(20+10+6+5+4+3+2+2+2+2+1\cdot10 = 66\).
  11. Question 11Easy
    \(\lfloor -7/2\rfloor + \lfloor 7/2\rfloor\) equals

    Why

    \(\lfloor-3.5\rfloor = -4\) and \(\lfloor3.5\rfloor = 3\). For non-integer \(x\), \(\lfloor x\rfloor+\lfloor -x\rfloor = -1\).
  12. Question 12Medium
    Assertion (A): \(\mu\) is a multiplicative function. Reason (R): \(\mu(mn) = \mu(m)\mu(n)\) for all positive integers \(m,n\). Choose the correct option.

    Why

    \(\mu(mn) = \mu(m)\mu(n)\) holds when \(\gcd(m,n) = 1\), so A is true. R fails for \(m = n = 2\): \(\mu(4) = 0\ne\mu(2)^2 = 1\).
  13. Question 13Hard
    The smallest positive integer with exactly \(12\) divisors is

    Why

    Exponent patterns for \(12\) divisors: \(p^{11}\), \(p^5q\), \(p^3q^2\), \(p^2qr\). The smallest values are \(2^{11}=2048\), \(2^5\cdot3=96\), \(2^3\cdot3^2=72\), \(2^2\cdot3\cdot5=60\). So \(60\). (\(48\) has only \(10\) divisors.)
  14. Question 14Hard
    Let \(\sum_{d\mid n}f(d) = n^2\) for all \(n\ge1\). Then \(f(12) =\)

    Why

    Mobius inversion: \(f(12) = \sum_{d\mid12}\mu(d)(12/d)^2 = 144 - 36 - 16 + 4 = 96\) (terms \(d = 1,2,3,6\); \(\mu(4)=\mu(12)=0\)). Equivalently \(f(n) = n^2\prod(1-p^{-2}) = 144\cdot\tfrac34\cdot\tfrac89 = 96\).
