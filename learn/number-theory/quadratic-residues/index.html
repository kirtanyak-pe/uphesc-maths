Why it matters for the exam

Three of the seven NT questions in 2026 were Legendre-symbol evaluations: \((2/97)\), \((-1/101)\) and \((29/43)\). All three are solved in two or three lines from the supplementary laws and quadratic reciprocity. The skill to build is fast, error-free evaluation of \((a/p)\), plus knowing exactly when \(-1\), \(2\) and \(3\) are residues.

Core ideas

Quadratic residues

Let \(m>1\) and \(\gcd(a,m) = 1\). \(a\) is a quadratic residue (QR) modulo \(m\) if \(x^2\equiv a\pmod m\) has a solution; otherwise a quadratic non-residue (NR).

For an odd prime \(p\), among \(1,2,\dots,p-1\) exactly \(\tfrac{p-1}2\) are QRs and \(\tfrac{p-1}2\) are NRs. The QRs are \(1^2,2^2,\dots,\bigl(\tfrac{p-1}2\bigr)^2\) (reduced), because \(x\) and \(-x\) have the same square and the squares of \(1,\dots,\tfrac{p-1}2\) are distinct.

\(p\) QRs among \(1,\dots,p-1\)
\(7\) \(1, 2, 4\)
\(11\) \(1, 3, 4, 5, 9\)
\(13\) \(1, 3, 4, 9, 10, 12\)
\(17\) \(1, 2, 4, 8, 9, 13, 15, 16\)

Rules: QR\(\times\)QR is QR, QR\(\times\)NR is NR, NR\(\times\)NR is QR. The product of two non-residues is a residue.

Modulo composite \(m\): for odd \(m\) with \(k\) distinct prime factors, there are \(\varphi(m)/2^k\) residues among the units. Modulo \(15\) the QRs coprime to \(15\) are \(1, 4\) (there are \(8/4 = 2\)). Modulo \(8\) only \(1\) is a unit square; modulo \(9\): \(1,4,7\).

Euler’s criterion

For an odd prime \(p\) and \(p\nmid a\): \(a^{(p-1)/2}\equiv\begin{cases}1 & a\text{ is a QR}\\-1 & a\text{ is an NR}\end{cases}\pmod p.\)

Proof idea. \(a^{p-1}\equiv1\), so \(a^{(p-1)/2}\equiv\pm1\). If \(a\equiv x^2\) then \(a^{(p-1)/2}\equiv x^{p-1}\equiv1\). The polynomial \(y^{(p-1)/2}-1\) has at most \(\tfrac{p-1}2\) roots, and all \(\tfrac{p-1}2\) residues are roots, so non-residues give \(-1\).

Example: modulo \(13\), \(3^6 = 729 = 13\cdot56+1\equiv1\), so \(3\) is a QR (\(4^2 = 16\equiv3\)); \(5^6 = 15625\equiv-1\), so \(5\) is an NR.

Legendre symbol

For an odd prime \(p\): \(\left(\frac ap\right) = \begin{cases}1&p\nmid a,\ a\text{ is a QR mod }p\\-1&a\text{ is an NR mod }p\\0&p\mid a.\end{cases}\)

Properties (for odd prime \(p\)):

  1. \((a/p)\equiv a^{(p-1)/2}\pmod p\) (Euler’s criterion).
  2. \((a/p)\) depends only on \(a\bmod p\).
  3. Completely multiplicative in the top: \((ab/p) = (a/p)(b/p)\).
  4. \((a^2/p) = 1\) if \(p\nmid a\), and \((1/p) = 1\).
  5. \(\sum_{a=1}^{p-1}(a/p) = 0\).
  6. The number of solutions of \(x^2\equiv a\pmod p\) is \(1+(a/p)\).

The symbol is not multiplicative in the bottom: \((a/pq)\) is a different object (Jacobi).

The values \((-1/p)\) and \((2/p)\)

First supplement. \(\left(\frac{-1}p\right) = (-1)^{(p-1)/2} = \begin{cases}1&p\equiv1\pmod4\\-1&p\equiv3\pmod4.\end{cases}\) So \(x^2\equiv-1\pmod p\) is solvable iff \(p = 2\) or \(p\equiv1\pmod4\). Consequently every odd prime divisor of \(n^2+1\) is \(\equiv1\pmod4\), and there are infinitely many primes \(\equiv1\pmod4\).

Second supplement. \(\left(\frac2p\right) = (-1)^{(p^2-1)/8} = \begin{cases}1&p\equiv\pm1\pmod8\\-1&p\equiv\pm3\pmod8.\end{cases}\) So \(2\) is a QR for \(p = 7, 17, 23, 31, 41, 47,\dots\) and an NR for \(p = 3, 5, 11, 13, 19, 29, 37, 43,\dots\).

Two derived rules: \((-2/p) = 1\) iff \(p\equiv1,3\pmod8\); and for \(p\equiv3\pmod4\) exactly one of \(a\) and \(-a\) is a QR (for \(p\equiv1\pmod4\), \(a\) and \(-a\) are both or neither).

Gauss’s lemma

Let \(p\) be an odd prime, \(p\nmid a\). Let \(\mu\) be the number of integers among \(a,\ 2a,\ 3a,\ \dots,\ \tfrac{p-1}2\,a\) whose least positive residue modulo \(p\) exceeds \(p/2\). Then \(\left(\frac ap\right) = (-1)^\mu.\)

Example \((3/7)\): the multiples \(3, 6, 9\) reduce to \(3, 6, 2\). Only \(6>3.5\), so \(\mu = 1\) and \((3/7) = -1\). Check: the QRs modulo \(7\) are \(1,2,4\).

Example \((5/11)\): \(5,10,15,20,25\to5,10,4,9,3\). Those above \(5.5\) are \(10, 9\), so \(\mu = 2\) and \((5/11) = +1\). Check: \(4^2 = 16\equiv5\).

Gauss’s lemma gives \((2/p)\): the multiples are \(2k\) for \(1\le k\le\tfrac{p-1}2\), and \(2k>p/2\) exactly when \(k>p/4\), so \(\mu = \tfrac{p-1}2-\lfloor p/4\rfloor\). Then \((-1)^\mu = (-1)^{(p^2-1)/8}\), which is the second supplement. For \(p=13\): \(\mu = 6-3 = 3\), so \((2/13) = -1\).

Quadratic reciprocity

Theorem (Gauss). For distinct odd primes \(p, q\): \(\left(\frac pq\right)\left(\frac qp\right) = (-1)^{\frac{p-1}2\cdot\frac{q-1}2}.\)

Equivalent reading:

  • If \(p\equiv1\pmod4\) or \(q\equiv1\pmod4\) (at least one is \(1\) mod \(4\)), then \((p/q) = (q/p)\).
  • If \(p\equiv q\equiv3\pmod4\), then \((p/q) = -(q/p)\).

Algorithm for \((a/p)\):

  1. Reduce \(a\) modulo \(p\) (use the representative with smallest absolute value if it helps).
  2. Pull out factors of \(-1\), \(2\), and factor the rest into primes.
  3. Use the supplements for \(-1\) and \(2\); flip odd primes with reciprocity; reduce again; repeat until the numbers are small.

Special results that follow:

Symbol Equals \(1\) iff
\((-1/p)\) \(p\equiv1\pmod4\)
\((2/p)\) \(p\equiv\pm1\pmod8\)
\((-2/p)\) \(p\equiv1,3\pmod8\)
\((3/p)\) \(p\equiv\pm1\pmod{12}\)
\((-3/p)\) \(p\equiv1\pmod3\)
\((5/p)\) \(p\equiv\pm1\pmod5\)

Solvability of \(x^2\equiv a\pmod p\)

For an odd prime \(p\) and \(p\nmid a\): solvable iff \((a/p) = 1\), and then there are exactly two solutions \(\pm x_0\). If \(p\mid a\) there is exactly one solution, \(x\equiv0\).

  • If \(p\equiv3\pmod4\) and \((a/p) = 1\), the solutions are \(x\equiv\pm a^{(p+1)/4}\pmod p\). (Check: \(x^2 = a^{(p+1)/2} = a\cdot a^{(p-1)/2}\equiv a\).)
  • If \(p\equiv1\pmod4\), a square root of \(-1\) is \(\bigl(\tfrac{p-1}2\bigr)!\) (Wilson).
  • General quadratic \(ax^2+bx+c\equiv0\pmod p\) (\(p\) odd, \(p\nmid a\)): complete the square. It is solvable iff the discriminant \(D = b^2-4ac\) satisfies \((D/p)\in\{0,1\}\), and has \(1+(D/p)\) solutions.
  • Prime powers. For odd \(p\) and \(\gcd(a,p) = 1\), \(x^2\equiv a\pmod{p^k}\) has \(1+(a/p)\) solutions (Hensel lifting).
  • Powers of 2. \(x^2\equiv a\) for odd \(a\): modulo \(2\) one solution; modulo \(4\) two solutions if \(a\equiv1\pmod4\), none if \(a\equiv3\); modulo \(2^k\) (\(k\ge3\)) four solutions if \(a\equiv1\pmod8\), none otherwise.
  • Composite modulus: count solutions modulo each prime power and multiply (CRT).

Jacobi symbol (basic level)

For odd positive \(n = p_1^{e_1}\cdots p_r^{e_r}\) and any integer \(a\): \(\left(\frac an\right) = \prod_i\left(\frac a{p_i}\right)^{e_i}.\)

Properties:

  • \((a/n)\) depends only on \(a\bmod n\) and is multiplicative in both \(a\) and \(n\); \((a/n) = 0\) iff \(\gcd(a,n) > 1\).
  • \((-1/n) = (-1)^{(n-1)/2}\) and \((2/n) = (-1)^{(n^2-1)/8}\).
  • Reciprocity: for odd positive coprime \(m, n\): \((m/n)(n/m) = (-1)^{\frac{m-1}2\cdot\frac{n-1}2}\).
  • It lets you evaluate Legendre symbols without factoring: flip, reduce, pull out \(2\)s, repeat (like the Euclidean algorithm).

Warning: for composite \(n\), \((a/n) = -1\) implies \(a\) is a non-residue modulo \(n\), but \((a/n) = +1\) does not imply \(a\) is a QR. Example: \((2/15) = (2/3)(2/5) = (-1)(-1) = 1\), yet \(2\) is not a square modulo \(15\) (the unit squares mod \(15\) are \(1, 4\)).

Worked examples

Example 1: residues modulo 13 and Euler’s criterion

List the QRs modulo \(13\) and test \(10\) and \(7\).

\(1^2,\dots,6^2 = 1,4,9,16,25,36\equiv1,4,9,3,12,10\). So QRs: \(\{1,3,4,9,10,12\}\). Thus \(10\) is a QR and \(7\) is an NR. Euler: \(7^6 = (7^2)^3 = 49^3\equiv10^3 = 1000\equiv12 = -1\). Consistent.

Example 2: product rule

Evaluate \((-42/97)\).

\(-42 = (-1)\cdot2\cdot3\cdot7\). Since \(97\equiv1\pmod4\), \((-1/97) = 1\). Since \(97\equiv1\pmod8\), \((2/97) = 1\). \((3/97) = (97/3) = (1/3) = 1\) (reciprocity applies as \(97\equiv1\pmod4\)). \((7/97) = (97/7) = (6/7) = (2/7)(3/7) = 1\cdot(-1) = -1\). Product: \(-1\). So \(-42\) is a non-residue modulo \(97\).

Example 3: reciprocity with two primes \(\equiv3\pmod4\)

Evaluate \((7/11)\).

\(7\equiv11\equiv3\pmod4\), so \((7/11) = -(11/7) = -(4/7) = -1\). Check: the QRs modulo \(11\) are \(1,3,4,5,9\); \(7\) is not among them.

Example 4: Jacobi symbol shortcut

Is \(219\) a quadratic residue modulo the prime \(383\)?

\(219\equiv3\) and \(383\equiv3\pmod4\), so \((219/383) = -(383/219) = -(164/219) = -(4/219)(41/219) = -(41/219)\). Now \(41\equiv1\pmod4\), so \((41/219) = (219/41) = (14/41) = (2/41)(7/41)\). As \(41\equiv1\pmod8\), \((2/41) = 1\); and \((7/41) = (41/7) = (6/7) = -1\). So \((41/219) = -1\) and \((219/383) = +1\). Yes, \(219\) is a QR modulo \(383\).

Example 5: solving quadratic congruences

(a) \(x^2\equiv5\pmod{11}\). \(11\equiv3\pmod4\), so \(x\equiv\pm5^3 = \pm125\equiv\pm4\), i.e. \(x\equiv4,7\). Check: \(16\equiv5\). (b) \(x^2+x+1\equiv0\pmod7\). \(D = 1-4 = -3\equiv4\), and \((4/7) = 1\), so there are two solutions. \(x = 2\): \(7\equiv0\); \(x = 4\): \(21\equiv0\). Solutions \(x\equiv2,4\). (c) \(x^2\equiv-1\pmod{103}\): \(103\equiv3\pmod4\), so no solution.

Example 6: counting solutions modulo a composite

How many solutions has \(x^2\equiv4\pmod{105}\)? \(105 = 3\cdot5\cdot7\) and \(4\) is a nonzero square modulo each, so each prime gives \(2\) solutions and CRT gives \(2^3 = 8\) solutions: \(x\equiv\pm2\) modulo each prime combined.

Example 7: which primes make \(3\) a residue

By reciprocity, \((3/p) = (p/3)(-1)^{(p-1)/2}\). For \(p\equiv1\pmod{12}\): \((p/3) = (1/3) = 1\) and the sign is \(+\), giving \(1\). For \(p\equiv11\pmod{12}\): \((p/3) = (2/3) = -1\) and \((-1)^{(p-1)/2} = -1\), giving \(+1\). For \(p\equiv5\): \((p/3) = -1\), sign \(+\), giving \(-1\). For \(p\equiv7\): \((p/3) = 1\), sign \(-\), giving \(-1\). So \((3/p) = 1\) iff \(p\equiv\pm1\pmod{12}\).

Common traps

  • Non-residue times non-residue is a residue. Only QR\(\times\)NR is an NR.
  • \((a/p)\) needs \(p\) prime and odd. \((2/15)\) is a Jacobi symbol, not a Legendre symbol.
  • Reciprocity needs both primes odd and distinct. Do not flip when either is \(2\); use the second supplement.
  • Sign rule: a minus sign appears only if both primes are \(\equiv3\pmod4\). \((29/43)\) has \(29\equiv1\pmod4\), so the flip carries no sign.
  • \((2/p)\) depends on \(p\bmod8\), not \(p\bmod4\). \(p = 5\) and \(p = 13\) are \(1\pmod4\) yet \(2\) is an NR.
  • \((-1/p)\) depends on \(p\bmod4\). \(p = 101\equiv1\pmod4\) gives \(+1\); \(p = 103\) gives \(-1\).
  • Reduce before flipping. \((29/43)\): flip first to \((43/29) = (14/29)\); do not leave \(43\) on top.
  • Jacobi symbol \(+1\) does not guarantee a square for composite \(n\). Only \(-1\) is conclusive.
  • Counting: \(x^2\equiv a\pmod p\) has \(2\) solutions for a residue, not \(1\); \((p-1)/2\) residues, not \(p/2\).
  • Euler’s criterion gives \(-1\), i.e. \(p-1\), not \(0\). \(a^{(p-1)/2}\equiv p-1\) for non-residues.
  • Gauss’s lemma counts residues greater than \(p/2\) among \(a,2a,\dots,\tfrac{p-1}2a\), not all of \(1,\dots,p-1\).

Previous-year questions

2026 Q53. Evaluate the Legendre symbol \((2/97)\). Worked key: A, which is \(1\) (unofficial key). Solution: \(97 = 12\cdot8+1\equiv1\pmod8\), so \((2/97) = (-1)^{(97^2-1)/8} = +1\). Direct check: \(14^2 = 196 = 2\cdot97+2\), so \(2\) is a square modulo \(97\).

2026 Q73. Evaluate \((-1/p)\) for \(p = 101\). Worked key: A, which is \(1\). Solution: \((-1/p) = (-1)^{(p-1)/2} = (-1)^{50} = 1\). Equivalent: \(101\equiv1\pmod4\). Indeed \(10^2\equiv-1\pmod{101}\).

2026 Q85. The value of the Legendre symbol \((29/43)\) is: Worked key: B, which is \(-1\). Solution: \(29\equiv1\pmod4\), so \((29/43) = (43/29) = (14/29) = (2/29)(7/29)\). As \(29\equiv5\pmod8\), \((2/29) = -1\). \((7/29) = (29/7) = (1/7) = 1\). So \((29/43) = -1\). Direct check: \(29^{21}\equiv-1\pmod{43}\).

Quick revision

  • Odd prime \(p\): exactly \((p-1)/2\) residues and \((p-1)/2\) non-residues among \(1..p-1\).
  • Euler: \((a/p)\equiv a^{(p-1)/2}\pmod p\); NR \(\times\) NR is a QR.
  • \((-1/p) = 1\) iff \(p\equiv1\pmod4\); \((2/p) = 1\) iff \(p\equiv\pm1\pmod8\).
  • \((3/p) = 1\) iff \(p\equiv\pm1\pmod{12}\); \((-3/p) = 1\) iff \(p\equiv1\pmod3\); \((5/p) = 1\) iff \(p\equiv\pm1\pmod5\).
  • Reciprocity: \((p/q)(q/p) = (-1)^{\frac{p-1}2\frac{q-1}2}\); minus sign only if both \(\equiv3\pmod4\).
  • Gauss’s lemma: \((a/p) = (-1)^\mu\) with \(\mu\) = number of \(ka\bmod p>p/2\), \(1\le k\le(p-1)/2\).
  • \(x^2\equiv a\pmod p\) has \(1+(a/p)\) solutions; for \(p\equiv3\pmod4\) the roots are \(\pm a^{(p+1)/4}\).
  • \(x^2\equiv-1\pmod p\) solvable iff \(p=2\) or \(p\equiv1\pmod4\).
  • \(ax^2+bx+c\equiv0\pmod p\): solvable iff \((D/p)\ne-1\) with \(D = b^2-4ac\).
  • Jacobi \((a/n) = \prod(a/p_i)^{e_i}\); \(-1\) means non-residue, \(+1\) proves nothing for composite \(n\).
  • 2026 values: \((2/97) = 1\), \((-1/101) = 1\), \((29/43) = -1\).
