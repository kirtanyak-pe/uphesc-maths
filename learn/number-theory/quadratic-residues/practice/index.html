Quadratic residues and reciprocity

15 questions. Pick an answer to see if it is right and why.

0 of 15 answered · 0 correct

  1. Question 1Easy
    The number of quadratic residues modulo \(19\) among \(1,2,\dots,18\) is

    Why

    For an odd prime \(p\) exactly \((p-1)/2\) of \(1,\dots,p-1\) are residues: \((19-1)/2 = 9\).
  2. Question 2Easy
    \(-1\) is a quadratic residue modulo which of the following primes?

    Why

    \((-1/p) = 1\) iff \(p\equiv1\pmod4\). Only \(13\) qualifies (\(7, 11, 19\equiv3\pmod4\)). Check: \(5^2 = 25\equiv-1\pmod{13}\).
  3. Question 3Easy
    \(2\) is a quadratic non-residue modulo

    Why

    \((2/p) = 1\) iff \(p\equiv\pm1\pmod8\). \(7, 17, 23\equiv7, 1, 7\pmod8\) are residues. \(13\equiv5\pmod8\), so \(2\) is a non-residue.
  4. Question 4Medium
    The Legendre symbol \(\left(\dfrac{7}{19}\right)\) equals

    Why

    \(7\equiv19\equiv3\pmod4\), so reciprocity gives a sign: \((7/19) = -(19/7) = -(5/7)\). The residues mod \(7\) are \(1,2,4\), so \((5/7) = -1\) and \((7/19) = +1\). (Check: \(8^2 = 64\equiv7\pmod{19}\).)
  5. Question 5Medium
    The Legendre symbol \(\left(\dfrac{15}{101}\right)\) equals

    Why

    \((15/101) = (3/101)(5/101)\). Since \(101\equiv1\pmod4\): \((3/101) = (101/3) = (2/3) = -1\) and \((5/101) = (101/5) = (1/5) = 1\). Product \(-1\).
  6. Question 6Hard
    The number of solutions of \(x^2\equiv1\pmod{256}\) modulo \(256\) is

    Why

    For \(2^k\) with \(k\ge3\) the congruence \(x^2\equiv1\) has four solutions, \(\pm1\) and \(\pm1+2^{k-1}\). Here they are \(1,127,129,255\). The count \(2\) holds only for odd prime powers.
  7. Question 7Medium
    For which of the following primes is \(5\) a quadratic residue?

    Why

    Since \(5\equiv1\pmod4\), reciprocity gives \((5/p)=(p/5)\), so \(5\) is a residue iff \(p\equiv\pm1\pmod5\). Now \(11\equiv1\), while \(13\equiv3\), \(17\equiv2\) and \(23\equiv3\) are non-residues. Check: \(4^2=16\equiv5\pmod{11}\).
  8. Question 8Medium
    Let \(p\) be an odd prime. Which statements are true? (I) The product of two quadratic non-residues modulo \(p\) is a residue. (II) If \((a/n)=1\) for odd composite \(n\) then \(a\) is a square modulo \(n\). (III) If \(a\) is a residue modulo \(p\) then \(a^{(p-1)/2}\equiv1\pmod p\). (IV) \((2/p) = 1\) iff \(p\equiv1\pmod4\).

    Why

    (I) true: \((-1)(-1) = 1\). (III) is Euler’s criterion. (II) false: \((2/15) = 1\) but \(2\) is not a square mod \(15\). (IV) false: \((2/p) = 1\) iff \(p\equiv\pm1\pmod8\) (e.g. \(p=5\)).
  9. Question 9Medium
    In Gauss’s lemma for \(a = 5\), \(p = 13\), the number \(\mu\) of elements of \(5,10,15,20,25,30\) whose least positive residue modulo \(13\) exceeds \(13/2\) is

    Why

    Residues of \(5,10,15,20,25,30\) modulo \(13\): \(5,10,2,7,12,4\). Those above \(6.5\): \(10, 7, 12\). So \(\mu = 3\) and \((5/13) = (-1)^3 = -1\).
  10. Question 10Hard
    A solution of \(x^2\equiv2\pmod{47}\) is

    Why

    \(47\equiv7\pmod8\), so \(2\) is a residue. As \(47\equiv3\pmod4\), \(x\equiv\pm2^{12} = \pm4096\equiv\pm7\). Check: \(7^2 = 49\equiv2\). The other options square to \(25, 81\equiv34, 121\equiv27\).
  11. Question 11Medium
    Assertion (A): \(6\) is a quadratic residue modulo every prime \(p\equiv1\pmod{24}\). Reason (R): for \(p\equiv1\pmod{24}\) both \((2/p)=1\) (since \(p\equiv1\pmod8\)) and \((3/p)=1\) (since \(p\equiv1\pmod{12}\)). Choose the correct option.

    Why

    By multiplicativity \((6/p)=(2/p)(3/p)\). If \(p\equiv1\pmod{24}\) then \(p\equiv1\pmod8\), so \((2/p)=1\); and \(p\equiv1\pmod{12}\), so \((3/p)=(p/3)=1\). The product is \(1\), so R explains A. (Example: \(73\).)
  12. Question 12Hard
    The Jacobi symbol \(\left(\dfrac{35}{57}\right)\) equals

    Why

    \(57 = 3\cdot19\). \((35/3) = (2/3) = -1\) and \((35/19) = (16/19) = 1\), so the product is \(-1\). By reciprocity instead: \(57\equiv1\pmod4\), so \((35/57) = (57/35) = (22/35) = (2/35)(11/35) = (-1)(1) = -1\). Since \(-1\), \(35\) is a non-residue mod \(57\).
  13. Question 13Medium
    The sum of all quadratic residues among \(1,2,\dots,12\) modulo \(13\) is

    Why

    The residues are \(1,3,4,9,10,12\) with sum \(39\). For \(p\equiv1\pmod4\), \(a\) and \(p-a\) are both residues, so they pair up with sum \(p\); \(3\) pairs give \(3\cdot13 = 39 = p(p-1)/4\).
  14. Question 14Easy
    The Legendre symbol \(\left(\dfrac{5}{29}\right)\) equals

    Why

    \(29\equiv1\pmod4\), so \((5/29) = (29/5) = (4/5) = 1\). Check: \(11^2 = 121 = 4\cdot29+5\).
  15. Question 15Medium
    The product of all quadratic residues among \(1,2,\dots,12\) modulo \(13\) leaves remainder

    Why

    The product of the residues modulo an odd prime \(p\) is \(\equiv(-1)^{(p+1)/2}\); for \(p=13\) this is \((-1)^7=-1\equiv12\). Direct check: \(1\cdot3\cdot4\cdot9\cdot10\cdot12=12960=13\cdot996+12\).
