  • Uniform convergence of nx/(1 + n²x²)

    Show answerHide answer

    Its maximum is 1/2, at x = 1/n, so it is not uniform on any interval containing 0. On [a, ∞) with a > 0 it is uniform.

  • Q44F_n(x)=nx/(1+n^3x^2)-type series on [0,inf): uniform convergence and interchange with integralD

    f_n = nx/(1+n^2x^2): sum_n f_n(x) ~ sum 1/(nx) diverges for x>0, so the series is not uniformly convergent (not even pointwise); term-by-term integration over [0,inf) invalid (int f_n diverges, sup f_n=1/2 not -> 0).

    Fairly sure

    Two solves agree. B is arguable only in the sense that both sides are infinite.

  • Q39Order: l² Hilbert → Banach → normed → topologicalC

    Implication chain: l2 Hilbert (II) => Banach (III) => normed (IV) => topological (I): II, III, IV, I. Reverse order (B) is the other reading.

    Fairly sure

    If the intended order is weakest to strongest, the answer is B instead.

  • Q40Xy/√(x²+y²): continuity/differentiability at originD

    |f| <= r/2 so continuous; f_x(0,0)=f_y(0,0)=0; along y=x, f/r = 1/2 != 0 so not differentiable.

    Sure

  • Q41Interval of uniform convergence of a series of functionsD

    On [1,inf), 1/(1+n^2 x) <= 1/n^2, Weierstrass M-test. On (0,c) not uniform (tail unbounded as x->0).

    Sure

  • Q42Ordering of series/convergence resultsC

    Chain of implications: partial sums converge (II) => series converges (III) => a_n->0 (IV) => {a_n} convergent hence Cauchy (I).

    Sure

  • Q43Max of sin x sin y sin(x+y)B

    Max of sin x sin y sin(x+y) is (sqrt3/2)^3 = 3sqrt3/8 at x=y=pi/3.

    Sure

  • Q44Divergence of a series ∑uₙ with reasonA

    u_n = 1/((2/3)^n+1) -> 1 != 0, so series diverges; R is the divergence (nth term) test.

    Sure

  • Q45Domain of uniform convergenceD

    f_n = n x e^{-n x^2}; sup on [0,a] is sqrt(n/2)e^{-1/2} -> inf (no uniform). On [1,2], f_n <= 2n e^{-n} -> 0, uniform. Exponent read as -n x^2.

    Fairly sure

    exponent in the printed f_n is small; read as -n x^2. If it were -x^2 the sequence would not converge pointwise at all, so D stands either way among the options.
