  • Q32Symmetric degenerate kernel of rank 2: max number of nonzero eigenvalues, eigenfunction orthogonalityD

    Answer: 2, orthogonal

    Rank-2 symmetric degenerate kernel has at most 2 nonzero eigenvalues; eigenfunctions of a symmetric kernel for distinct eigenvalues are orthogonal.

    Sure

  • Q39Y(x)=1+lambda*integral of x t y(t) dt on [0,1]: nonzero eigenvalue via consistency conditionD

    Answer: lambda=3

    y=1+lambda*c*x with c=int t y dt; c=1/2+lambda*c/3 so c(1-lambda/3)=1/2; singular (characteristic value) at lambda=3.

    Sure

  • Q45BVP converted via Green's function to symmetric Fredholm equation; smallest lambda where resolvent kernel failsA

    Answer: pi^2

    EL: y''=lambda*y, Dirichlet Green's function of -d^2/dx^2 has characteristic values n^2 pi^2; smallest is pi^2 (sign convention aside, only positive options).

    Fairly sure

    sign of lambda (true value -pi^2 under one convention); chose smallest positive characteristic value pi^2.

  • Q68Evaluate improper integral of sin x / x (type) using Fourier-transform reasoningD

    Int_0^inf sin x / x dx = pi/2 (Dirichlet integral, via Fourier transform of rectangular pulse)

    Sure

  • Q76Extremal of integral (y'^2+y^2) with constraint integral y=1 via Lagrange multiplier: formC

    Euler-Lagrange: y''-y=-lambda/2 gives y=lambda/2 + c1 e^x + c2 e^-x; with free ends (natural BC y'(0)=y'(1)=0) c1=c2=0 so y=constant=1 (int y=1). Constant is the only option that can occur

    Fairly sure

    No boundary conditions are printed. C assumes natural boundary conditions.

  • Q82Degenerate kernel gives singular linear system: condition for existence of solution (rank condition)B

    Singular (degenerate-kernel) system is solvable iff consistency holds: rank A = rank [A|b] (Fredholm alternative). "Rank condition satisfied" is the only sensible option

    Sure

  • Q89Volterra kernel not of convolution type: correct way to apply Laplace transformB

    Laplace transform needs convolution kernel; a variable transformation (e.g. t=e^s) can convert some non-convolution kernels (Mellin type) to convolution form. Other options (ignore kernel, convert to PDE, direct transform) are not valid approaches

    Not sure

    poorly posed; B (variable transformation) is a best guess.

  • Q97Y(x)=lambda * integral of G(x,t)y(t)dt: condition for nontrivial solution via operator theory (OCR-uncertain)D

    Homogeneous Fredholm eqn y=lambda K y has non-trivial solution iff lambda is an eigenvalue i.e. Fredholm determinant D(lambda)=det(I-lambda K)=0

    Sure
