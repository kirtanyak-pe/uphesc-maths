  • Q315-dim operator, min poly (x-2)^3(x-1): Jordan block structure, generalized eigenspace dim, rank of (T-2I)^2A

    Answer: 3,3

    Min poly (x-2)^3(x-1): gen. eigenspace of 2 has dim d=3 or 4. d=3 (one 3-block, eigenvalue 1 has mult 2): rank (T-2I)^2 = 1 + 2 = 3. d=4 gives (4,2), not an option; (4,1) impossible.

    Sure

  • Q38Gram-Schmidt on (1,1,0),(1,0,1),(0,1,1); trace of projection onto first two vectorsA

    Answer: 2

    Projection onto a 2-dim subspace has trace = rank = 2.

    Sure

  • Q75F,g independent in V*; T(x)=(f(x),g(x)): rank of T and dim kernelA

    f,g independent -> T onto R^2, rank 2; nullity n-2

    Sure

  • Q80Operator with rank(T)=2 and given eigenvalue data: find minimal polynomial, then trace and nullityA

    T^2=T: min poly x^2-x; eigenvalues 1 (mult 2 = rank), 0 (mult 2). trace=2, nullity=4-2=2

    Sure

  • Q83Hermitian A with A^2=I, 4-dim, equal multiplicities: eigenvalues, orthogonal decomposition, traceA

    A^2=I, A Hermitian -> eigenvalues +-1; dim 4 with equal multiplicity (2 each) -> trace = 2-2 = 0

    Sure

  • Q84Q=x^2+y^2+z^2+2xy+2yz+2zx: matrix form, diagonalise, rank and indexB

    Q=(x+y+z)^2: matrix of all ones, eigenvalues 3,0,0 -> rank 1, positive index 1 -> (1,1)

    Fairly sure

    Rank 1. If "index" means the number of negative squares, the answer is A (1,0).

  • Q873x3 real symmetric with char poly (x-1)^2(x-3): diagonalizable?, quadratic form signatureC

  • Q90Ax=b, A is 3x4 rank 2, consistent: dimension of solution space, null spaceC

  • Q93RCF has companion blocks of degrees 2 and 3: dimension, minimal and characteristic polynomialD

  • Q98A^3-3A^2+2A=0: eigenvalues, invertibility, rank of A(A-I)A
