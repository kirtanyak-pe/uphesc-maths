  • Gaussian curvature of a surface

    Show answerHide answer

  • Q34Count something between antipodal points of a sphere using global geometric arguments (1, 2, finite, infinite)D

    Answer: Infinite

    Antipodal points on S^2 are joined by infinitely many great semicircles (one per meridian).

    Sure

  • Q42Hausdorff second countable regular manifold: number of compatible metrics (0,1,finite,infinite)D

    Answer: Infinite

    Hausdorff, 2nd countable, regular implies metrizable (Urysohn); if d is compatible so is c*d for any c>0 (also min(d,1) etc.), so infinitely many.

    Sure

  • Q49Curve with k=1, tau=0: dimension of minimal ambient manifold containing itC

    Answer: 2

    k=1, tau=0 constant: plane circle; minimal ambient dimension 2.

    Sure

  • Q54Every sequence has a Cauchy subsequence: which of compact/totally bounded/complete must holdB

    Answer: totally bounded only

    Every sequence has a Cauchy subsequence iff X totally bounded; completeness/compactness not implied (e.g. (0,1)).

    Sure

  • Q58Surface z=x^2+y^2: Gaussian curvature at origin via fundamental formsC

    Answer: 4

    K=(f_xx f_yy - f_xy^2)/(1+f_x^2+f_y^2)^2 = 4 at origin.

    Sure

  • Q62Curve (t,t^2,t^3): curvature at t=0 via Frenet formulasC

    Answer: 2

    gamma'=(1,0,0), gamma''=(0,2,0) at t=0: k = |gamma' x gamma''|/|gamma'|^3 = 2.

    Sure

  • Q96Compact connected manifold: number of connected componentsD

    Connected means exactly 1 component

    Sure

  • Q99Curve with constant nonzero curvature and torsion: circle/line/helix/ellipseC

    Constant nonzero curvature and torsion -> circular helix (Frenet equations); circle has zero torsion, line zero curvature

    Sure
