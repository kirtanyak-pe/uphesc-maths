  • Divisor functions σ(n) and d(n)

    Show answerHide answer

    For n = ∏ pᵃ: d(n) = ∏ (a + 1) and σ(n) = ∏ (p^(a+1) − 1)/(p − 1).

  • Q48X=1003*997, find x mod 13Likely bonus marksB

    Answer: 3

    1003 = 2, 997 = 9 mod 13, product 18 = 5 mod 13 (also 10^6 - 9 = 1 - 9 = 5). Options are 1,3,12,9, none is 5. Guess 3 (would arise from slip 10^6 = -1).

    Not sure

    Misprint: 1003×997 ≡ 5 (mod 13), which is not an option. 3 is what the same product gives mod 11, so the options may belong to a different modulus.
